# 营销内容学习与反思

## 1. 学习不是只看播放量

至少分开：

```text
内容质量
分发触达
目标人群匹配
销售承接
产品事实
```

单条播放量不能证明产品价值，也不能证明内容结构成功。

## 2. 反馈来源

- 真实发布数据：曝光、2 秒留存、完播、收藏、评论、主页、私信。
- 销售反馈：客户原话、异议、比较对象、预约和诊断结果。
- 使用反馈：从 `zhuangdeqing-usage-content` 获取入驻、困惑和兼容问题。
- 业务变化：从 `zhuangdeqing-business` 获取新决策、缺口和能力成熟度。

## 3. 复盘卡

```text
MC-LEARN-*
场景：
受众：
内容目标：
主要变量：
证据：
发生了什么：
可能原因：
内容问题 / 分发问题 / 产品问题 / 销售问题：
结论：keep / adjust / extend / stop
下一步实验：
```

## 4. 结论边界

- 至少等 24–72 小时数据。
- 不把不同选题、不同受众、不同档期的数据直接归为同一实验。
- 一次只调整一个主要变量。
- 学习结论先写为候选经验，多次证据后再晋升为团队规则。
- 不用内容学习结论修改业务事实。

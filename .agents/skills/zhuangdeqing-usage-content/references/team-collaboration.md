# 使用内容团队协作

## 输入

- 业务智能体：场景、规则、权限、金额、状态和证据。
- 产品应用开发：当前页面、Provider、角色路径、验收和产品缺口。
- 营销内容：用户看到的外部承诺和预期。
- 客服/培训/客户成功：真实问题和操作阻力。
- 产品研发：修复结果和新行为证据。

## 输出

- 入驻和首周路径。
- 角色快速开始、任务教程和 FAQ。
- App/Web 对比说明。
- 页面内帮助和异常恢复。
- 兼容台账和产品缺口。
- 给营销内容的真实操作路径和边界。

## 交接规则

- 事实 ID 和页面证据必须随内容包传递。
- 产品行为变化时，通知使用内容负责人标记相关 `UC-*` 为 `stale`。
- 兼容结论必须进入 `UC-COMPAT-*`，不只留在聊天或客服话术。
- 营销内容不得直接改写使用步骤；使用内容不得直接发布外部营销主张。

# 页面构图模板（Web）

> 构图先定骨架再填内容。不要在写代码时临时决定布局。

## 0. 通用骨架

```text
┌─────────────────────────────────────────────────────────┐
│ 侧边导航 236px │  顶栏 64px（当前企业/门店/角色/搜索/账号）│
│                ├─────────────────────────────────────────┤
│                │  PageHeader：页面标题 + 口径/时间 + 主行动 │
│                ├─────────────────────────────────────────┤
│                │  主内容区（12 列栅格，左右留白 24px）      │
│                │  区块间距 20–32px                        │
│                └─────────────────────────────────────────┘
```

规则：

- 全局上下文（企业/门店/团队/角色）必须常驻可见。
- `PageHeader` 高度 56–72px，包含：标题（20px/600）、口径与时间（12px）、唯一主行动（右侧）。
- 主内容区最大宽度不限制，但内容必须对齐栅格；超宽屏（>1600px）内容不超过 1600px。
- 页面第一个区块距离 PageHeader 的间距 ≥ 20px。

## 1. 决策页（Boss 经营管控）

```text
标题 + 周期/口径 + 数据截止时间
────────────────────────────────────────────
[主指标卡 ×4]  每个：指标名 / 数值(28px) / 环比 / 口径
────────────────────────────────────────────
[趋势区 8 列]                    [结构/排行 4 列]
────────────────────────────────────────────
[风险与待决事项列表（可下钻）]
```

首屏预算：标题、四个主指标、至少一个风险入口。

规则：

- 每个数字必须带口径、周期、`asOf`。
- 指标卡最多 4 个一行；超过 4 个必须分组或改为列表。
- 风险区优先级高于排行区。
- 禁止在决策页放批量录入表单。

## 2. 行动队列页（岗位工作台）

```text
标题 + 我的范围（企业/门店/团队）+ 今日日期
────────────────────────────────────────────
[今日主线：待办 N 项]     [风险提示]     [快捷动作 ×2–3]
────────────────────────────────────────────
[任务卡列表]
  每张卡：对象身份 / 当前状态 / 下一步 / 原因 / 责任人 / 截止
────────────────────────────────────────────
```

首屏预算：今日待办数量、至少 3 条具体任务、下一步动作。

规则：

- 角色工作台统一使用 `RoleWorkbenchShell`，分段加载用 `Promise.allSettled`。
- 任务卡必须有"下一步"按钮；没有下一步的任务不是任务卡。
- 快捷动作最多 3 个，超过则收进"更多"。
- 禁止在工作台内嵌完整业务页面。

## 3. 对象详情页（共享对象层）

```text
[对象身份区]  名称 + 编号 + 状态标签 + 负责人 + 关键金额
[状态轨道]    当前阶段 + 时间线
[下一步卡片]  动作 + 原因 + 前置条件 + 阻断
────────────────────────────────────────────
[事实摘要 8 列]              [关联对象 4 列]
────────────────────────────────────────────
[Tab：明细 / 变更 / 附件 / 操作记录 / 时间线]
```

首屏预算：对象身份、当前状态、下一步、关键金额。

规则：

- 所有角色的对象页使用同一骨架（`ObjectDetailShell`），差异只在字段、动作与默认排序。
- 状态轨道使用 `ObjectMainlineTrack`，必须显示已完成/当前/未开始三段。
- 下一步卡片必须给出"为什么不能继续"。
- 关联对象必须可点击，且保持当前上下文（返回后回到原 Tab）。

## 4. 专业列表页（财务、合同、材料、组织）

```text
标题 + 结果计数 + 搜索 + 筛选 + 主行动
────────────────────────────────────────────
[筛选条件回显条]
[批量操作条（选中时出现）]
────────────────────────────────────────────
[表格]  固定表头 / 固定操作列 / 数字右对齐
────────────────────────────────────────────
[分页：总数 + 范围 + 页码]
```

首屏预算：表头、至少 8 行数据、分页或总数。

规则：

- 列表用于定位，详情用于推进；行内只放 1 个主操作。
- 操作列最多 2 个可见按钮，其余收进"更多"。
- 筛选超过 3 项必须收进抽屉。
- 空态与"筛选无结果"必须区分。

## 5. 抽屉表单页

```text
┌──────────────────────────────┐
│ 标题 + 关闭                   │
├──────────────────────────────┤
│ [分组标题]                    │
│ 字段（标签在上，错误在下方）    │
│ [分组标题]                    │
│ 字段                          │
├──────────────────────────────┤
│ 底部固定：[取消] [主行动]      │
└──────────────────────────────┘
```

规则：

- 抽屉宽度：单职责 400–480px；表单 560–720px；查看 640–840px。
- 底部操作栏固定，滚动时始终可见。
- 标题必须写明"做什么对象、做什么动作"。
- 超过 12 个字段改用独立页面。
- 高危动作在抽屉内也必须二次确认。

## 6. 浏览器兼容与栅格降级

| 宽度 | 布局 |
| --- | --- |
| ≥ 1441px | 12 列完整布局，侧栏展开 |
| 1281–1440px | 12 列，次要列收窄 |
| 1025–1280px | 12 列，次要列隐藏或折叠，侧栏可收起 |
| 769–1024px | 侧栏收起为 72px，表格横向滚动，抽屉加宽 |
| ≤ 768px | 单列堆叠（降级形态，是否承诺由产品裁决） |

## 7. 构图自检

- 首屏能回答"这是什么、现在什么状态、我该做什么"吗？
- 遮住内容只看骨架，区块关系清楚吗？
- 把任意区块单独截图，它自己成立吗？
- 换一个角色进入，骨架是否需要重做？（需要则说明壳层设计有问题）

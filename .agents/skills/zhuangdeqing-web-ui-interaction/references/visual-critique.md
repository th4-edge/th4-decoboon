# 视觉批判与修正（强制循环）

> 这份文件的作用是让"丑"变成可检测、可修正、可验收的问题。批判必须基于截图，不允许凭感觉。

## 1. 批判循环

```text
① 渲染   真实浏览器打开目标页面，按角色登录
② 截图   1440×900 / 1280×800 / 1024×768 三档整屏
③ 批判   逐条对照第 2 节反模式清单，标出命中项
④ 修正   按第 3 节处方修改，一次只改一类问题
⑤ 复渲染 重新截图，确认命中项消失且未引入新问题
⑥ 判定   按第 4 节量规打分，< 3 分不得交付
```

硬性要求：

- 至少两轮循环；第一轮后必须列出问题清单。
- 每轮记录"问题 → 修正 → 证据"。
- 不允许"我觉得差不多了"作为结束理由。
- 第二轮后仍有未解决项，必须写明原因，不得静默放行。

## 2. 反模式清单

### A. 色彩（P0）

- [ ] 页面出现 `tokens.scss` 之外的硬编码色值。
- [ ] 出现已废弃冷灰蓝：`#8d98a5` `#25313d` `#778390` `#465260` `#17212b` `#66717e` `#eef2f4` `#fbfcfd` `#aeb8c2`。
- [ ] 同一页面出现两种以上同等强度的强调色。
- [ ] 语义色被用于装饰（如用危险色做边框美化）。
- [ ] 仅靠颜色区分状态，没有文字或图标。
- [ ] 页面颜色种类超过 8 种。

### B. 字体（P0）

- [ ] 出现 12px 以下的正文字号（9 / 9.5 / 10 / 10.5 / 11 / 11.5px）。
- [ ] 字号不在冻结字阶内。
- [ ] 同一层级元素字号/字重不一致。
- [ ] 一屏出现超过 4 种字号。
- [ ] 金额未使用等宽数字，无法纵向对齐比较。
- [ ] 中文使用 800 以上字重导致糊字。
- [ ] 行高过密（正文 < 1.45）或过疏（表格 > 1.8）。

### C. 间距与对齐（P0）

- [ ] 出现非 4 倍数间距（5 / 7 / 9 / 10 / 14 / 18px 等裸值）。
- [ ] 相关元素与无关元素间距相同，分组不成立。
- [ ] 卡片内边距不一致（同为卡片却是 12px 与 20px 混用）。
- [ ] 左边缘未对齐到同一垂直线。
- [ ] 数字列未右对齐。
- [ ] 表单标签左右混用两种对齐方式。
- [ ] 元素居中摆放但没有居中理由。

### D. 层级（P1）

- [ ] 一屏看不出"最重要的一件事"。
- [ ] 层级差距过小（只差 1px 字号或 100 字重）。
- [ ] 出现 4 种以上视觉强调。
- [ ] 每个卡片都用重阴影或强边框，没有主次。
- [ ] 标题、正文、说明使用相近的视觉权重。

### E. 组件（P1）

- [ ] 页面自造卡片、状态标签、抽屉、空态、错误态。
- [ ] 同类元素圆角不一致（7/8/9/10/11/12px 混用）。
- [ ] 图标风格混用（线性 + 实心 + emoji + 字符箭头）。
- [ ] 按钮层级混乱（多个实心主色按钮同屏）。
- [ ] 圆角裸值未使用 Token。

### F. 状态（P0）

- [ ] 缺少加载态、失败态、真实空态、无权限态、会话过期态中的任一。
- [ ] 加载失败显示成空数据或 0。
- [ ] 空态只写"暂无数据"，没有下一步。
- [ ] 错误文案无信息量（"操作失败"）。
- [ ] 一个区块失败导致整页白屏。
- [ ] 长文本、长金额、超多列没有处理方案。

### G. 表格（P1）

- [ ] 表格行高 < 40px 导致拥挤。
- [ ] 数字列未右对齐。
- [ ] 操作列未固定，横向滚动后找不到操作。
- [ ] 超过 8 列但无列取舍策略。
- [ ] 筛选条件无回显、无法一键清除。
- [ ] 分页切换筛选后未回到第 1 页。
- [ ] "无数据"与"筛选无结果"未区分。

### H. 表单（P1）

- [ ] 超过 7 个字段未分组。
- [ ] 输入过程中实时报错。
- [ ] 错误只汇总在顶部，未贴近字段。
- [ ] 提交按钮位置与其他页面不一致。
- [ ] 提交中未禁用，可重复提交。
- [ ] 有未保存修改时离开无提示。

### I. 动效与性能感（P2）

- [ ] 使用 `transition: all`。
- [ ] 动画时长超过 300ms。
- [ ] 出现弹跳、旋转、缩放等娱乐化动效。
- [ ] 未尊重 `prefers-reduced-motion`。
- [ ] 点击后 300ms 内无任何反馈。

### J. 可访问性（P0）

- [ ] 使用 `outline: none` 移除焦点。
- [ ] 关键路径无法用键盘完成。
- [ ] 图标按钮缺少可访问名称。
- [ ] 正文对比度低于 WCAG AA。
- [ ] 弹层不支持 `Esc` 关闭。

### K. 响应式（P1）

- [ ] 使用冻结断点（1440/1280/1024/768）之外的断点。
- [ ] 出现「百分比宽度 + gap」或 `calc(NN% - Npx)` 栅格写法。
- [ ] 1024 宽度下出现异常横向滚动或主行动被遮挡。
- [ ] 表格在窄屏下未做列取舍。
- [ ] 内联样式承担布局职责。

### L. 跨端（P1）

- [ ] 同一业务对象在 App 与 Web 的状态、金额、责任人显示不一致。
- [ ] Web 自行计算了 App 未认可的金额或完成度。
- [ ] 差异未登记 `DEF-*`。

## 3. 常见病症与处方

| 病症 | 处方 |
| --- | --- |
| 整页冷淡发灰 | 用 `$ink-*` 中性色替换冷灰蓝；品牌青绿只给主行动与选中态 |
| 字小且平 | 正文升到 14px，标题 18/20px，压缩用字阶而不是压字号 |
| 满屏都是卡片 | 减少卡片数量，改用分组标题 + 分隔线；卡片内边距统一 18–20px |
| 到处都是框和线 | 只给真正的容器加边框，组内用间距区分 |
| 数字对不齐 | 金额列右对齐 + `tabular-nums` |
| 页面很挤 | 区块间距提到 20–32px，卡片内边距提到 18–20px，删掉低价值字段 |
| 状态看不清 | 状态四件套：文字 + 颜色 + 图标 + 位置 |
| 空页面很空 | 空态给图标 + 一句业务说明 + 一个下一步按钮 |
| 灰阶没有对比 | 主文本用 `$ink-950`，次要 `$ink-600`，辅助 `$ink-400`，不要都用同一灰 |
| 首屏没有重点 | 定一个主指标/主行动，其余全部降级 |

## 4. 量规（评分锚点）

| 分数 | 含义 |
| --- | --- |
| 0 | 存在 P0 反模式，或基本不可用 |
| 1 | 能用但明显业余，多个 P1 反模式 |
| 2 | 基本合格，仍存在影响专业度的 P2 问题 |
| 3 | 达到可交付标准，无 P0/P1 反模式 |
| 4 | 达到标杆水平，可被其他页面直接参照 |

交付判定：

- 任一维度 < 3 → **不得交付**。
- 主链页面（客户、报价、合同、项目、财务、角色工作台）平均必须 ≥ 3.5。
- C1 视觉一致性与 C4 状态完整性必须 ≥ 3，无例外。

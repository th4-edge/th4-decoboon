## 风险

- Web v2 已通过类型检查、全角色静态体系校验和生产构建，并已部署到正式域名；但生产库尚无真实企业账号和业务数据，登录后全业务验收尚未完成。
- 设计明细仍逐行保存而非服务端原子批量；增减项 UI 当前以金额/成本变化为主，原合同行级来源追溯仍可增强。
- `ProviderSecurityAcceptanceTest` 路由总数预期仍为 196，当前实际 197；`ProductionReleaseBaselineAcceptanceTest` 仍禁止 `127.0.0.1`，与生产回环绑定策略冲突，需 acceptance 同步更新。
- `.env.production` 已指向 `https://decoboon.joytsing.com/api/`；历史归档中的 `api.invalid` 仅保留为旧构建验证记录。
- 主入口 chunk 体积较大，存在首屏性能风险。
- 历史本地 `upload/**` 文件不会自动迁移；生产服务器如已有历史文件需先清点再迁移。
- 框架通用 `{model}/upload/{property}` 仍存在本地写入能力，业务代码不得新增直接使用该通道的模型字段。
- 微信支付 API v3 密钥仅能通过真实回调端到端确认；商户证书 2031-09-14 到期，微信支付公钥轮换需监控。
- 微信支付证书材料与回调域名已部署到生产服务器，但真实回调验签解密和幂等履约仍需首笔支付端到端确认。
- `decoboon.joytsing.com` TLS 证书当前有效期至 2026-12-13 UTC（北京时间约 2026-12-14），需配置续期与部署监控。
- 真实微信业务回归、生产初始账号、备案、AppID、法务正文以及备份恢复/回滚演练仍未完成。

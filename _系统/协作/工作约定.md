# 工作约定（当前生效）

> 本文件只保留长期有效的协作规则，不记录任务历史。
> 2026-11-02 以前的历史已归档到 `_系统/归档/20261102/工作约定-历史.md`，默认不读取。

## 1. 当前协作模式

- 试运营单人模式，优先成本和响应速度，安全底线以 `docs/operations/试运营单人轻量协作与发版规范.md` 为准。
- 每次变更先判定 L0–L3，并用 `CHG-*` 记录目标、范围、验收、证据和结论。
- L0/L1 做定向验证；L2/L3、DDL、迁移、权限、金额/成本、支付、跨租户和数据删除按高风险门禁执行。
- 新任务默认使用新的 Codex 会话；同一会话只处理一个连续目标，不把诊断、开发和发版混在一起。

## 2. 任务启动

开始编码前必须写清：

- 一个用户可见结果或明确技术结果；
- 范围内和明确非范围；
- 验收命令、页面或接口证据；
- 失败时的停止条件。

没有明确结果、边界和验收时，只做调查，不进入实现。

## 3. 阅读预算

- 先读根 `AGENTS.md` 和当前目录最近的 `AGENTS.md`，再用 `rg -n` 定位任务文件。
- 不预读完整 `rules.md`、历史 worklog、归档状态、历史验收或无关端代码。
- L0：最多 3 个文件、约 100 行，不跑无关测试。
- L1：最多 8 个文件，一次定向测试和一次构建/类型检查。
- 工具输出只保留失败行、关键结论和 diff；完整日志留在文件。

## 4. 执行纪律

| 约定 | 要求 |
| --- | --- |
| 最小补丁 | 只改实现当前目标所需的文件，禁止顺手重构和扩展相邻功能 |
| 一次一轮 | 一轮实现、一次验证、一次修复；不连续换方案试错 |
| 目标锁定 | 如果本轮没有产生新的用户可见结果或可验证事实，停止而不是继续扩查 |
| 两轮止损 | 同一问题连续两次修正仍无改善，停止并重新确认目标、边界或事实源 |
| 证据优先 | 没运行过的测试、没看到的页面、没发生的接口调用不得写成 PASS |
| 输出从简 | 只报告结论、证据、失败项、风险和下一步，不倾倒完整日志 |

## 5. 记录与归档

- `CHG-*` 是变更和发布事实源；`_系统/任务/当前工作.md` 只保留当前活跃任务，不累积历史。
- 任务完成后更新 `CHG-*` 和当前状态；历史执行摘要按月或阶段归档，不继续追加到本文件。
- `_系统/上下文/当前项目.md` 只保留当前产品阶段、发布基线、活跃风险和下一步。
- 归档目录不是默认上下文；只有追溯事故、发布或历史决策时才按关键词读取。

# 营销证据与主张门禁

## 1. 事实等级

只使用业务智能体允许的等级：

- `verified`：可作为正式事实表达。
- `implemented / accepted`：按业务智能体定义和范围表达，不得自动等同于客户效果。
- `draft / hypothesis`：只能写成待验证判断。
- `gap / conflict`：不得作为确定性卖点。
- 用户明确决策：按决策原文和适用边界表达。

## 2. 主张类型

| 类型 | 示例 | 必要证据 |
| --- | --- | --- |
| 能力主张 | 可以记录报价版本 | CAP、页面/测试、范围 |
| 业务规则主张 | 未完成报价不能直接签约 | BR、SCN |
| 指标主张 | 回款、毛利、成本完整性 | MET、口径、缺失值 |
| 客户案例主张 | 某装企使用后发生变化 | 授权、脱敏、原始证据 |
| 对比主张 | 装得清与 Excel/传统方式差异 | 同一任务、同一边界 |
| 效果主张 | 节省时间、减少损失、提升利润 | 正式测量和用户授权；无证据禁止 |

## 3. 对外表达文件必须包含

```text
事实等级：
适用装企类型：
前置条件：
可引用证据：
不可承诺事项：
素材授权：
```

## 4. 禁止表达

- “保证、百分百、绝对不会、必然提升、精准算清利润”。
- 没有来源的比例、金额、行业排名和客户数量。
- 把测试数据、演示数据、设计稿或内部原型写成上线事实。
- 把单个客户经验写成行业规律。
- 用功能存在替代任务价值。
- 用大改版、重构或新交互作为卖点。

## 5. 事实冲突

发现冲突时：

1. 停止对外定稿。
2. 记录 `MC-GAP-*`，写清冲突主张、来源和影响素材。
3. 回到业务智能体 `T05`。
4. 收到 `T06/T12` 后再恢复内容。
5. 已被业务变更影响的旧内容标记 `stale`，不得继续复用。

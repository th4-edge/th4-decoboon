# App / Web 使用内容分工

## App 内容优先回答

- 我现在最需要处理什么？
- 这个提醒对应哪个客户/项目/款项？
- 我能否用最少步骤完成当前动作？
- 现场照片、日报、确认、回读是否方便？
- 网络差或接口失败时怎么继续？

App 不承载：

- 把所有模块做成一条长流程。
- 强制查看完整跨项目比较。
- 复杂批量授权、批量对账和长表单铺满。
- 用移动端学习成本换取桌面端复杂度。

## Web 内容优先回答

- 我如何比较多个对象和期间？
- 如何批量筛选、处理、导出和对账？
- 如何查看完整字段、历史、证据和责任链？
- 如何进入模板、组织和权限治理？
- 复杂操作完成后回读什么？

Web 不承载：

- 把 App 的快捷动作改成多步详情。
- 以图表替代业务对象和行动。
- 用大屏重做已有专业工作台。
- 用一次性大改破坏现有菜单和深链。

## 内容写法

- 先写任务，再写端。
- 同一个 task key 在 App/Web 使用同一对象和结果。
- 说明“为什么这里适合 App/Web”，不把端差异说成权限差异。

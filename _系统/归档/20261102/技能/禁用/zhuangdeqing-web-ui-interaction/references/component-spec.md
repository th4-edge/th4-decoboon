# 组件规范（Web）

> 每个组件给出：用途 / 尺寸 / 变体 / 状态 / 禁止。未在此登记的组件不得新增。

## 1. 按钮 Button

| 项 | 规范 |
| --- | --- |
| 高度 | 主 36px；次 32px；表格内 28px |
| 内边距 | 左右 16px（小号 12px） |
| 字号 | 14px / 500 |
| 圆角 | `$radius-sm` |
| 变体 | 主（品牌实心）/ 次（描边）/ 文字 / 危险 |
| 状态 | 默认 / hover / active / focus-visible / loading / disabled |

规则：

- 一个区块只能有一个主按钮。
- 危险操作使用危险色，不用品牌色。
- loading 时禁用并保持宽度不变。
- 图标与文字间距 6–8px；纯图标按钮必须 32×32 且带 `aria-label`。

## 2. 输入类 Input / Select / DatePicker

| 项 | 规范 |
| --- | --- |
| 高度 | 32–36px |
| 字号 | 14px |
| 内边距 | 左右 12px |
| 圆角 | `$radius-sm` |
| 状态 | 默认 / hover / focus / disabled / error / readonly |

规则：

- 标签在上时左对齐，在左时右对齐；同一表单不混用。
- 错误态：危险色边框 + 字段下方 12px 错误文案。
- placeholder 只做示例，不承载必填说明。
- 长选项必须支持搜索。

## 3. 表格 Table

| 项 | 规范 |
| --- | --- |
| 表头高 | 40px，背景 `$surface-100`，字重 600，13px |
| 行高 | 40–44px |
| 单元格内边距 | 左右 12–16px |
| 边框 | 仅横向 1px `$border-light` |
| 状态 | 加载 / 空 / 筛选无结果 / 错误 / 选中 |

规则：

- 表头固定；操作列固定右侧。
- 数字列右对齐 + 等宽数字；状态列用 `StatusTag`。
- 超过 8 列必须有取舍策略；长文本省略并提供完整内容入口。
- 行内操作最多 2 个按钮。

## 4. 卡片 Card

| 项 | 规范 |
| --- | --- |
| 内边距 | 18–20px |
| 边框 | 1px `$border-light` |
| 圆角 | `$radius-md` |
| 阴影 | 默认无；hover 用 `$shadow-card` |
| 标题 | 16px / 600 |

规则：

- 卡片只用于包裹独立信息单元，不用于页面分区（分区用标题 + 间距）。
- 同屏卡片样式必须完全一致。
- 禁止卡片内套卡片超过一层。

## 5. 状态标签 StatusTag

- 尺寸：高 22–24px，左右内边距 8px，圆角 `$radius-xs`。
- 字号 12px / 500；必须同时有色底与文字色。
- 变体：成功 / 警告 / 危险 / 信息 / 中性 / 特殊（AI）。
- 禁止用标签表达数量、计数或纯分类（分类用文字或 `ScopeTag`）。

## 6. 统计卡 StatCard

- 结构：指标名（12px/次要色）+ 数值（28px/750/等宽）+ 环比（12px）+ 口径（12px/辅助色）。
- 数值与单位分离：单位用小一号字号，基线与数值对齐。
- 一行最多 4 张；超过必须分组。
- 必须带口径与 `asOf`，否则不得展示。

## 7. Tab

- 高度 36–40px，字号 14px，选中态用品牌色下划线或文字加重。
- 一屏最多 7 个 Tab；超过使用下拉或分组。
- 切换 Tab 不改变页面骨架与上下文。
- Tab 与路由对应时应保留 URL，可直接分享。

## 8. 工具栏与筛选 Toolbar

- 结构：左侧筛选/搜索，右侧主行动。
- 高度统一 40px 对齐；控件高度一致。
- 筛选超过 3 项收进抽屉；已选条件必须回显并可一键清除。
- 禁止把主行动放在工具栏左侧。

## 9. 分页 Pagination

- 显示：总数、当前范围（如 1–20 / 共 348 条）、页码跳转。
- 默认每页 20 条。
- 切换筛选或排序后回到第 1 页。

## 10. 抽屉 Drawer / 模态 Modal

| 项 | Drawer | Modal |
| --- | --- | --- |
| 宽度 | 400–480 / 560–720 / 640–840px | 400–480px |
| 用途 | 单职责动作、表单、对象查看 | 确认、强阻塞决策 |
| 关闭 | `Esc` + 关闭按钮 + 遮罩（表单类遮罩不关闭） | `Esc` + 关闭按钮 |
| 焦点 | 打开移入，关闭归还 | 同左，且焦点陷阱 |

规则：禁止嵌套；禁止把完整业务页面放进抽屉；标题必须写明对象与动作。

## 11. 空态 EmptyState

- 结构：图标（32–48px）+ 一句业务说明 + 一个下一步按钮。
- 必须区分：真实为空 / 筛选无结果 / 无权限 / 加载失败。
- 禁止只显示"暂无数据"。
- 空态不得占据超过首屏 60% 高度。

## 12. 提示 Alert / Toast

| 类型 | 位置 | 时长 |
| --- | --- | --- |
| 行内提示 | 紧贴相关区块/字段 | 常驻 |
| Toast | 顶部居中或右上 | 成功 2–3s；失败 ≥ 5s 或不自动消失 |
| Alert | 区块顶部 | 常驻直到解决 |

规则：同一时刻只允许一个全局通知；需要用户决策的信息不得用 Toast。

## 13. 时间线 Timeline

- 节点直径 8–10px，连接线 1px。
- 每条包含：时间（12px/辅助）+ 事件（14px）+ 操作人（12px/次要）。
- 倒序排列；关键节点（签约、验收、收款）用语义色突出。

## 14. 步骤条 Steps

- 只用于线性的多步流程，不超过 5 步。
- 当前步骤高亮，已完成用成功色，未开始用中性色。
- 必须有"当前第几步 / 共几步"的文本表达，不能只靠视觉。

## 15. 头像 Avatar

- 尺寸只用 24 / 32 / 40 / 48px；圆形。
- 无图时用姓名首字，背景取品牌浅色。
- 多头像叠加最多显示 4 个 + "+N"。

## 16. 图表 Chart

- 图表标题必须写清口径、周期、`asOf`。
- 一个图表只表达一个结论。
- 必须提供关键数值的文字表达，不只靠图形。
- 成本不完整时不得绘制利润类图表，显示"成本未完整"。

## 17. 骨架屏 Skeleton

- 形状与最终内容一致，避免加载完成后的布局跳动。
- 数量与典型数据量一致（如表格骨架 8 行）。
- 超过 3 秒的加载必须给出文字说明。

## 18. 图标 Icon

- 尺寸只用 16 / 18 / 20 / 24px。
- 统一线性风格，线宽一致。
- 与文字基线对齐；纯图标按钮必须带可访问名称。
- 禁止 emoji、字符箭头（→ ↑）、字符加号作为图标。

# 设计语言法则（Web）

> 本文回答"为什么看起来专业"。所有数值都是硬约束，不是建议。

## 1. 层级：一屏最多三层信息

用户在 3 秒内必须能回答"屏幕上最重要的一件事是什么"。

| 层级 | 作用 | 视觉手段 | 数量上限 |
| --- | --- | --- | --- |
| 第一层 | 结论 / 主指标 / 当前状态 | 最大字号 + 最强字重 + 最强调色 | 1 个 |
| 第二层 | 支撑结论的关键事实 | 中字号 + 常规字重 + 主文本色 | 3–5 个 |
| 第三层 | 说明、口径、时间、次要属性 | 小字号 + 次要文本色 | 不限，但必须明显弱化 |

法则：

- 同一层级的元素必须使用**完全相同的字号、字重、颜色**。差一点点的层级等于没有层级。
- 相邻层级之间的字号差至少 2px，或字重差至少两个档（如 400 → 600）。
- 一屏内出现第四种视觉强调（除主行动、主指标、状态、链接）就是噪声，必须削减。

## 2. 字阶（冻结）

**Web 端只允许这八档字号**（DS-TYPE-001）：

| Token | 值 | 用途 | 字重 |
| --- | --- | --- | --- |
| `$font-display` | 28px | 经营总览主指标 | 750 |
| `$font-h1` | 20px | 页面标题 | 600 |
| `$font-title` | 18px | 区块标题 | 600 |
| `$font-card-title` | 16px | 卡片标题、重要数值 | 600 |
| `$font-body` | 14px | **正文默认**、表格正文、表单值 | 400 |
| `$font-body-sm` | 13px | 密集表格、次要正文、标签 | 400/500 |
| `$font-caption` | 12px | 口径、时间、单位、辅助说明 | 400 |
| `$font-micro` | 11px | **仅限**角标、头像内字母等非阅读文本 | 500 |

硬约束：

- **正文最小 13px**；12px 只用于辅助信息；11px 只用于非阅读性装饰文字。
- **禁止 9px / 9.5px / 10px / 10.5px / 11.5px**。
- 禁止使用 token 之外的字号。
- 中文正文行高 1.5–1.6；标题行高 1.25–1.35；表格行高 1.4。
- 金额、数量、日期一律使用等宽数字（`font-variant-numeric: tabular-nums`）。
- 中文字重只用 400 / 500 / 600 / 700，避免 800+ 造成糊字。

### 反面示例（必须在治理中清除）

```scss
/* 错误：字号碎片化 + 过小 */
.meta { font-size: 9.5px; }
.tag { font-size: 10.5px; }
.name { font-size: 11.5px; }

/* 正确：只用字阶 */
.meta { font-size: $font-caption; }
.tag { font-size: $font-caption; }
.name { font-size: $font-body-sm; }
```

## 3. 颜色：90 / 9 / 1

| 比例 | 用途 | 颜色 |
| --- | --- | --- |
| 90% | 中性底色与文本 | `$surface-*` / `$ink-*` / `$line-*` |
| 9% | 品牌结构 | `$brand-*`（导航、主行动、选中、强调条） |
| 1% | 语义信号 | `$success/warning/danger/info/purple-*` |

法则：

- **一个页面只允许一个品牌强调色**。禁止在一个页面里混用青绿与蓝/紫作为同等强调。
- 语义色只表达业务语义，不得用于装饰。
- 状态同时用文字 + 颜色 + 图标 + 位置表达，禁止仅颜色区分。
- 禁止硬编码颜色；只允许引用 `tokens.scss` 变量。
- **已废弃的冷灰蓝调色板禁止新增**：`#8d98a5` `#25313d` `#778390` `#465260` `#17212b` `#66717e` `#eef2f4` `#fbfcfd` `#aeb8c2`。
- 一个页面使用的颜色总数（含语义色）不超过 8 种。

## 4. 间距：4px 基准节奏

| Token | 值 | 用途 |
| --- | --- | --- |
| `$space-1` | 4px | 图标与文字、标签内边距 |
| `$space-2` | 8px | 紧密关联元素、表单标签与控件 |
| `$space-3` | 12px | 同组元素、表单项之间 |
| `$space-4` | 16px | 卡片内边距、区块内元素 |
| `$space-5` | 20px | 卡片内边距（大） |
| `$space-6` | 24px | 页面左右留白、区块间距 |
| `$space-8` | 32px | 大区块分隔 |
| `$space-10` | 40px | 页面底部留白 |

法则：

- 所有间距必须是 4 的倍数；禁止 5px / 7px / 9px / 10px / 14px 等随意值。
- **间距传达关系**：相关元素用 8–12px，不相关元素用 24–32px。间距必须比"组内间距"明显更大才能区分分组。
- 卡片内边距统一 18–20px；卡片之间统一 16px。
- 页面左右留白 ≥ 20px，底部留白 ≥ 32px。
- 一屏内的不同间距值不超过 4 种。

## 5. 对齐与栅格

- 页面主体使用 12 列栅格，列间距 16–24px。
- **所有左边缘必须对齐到同一条线**；表格、卡片标题、表单标签都不例外。
- 数字右对齐，文本左对齐；金额列必须右对齐并使用等宽数字。
- 表单标签与控件：标签在左时右对齐，标签在上时左对齐；**同一表单内不得混用两种**。
- 禁止元素居中摆放（除空态、确认弹窗、登录页等明确居中场景）。
- 禁止"看起来差不多"的错位：1–2px 的偏移比 20px 的偏移更显业余。

## 6. 层级深度：边框优先，阴影次之

| 元素 | 手段 |
| --- | --- |
| 普通卡片 | 1px 边框 `$border-light` + 白底 + 无阴影 |
| 卡片 hover | `$shadow-card` + 边框加深 + `translateY(-1px)` |
| 浮层（抽屉/弹层/下拉） | `$shadow-elevated` |
| 页面区块分隔 | 间距或 1px 分隔线，不用阴影 |

法则：

- **禁止阴影堆叠**：同一视口内出现 3 个以上带阴影元素即为层级混乱。
- 禁止渐变作为装饰背景；只允许在品牌头部等少数明确场景使用。
- 禁止用色块边框强调所有卡片；强调只给当前选中或被风险标记的对象。

## 7. 密度：三类页面三档行高

| 页面类型 | 表格行高 | 卡片内边距 | 区块间距 |
| --- | --- | --- | --- |
| 经营决策页 | — | 20–24px | 24–32px |
| 岗位工作台 | 44px | 18–20px | 16–20px |
| 专业列表页 | 40px | 16–18px | 16px |
| 对象详情页 | 44px | 18–20px | 20–24px |

法则：

- 密度不是"塞更多"，而是"在可读前提下减少滚动"。
- 高密度页面必须保证行高 ≥ 40px，否则改用卡片或减少列。
- 同一页面不得混用多种行高。

## 8. 圆角与图标

- 圆角只用 `$radius-xs 4 / $radius-sm 8 / $radius-md 12 / $radius-lg 16 / $radius-pill 999`；禁止 7px / 9px / 10px / 11px 等裸值。
- 同类元素圆角必须一致：同为卡片就用同一个值。
- 图标尺寸只用 16 / 18 / 20 / 24px，与相邻文字形成视觉平衡。
- 图标风格必须统一（同一套线性图标）；禁止混用 emoji、字符箭头、实心与线性图标。

## 9. 图片与头像

- 头像统一为圆形，尺寸只用 24 / 32 / 40 / 48px。
- 无头像时使用姓名首字，不得使用随机插图。
- 品牌 Logo 只能使用 `BrandLogo` 组件，不得另存图片。
- 空状态插图必须克制：优先使用图标 + 文案，不使用大型插画占据首屏。

## 10. 判断"专业"的三个快速自检

1. 把页面截图缩到 25%，还能看出层级吗？看不出说明层级不够。
2. 把页面截图转成灰度，还能区分状态和主次吗？不能说明过度依赖颜色。
3. 遮住所有文字，只剩色块和线条，布局还整齐吗？不整齐说明对齐和节奏有问题。

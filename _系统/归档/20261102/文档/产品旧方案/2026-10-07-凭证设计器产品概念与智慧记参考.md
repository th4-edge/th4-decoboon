# 凭证设计器产品概念与智慧记参考

> 状态：产品概念冻结草案
> 日期：2026-10-07
> 适用：Web、App、Backend、PDF Renderer
> 目标：把“凭证模板参数配置”升级为中小装企可使用的 Excel 式凭证设计器

> 当前实施进度（2026-10-07）：D1 `designerConfig` 后端持久化、版本快照和 Web/App 契约已完成；产品级四区设计器原型已产出；D2 Web 高级设计器第一版已接入：四区画布、字段库、文本/字段/表格/图片/二维码/签字元素、拖动、缩放、属性面板、边框和表格列配置；任意坐标 PDF 落版和精细合并仍待继续。

## 1. 概念纠正

此前把该能力称为“凭证模板”，容易把它理解成字段显隐和参数配置。正确概念应为：

> **凭证设计器：企业以 Excel/表格排版为心智，自行设计和打印业务凭证的可视化设计器。**

“模板”只是设计器保存的产物；“layoutConfig”只是设计器输出的一种受控布局模型。

当前已实现的纸张、方向、页边距、区块顺序等功能，只能定义为：

> **快速版式模式或基础版式配置，不是完整凭证设计器。**

## 2. 智慧记官方教程提供的真实参考

官方帮助文档：https://www.zhihuiji.cn/help/doc/3199

智慧记的打印模板功能明确具备以下模型：

1. 选择需要修改的单据模板。
2. 白色画布就是打印内容。
3. 可以删除文本框、删除表格字段和多余表格线。
4. 可以新增文本框，拖动并调整大小。
5. 文本区分“固定文本”和“活动文本”。
6. 可以绘制表格线，缩小或调整其他列宽度，再增加表格内容。
7. 可以插入图片。
8. 可以调整字体、居中、列间距、表格位置。
9. 可以控制每页打印行数。
10. 可以调整打印边界黑线，使内容落在纸张范围内。
11. 可以控制只在最后一页打印页脚。
12. 可以通过预览调整版式，再打印或备份模板。

这说明智慧记的核心交互是：

```text
直接选择元素 -> 拖动/缩放 -> 修改属性 -> 绘制边框 -> 预览 -> 打印
```

它不是：

```text
勾选字段 -> 调整几个全局参数 -> 自动排版
```

## 3. 装得清应采用的凭证设计器概念

采用三层模型：

```text
基础版式
  -> 凭证设计器
  -> 版本快照
  -> PDF 渲染器
```

- 基础版式：行业常用模板，企业只读。
- 凭证设计器：企业复制基础版式后自由编辑。
- 版本快照：发布后不可变。
- PDF 渲染器：与设计器共用同一布局模型，确保预览和打印一致。

## 4. 产品级页面构图

凭证设计器采用“四区”结构：

```text
┌────────────────────────────────────────────────────────────┐
│ 顶部工具栏：撤销/重做、复制、删除、合并、边框、对齐、预览、发布 │
├──────────────┬───────────────────────────────┬─────────────┤
│ 左侧字段库    │ 中央设计画布                  │ 右侧属性面板 │
│ 固定文本      │ 纸张边界、打印边界、网格、标尺 │ 字体/对齐   │
│ 活动字段      │ 可选中文本框、表格、图片       │ 边框/底色   │
│ 表格列        │ 拖拽、缩放、合并、行高列高      │ 行高/列宽   │
│ 图片/签字/章印│ 表格线和打印区域              │ 数据绑定    │
├──────────────┴───────────────────────────────┴─────────────┤
│ 底部状态：页码、缩放、每页行数、打印预览、错误与占位符提示     │
└────────────────────────────────────────────────────────────┘
```

## 5. 设计器元素

### 固定文本

- 企业名称、标题、说明、页脚、签字栏文字。
- 可拖动、缩放、换行、对齐。
- 不属于数据字段。

### 活动字段

- 客户、项目、合同、金额、日期、账户、对方等。
- 必须绑定服务端字段。
- 支持显示名、格式、脱敏和条件显隐。

### 表格

- 明细行、来源单号、日期、数量、金额、备注。
- 支持列宽、列顺序、显示/隐藏、列标题。
- 支持表头重复、每页行数、明细行高。
- 支持合并单元格。
- 支持表格线、四边框、行下边线。

### 图片

- 企业 Logo、活动图片、二维码。
- 支持位置、尺寸、缩放比例。
- 底图和坐标套打进入 L3。

### 签字/印章

- 制单、审核、领款、收款人。
- 支持固定文本、空白线、签名图片位、电子印章位。

## 7. 渲染器原则

- 设计器画布和 PDF 渲染器必须使用同一份布局模型。
- 禁止 Web 预览一套算法、后端 PDF 一套算法。
- 后端负责最终渲染、文件哈希、版本快照和重打。
- 预览可复用 Web 渲染器，但保存发行必须以后端 PDF 为准。
- 支持分页、表头重复、每页行数、合并单元格和边框绘制。
- 字段缺失时按类型留空或提示，不能伪造数据。

## 8. 智慧记可借鉴、不可直接照搬

### 可以借鉴

- 白纸画布心智；
- 文本框拖动和缩放；
- 活动字段与固定文本；
- 表格线绘制；
- 列宽、行高和合并单元格；
- 图片和二维码；
- 每页行数；
- 打印边界；
- 最后一页页脚；
- 模板备份和版本。

### 不应照搬

- 智慧记面向进销存和货品销售，字段模型完全不同；
- 装得清必须绑定装修项目、合同、收款、付款、工资、材料和质保金；
- 装得清金额、成本和敏感字段受权限控制；
- 装得清不做任意数据库字段和 SQL 绑定；
- 装得清必须保证历史凭证版本不可变；
- 装得清不能把会计凭证混入业务凭证设计器。

## 9. 分阶段实施

### D1 设计模型与渲染底座

- 新增 `VoucherDesign` 布局模型；
- 页面、网格、行列、单元格、表格、边框；
- PDF 渲染器支持单元格和边框；
- 保留旧 `layoutConfig` 作为兼容快速模式。

### D2 Web 设计器

- 四区布局；
- 元素选中、拖动、缩放；
- 字体、对齐、边框、底色、行高列宽；
- 合并/拆分单元格；
- 表格列管理；
- 预览和打印边界；
- 草稿、发布、版本。

### D3 App 轻量设计器

- 纸张、方向、页边距；
- 文本和字段显隐；
- 区块顺序；
- 预览和打印；
- 复杂设计提示到 Web 完成。

### D4 L3 套打

- 上传背景底图；
- 坐标绑定；
- 打印偏移和缩放；
- 预印纸对位。

## 10. 当前实现的处置

现有 `layoutConfig`、区块顺序、纸张、方向、页边距、签字栏、页脚说明保留：

- 作为“快速版式模式”；
- 作为基础模板到高级设计器的兼容入口；
- 不删除，不覆盖正式设计器模型；
- 正式产品页面统一命名为“凭证设计器”；
- “模板”只表示设计结果和版本。

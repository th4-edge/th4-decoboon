# 手工记账分类说明自定义与装企维护设计

> 状态：BIZ_DECIDED / 可研发使用
> 用户裁决：2026-10-07
> 关联知识：`DEC-039`、`BR-034`、`ANS-BIZ-20261007-025`、`T12-BIZ-20261007-008`
> 边界：本设计属于经营管理账，不涉及会计科目、借贷分录、总账或税务申报。

## 1. 目标

装企在手工记账时使用“标准分类 + 企业自定义分类 + 分类说明”，让后续员工按统一口径选择分类，减少自由文本导致的记账偏差。

## 2. 范围

- 分类对象：`LedgerCategory`。
- 流水对象：`Ledger`。
- 方向：收入、支出。
- 层级：只有一级，不存在一级/二级父子结构。
- 维护角色：Boss、Finance。
- 选择角色：按既有财务读取/记账权限。
- 不改变：金额、成本、利润、现金流、项目收入/成本公式。

## 3. 分类模型

每个分类包含：

| 字段 | 规则 |
| --- | --- |
| name | 分类名称，最多 64 字符 |
| description | 分类说明，1–500 字符；平台默认/企业可维护 |
| direction | Income / Expense |
| builtIn | 平台内置分类 |
| active | 是否启用 |
| code | 内置稳定编码；自定义为空 |
| sort | 显示排序 |

分类没有父子层级；`parentId` 只允许兼容历史数据，新分类创建时拒绝。

## 4. 标准分类与企业自定义

- 平台内置其他账务一级分类：企业可按当前企业管理名称和说明，也可停用。
- 企业自定义分类：Boss/Finance 可新增一级分类、改名、改说明、停用。
- 不允许新增二级分类；旧两级分类不进入新记账选择器。
- 新建自定义分类必须填写名称和分类说明。
- 分类说明只影响当前企业；平台模板升级只补种缺失分类和空说明，不覆盖企业修改。
- 历史流水保留 `category` 名称快照和 `category_id`；分类说明修改不回写历史流水。
- 本轮不新增流水级分类说明快照。

## 5. App/Web 记账交互

```text
选择收支方向
-> 选择一级其他账务分类
-> 表单回显只读分类说明
-> 填写摘要、金额、账户、日期、项目等
-> 服务端校验分类、方向、企业、手工记账边界
```

- App：手工记账的“分类说明”从自由文本改为一级分类选择入口；Boss/Finance 可在分类页新增/编辑一级分类和说明。
- Web：分类树节点展示分类说明；Boss/Finance 可在分类选择器内维护分类。
- 摘要和备注仍记录每笔业务事实；分类说明是选择指引，不代替摘要。
- 所有分类都是一级，直接选择记账；不存在一级分组或二级分类。
- 工程款、材料款、工资、项目款等仍由 `ManualLedgerContext` 禁止手工登记。

## 6. 数据与迁移

新增迁移：`docs/design/migrations/89-手工记账分类说明.sql`

- `db_finance_ledger_category` 新增 `description varchar(500) null`。
- 既有分类保留；内置分类空说明由应用层幂等回填。
- 不增加 `db_finance_ledger` 字段。

## 7. 接口

- `finance/ledger-category/tree`：返回 description。
- `finance/ledger-category/save`：接收 name、description、direction；不接收 parentId，出现 parentId 直接拒绝。
- `finance/ledger-category/update`：接收 categoryId、name、description、active。
- `finance/ledger-category/delete`：保持逻辑停用。
- `finance/ledger/save|update|correct`：继续接收 categoryId 与 category 文本快照。

## 8. 验收

- 正向：新增带说明的自定义分类，App/Web 可选并回显说明。
- 正向：企业修改标准其他账务一级分类说明，仅当前企业生效。
- 正向：模板升级不覆盖企业改名和说明。
- 反向：无说明自定义分类不能创建；二级分类或 parentId 被拒绝；停用、跨企业、方向错误分类拒绝。
- 反向：工程款、材料款、工资、项目款手工记账仍拒绝。
- 历史：旧文本分类可查看，不静默匹配、不批量改写。
- 一致性：App/Web/台账/项目财务回读一致。

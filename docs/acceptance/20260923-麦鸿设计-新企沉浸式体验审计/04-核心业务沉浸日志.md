## 实际 UI 写入证据

### 业务员新增跟进

- 页面：`subpackages/customer/pages/follow`
- 动作：输入文本后点击“保存跟进”
- 页面结果：立即显示新跟进，跟进方式为“微信”
- 数据库结果：生成对应测试记录
- 证据：`raw/accessibility/S04-follow-ui-write.json`
- 说明：本次为复核执行两次，因此留下两条相同测试记录，不计为产品重复提交缺陷。

### 项目经理交接

- 页面：`subpackages/project/pages/members`
- 动作：在项目经理选择器中点击徐勇
- 页面结果：项目经理从张伟切换为徐勇，团队成员和岗位同步刷新
- 数据库结果：`db_project.manager_id` 更新为徐勇
- 证据：`raw/accessibility/S06-pm-handoff.json`
- 后续结果：徐勇登录后首页出现 1 个在管项目、3 个待推进任务、1 个待确认验收。

### 项目计划页签

- 页面：项目详情
- 动作：点击“计划”
- 结果：显示 8 个施工阶段、起止日期和阶段状态。
- 证据：`raw/scripts/ui_project_tab_probe.js` 输出及对应截图。

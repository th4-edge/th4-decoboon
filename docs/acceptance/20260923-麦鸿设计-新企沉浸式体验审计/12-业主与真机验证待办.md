# 业主与真机验证待办

## 为什么还不能自动完成

微信开发者工具不能替代以下真实验证：

- 独立微信账号登录并授权手机号。
- 相机、相册和文件选择。
- 业主本人进入“我的家”并确认验收。
- 多微信并发协作与消息提醒。

因此采购付款和员工页面已可在本地完成，但业主端和真机上传必须扫码后在手机微信中继续。

## 需要用户提供

1. 一个员工测试微信对应的手机号，用于接受项目经理/设计师邀请并测试现场照片上传。
2. 一个独立业主测试微信对应的手机号，用于接受业主邀请并完成阶段验收。
3. 两个手机与 Mac 处于可互通的局域网，能访问 `192.168.0.101:8091`。
4. 明确授权创建本地测试邀请和不涉及真实资金的本地测试记录。

## 员工真机上传步骤

1. 在本地测试库创建项目经理邀请，手机号使用用户提供的员工测试号。
2. 生成微信开发者工具预览二维码。
3. 用户用员工测试微信扫码打开小程序并授权手机号。
4. 接受邀请并进入麦鸿设计项目。
5. 在项目详情报师附件中调用相机或相册上传测试照片。
6. 核对页面是否显示照片、数据库/文件对象是否记录、OSS/local 文件是否能读取。
7. 记录上传耗时、失败重试、签名访问和异常提示。

## 业主验收步骤

1. 由负责人通过项目邀请页创建业主邀请，手机号使用用户提供的业主测试号。
2. 设置预览入口为带 `inviteId`/`token` 的业主接受页。
3. 业主测试微信扫码、授权手机号、进入“我的家”。
4. 查看项目阶段、施工动态、验收信息和金额边界。
5. 对“开工交底”验收进行确认、驳回或整改后的再次确认。
6. 员工端核对阶段是否推进、验收记录是否追加、消息是否正确通知。
7. 验证业主不能看到成本、利润、内部采购或无关项目。

## 需要特别观察

- 本地 API 地址在手机上是否可达。
- 微信授权手机号是否与邀请手机号严格匹配。
- 相机/相册上传是否成功，图片是否可长期读取。
- 业主确认是否只改变质量验收事实，不改变合同、金额、应收或成本。
- 驳回后的轮次、整改证据和再次确认是否完整保留。
- 两个微信同时操作时，消息、待办和项目可见性是否一致。

## 3. 发版顺序

1. 冻结 commit，构建后端 release 归档并校验 `SHA256SUMS`。
2. 备份生产数据库、私有文件和公开文件，验证备份可读。
3. 审计 `db_schema_migration`；在隔离 MySQL 按 55→59 顺序演练。
4. 应用增量迁移：55、56、57、58、59。
5. `scripts/deploy-prod.sh --release-dir <dist/releases/...>` 发布后端，健康检查失败自动回滚。
6. 小程序上传体验版，确认 `VITE_API_BASE` 为生产 HTTPS、协议版本和类目合规。
7. 用业主、设计师、项目经理、财务四角色做发布后冒烟。

# 新企冷启动体验日志

本次主模式为全角色业务闭环，不是从 0 开始的首次入驻体验。企业、员工和报价库属于受控夹具初始化，业务数据通过 Provider 产生。

## 初始化观察

- 空库后可以通过空库基线和当前代码生成可运行的完整结构。
- 独立 Password 员工凭证可稳定切换 8 个角色。
- 报价项目库能够导入并供设计报价使用。
- 旧导入脚本在新空库存在分页去重和套餐模板保存问题，详见 BUG 台账。
- 企业初始页面在报价项目导入前没有报价基础数据；导入后 Boss、设计师和报价工作台可读取。

## 结论

新企初始化主链 `INITIALIZED`；报价项目库 `PASS`；套餐模板自动导入 `FAIL`；首次微信注册/真实邀请未测试。

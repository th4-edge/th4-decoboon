## XA-20260924-001 · 业务员可越权新增设计

- 真实用户目标：业务员只应在设计交接后只读查看设计和报价。
- 最小复现：以黄贤杰 token 调用 `design/scheme/save`，提交合法客户和房屋，接口返回成功并创建 `Draft` 设计。
- 期望：403 或业务权限错误，不落库。
- 实际：成功落库；测试记录已清理。
- 影响：越权写入、版本数污染、设计责任混乱。
- 根因候选：`design/service/schemes/save/support/Save.java` 只校验企业和客户可见性，没有按 `edit:design` 或设计参与人校验。
- 建议：在 Provider/Context 层加入角色和项目/客户授权校验，并补负向测试。
- 验收：业务员、PM、财务均无法新增设计；设计师和 Boss/店长按业务边界可新增。

## XA-20260924-002 · 默认施工任务负责人错误

- 最小复现：项目由王昌富负责，默认合同施工任务创建后打开任务详情。
- 期望：负责人为项目经理王昌富或明确的任务执行人。
- 实际：负责人显示黄贤杰（业务员），24/24 默认任务均如此。
- 影响：项目经理工作台责任失真，任务分派和绩效归因错误。
- 根因：`ProjectContext.appendConstruction` 使用 `ProjectPermissionContext.apply(task, project)`，把房屋经营 owner 写入任务 `owner`，任务模型该字段语义是“任务负责人”。
- 建议：拆分经营 owner 与任务负责人；默认任务负责人优先取 `project.manager`。
- 验收：新建项目默认任务负责人为 PM，业务员不显示为施工负责人；历史数据有迁移策略。

## XA-20260924-003/004 · 初始化脚本缺陷

- 报价分页：脚本按 200 请求，但 Provider 第一页只返回 100；重复执行时未覆盖全部已有项，最终出现 122 条重复。已受控去重回 550 条唯一项。
- 套餐保存：套餐模板创建后，在 `pack/line/save` 抛出 `orphan deletion / PackageTemplate.items` 异常，留下空套餐和无分项模板。已清理空模板，未将其作为成功初始化。
- 建议：修复分页遍历和套餐集合初始化；补空库导入幂等回归。

## XA-20260924-005 · 成本拆分歧义

- 实际：项目 44 API 返回 `totalCost=30047.40`、`profitAmount=-13889.67`，但 `materialCost/laborCost/projectCost/expenseAllocation` 均为 0。
- 解释：总成本取预计/实际成本，分项当前只统计应付实际成本；公式本身在代码中有注释，但页面没有解释。
- 影响：经营者会误以为金额算错。
- 建议：拆分“预计/实际总成本”和“已发生应付成本”，或增加口径说明。

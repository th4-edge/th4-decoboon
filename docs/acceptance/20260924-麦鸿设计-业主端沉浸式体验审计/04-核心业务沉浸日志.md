## 场景 1｜业主第一次打开小程序（冷启动）

| 步 | 我（业主）想的/做的 | 系统表现 | 证据 |
|---|---|---|---|
| 1 | 打开小程序，看到「装得清 / 装企数字化协同管理平台」+ 微信登录 | 首屏即登录页，只有一个主按钮「微信登录」；下方协议勾选 | `01-登录页-初始.png` |
| 2 | 直接点登录 | **被拦**：必须先勾选《用户协议》《隐私政策》 | `02-登录页-已勾选协议.png` |

**体验判断**：登录路径短、无多余表单 ✅；但**登录页没有任何"我是业主，怎么看我家工地"的引导**，业主首次可能不知道这是给装修公司员工的系统还是给自己的（文案偏 B 端："装企数字化协同管理平台"）。

## 场景 2｜业主看"我的家"整体（装修进行到哪了）

- 项目详情首屏：项目名/编号、**待验收**、整体进度 0%、`当前： · 阶段 0/8`、开工 09-15、计划 12-19、8 个施工阶段与计划区间、合同履约档案（¥5,274 / 2026-09-21 / 计划工期）
- 判断：**阶段排期与合同金额一眼可见** ✅；但「当前阶段」为空 + 状态"待验收"（见 XA-001/003），业主会困惑"到底开没开工"。

## 场景 3｜业主核对量房（交房原样有没有留痕）

- 「我的家 · 量房档案」：`1 量房记录 / 1 现场照片 / 09-10 05:03 最近量房`；记录卡含**量房设计师 谢玲玲、原始结构、尺寸记录、需求、结论**
- 判断：**四要素齐全，可直接与设计师对话** ✅ 这是业主端最有价值的一页之一。

## 场景 4｜业主看设计（给我家做成什么样）

- 「我的家 · 设计方案」：状态"待谈单"、方案 V1、**设计风格 奶油风 / 套内面积 50.54㎡ / 户型 三室两厅一厨一卫**、区域尺寸、区域设计内容
- 判断：信息结构清晰 ✅；但**"暂无设计图纸"**（无 CAD/效果图），业主看不到"长什么样"，只能看文字。

## 场景 5｜业主看报价（要花多少钱、钱花在哪）

- 「我的家 · 报价清单」：`已转项目`、`¥5,274`、`Q1790110987701 · 客户报价 V3`、**清单小计 ¥5,344元 / 折扣 0.94 / 税金 ¥251元 / 报价总额 ¥5,274元**、`共 3 个区域 · 6 个清单项`、按区域查看报价
- 判断：**金额链完整可核对** ✅（含折扣与税金），且按区域展开符合业主核对习惯。

## 场景 6｜业主看选材（用了什么材料）

- 「我的家 · 选材记录」：`已到场`、`材料计划 1 项，已到场 1 项`、`V1 选材版本 / 已确认 选材状态`、`沉浸审计主材选材确认`、数量 30
- 判断：选材结果与到场状态可分 ✅。

## 场景 7｜业主看增减项（有没有偷偷加钱）

- 「我的家 · 增减项」：`暂无变更`、`0 变更总数 / 0 待确认 / ¥0 已确认金额`
- 判断：**空态文案解释了规则**（"都会形成正式增减项单并请您确认后再执行"）✅ 这是很有价值的一句承诺式文案。

## 场景 8｜业主验收与整改（重点）

- 「我的家 · 验收整改」：`整改中 1 个阶段待整改`、`0 待确认 / 1 整改中 / 0 已确认`、`2026-09-26 还差 2 天 最近整改截止`、**阶段验收单 · 开工交底 · 已驳回 · 2026-09-23 13:41 · 整改截止**
- 判断：**"还差 2 天"这类相对时间非常有用** ✅（业主不用算日子）；明细也能看到是哪张验收单被驳回 ✅
- 但**与项目状态"待验收"矛盾**（XA-001），且页面上没有"我要复验/我要确认"的动作入口（业主只能看到结论，无法推进下一步）。

## 场景 9｜业主看付款（什么时候要交钱）

- 「我的家 · 付款计划」：`待付款`、`已付 474.69，待付 4799.64`、`¥5,274 应付总额 / ¥475 已付 / ¥4,800 待付`、下一节点横向卡：`合同签约款 / 2026-09-23 / 已逾期 1 天 / 待付 ¥1,582元`
- 判断：**业主口径（已付/待付）+ 逾期提示 + 下一节点卡片** ✅ 是业主端最"省心"的一页。

## 场景 10｜业主看合同（我签的是什么）

- 「我的家 · 合同」：`已生效 · C1790110988926`、`¥5,274 签约金额 / ¥5,274 当前金额 / 2026-09-21 签约日期 / 合同履约额度 ¥5,274`
- 判断：日期已收敛（无 ISO）✅。

## 场景 11｜业主回看工地照片（留证据）

- 「工地相册」：`共 2 条记录 · 2 张照片`、`昨天 2026-09-23 / 开工交底 / 张伟 企业负责人 / 阶段开工 05:03 / 阶段开工 · 开工交底`、`验收 · 已驳回 / 开工交底验收单`
- 判断：**按"日期 → 阶段"归档 + 落款人** ✅ 符合"履约证据链"的定位。

## 场景 12｜业主提意见

- 「我的意见与投诉」：`及时反馈、受理、处理和确认`、1 条记录（标题/内容为测试串）、`处理人：徐勇 / 承诺：2026-09-26 14:08:14 / 提交：2026-09-23 14:08:14`
- 判断：**有处理人 + 承诺时间** ✅ 这是业主端少见的"服务承诺"表达；但测试数据需清理（XA-005）。

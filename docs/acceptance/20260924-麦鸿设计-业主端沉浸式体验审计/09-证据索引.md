## 复现命令

```bash
# 1) 起后端（需本地 MySQL/Redis）
cd <backend> && set -a && . ./.env.dev.local && set +a && bash run-dev.sh
# 2) 打开小程序项目 + 开启自动化
/Applications/wechatwebdevtools.app/Contents/MacOS/cli open  --project <app>/dist/dev/mp-weixin
/Applications/wechatwebdevtools.app/Contents/MacOS/cli auto --project <app>/dist/dev/mp-weixin --auto-port 9420 --trust-project
# 3) 登录（业主）
node <run>/raw/login2.cjs
# 4) 遍历业主端并采集
node <run>/raw/walk3.cjs
```

# 问题与整改建议

## XA-20261004-001 PM 手工新建任务失败

- 严重度：P1 / BUG
- 用户目标：项目经理在项目详情或阶段详情新增施工任务。
- 最小复现：PM 登录 -> 项目详情 -> 新建任务 -> 填名称/内容/负责人 -> 保存任务。
- 期望：任务保存并回显在项目任务列表。
- 实际：停留编辑页，未落库；后端返回“工艺任务不能为空”。
- 根因证据：`Save.java` 新建任务必须有 `catalogItem`，UI `task/edit.vue` 没有 `catalogId` 选择。
- 建议：恢复工艺目录选择，或在进入页面时要求从目录项预填 `catalogId`；无 `catalogId` 时前端明确阻止并引导到目录选任务。
- 正向验收：PM 能新建一条目录任务并看到负责人、阶段和数量。
- 反向验收：不在目录项的任意文本任务不得绕过后端；错误提示可理解。

## XA-20261004-002 无权限深链打开财务页

- 严重度：P2 / SEC
- 最小复现：Marketer 登录后直接打开 `/subpackages/finance/pages/ledger`。
- 实际：页面打开，接口 403 后显示“资金台账加载失败 / 当前账号无权执行该操作”。
- 影响：路由层未阻断，产生错误页且破坏三层权限一致性；无数据泄露。
- 建议：页面 `onLoad` 增加 capability 校验并返回首页/无权限页；补深链/冷启动测试。

## XA-20261004-003 TeamLeader 未绑定团队时空态不统一

- 严重度：P2 / UX
- 实际：首页明确“当前账号尚未绑定团队”，但团队派单、团队成员、团队业绩显示“加载失败”。
- 建议：统一为可恢复空态，给出“联系店长/负责人安装团队”的下一步。

## XA-20261004-004 选材客户确认缺少业主身份证明

- 严重度：P2 / GAP
- 观察：设计师/管理者可填写 `confirmerName` 后代录客户确认；未执行员工代确认动作。
- 建议：产品明确文本确认记录与业主本人电子确认的区别；若要对客户承诺，需要独立业主身份链路。

## 建议顺序

1. 修复 XA-001，恢复 PM 手工任务创建。
2. 修复 XA-002，统一深链权限守卫。
3. 修复 XA-003，统一 TeamLeader 空态。
4. 与业务裁决 XA-004，再决定选材确认的业主链路。

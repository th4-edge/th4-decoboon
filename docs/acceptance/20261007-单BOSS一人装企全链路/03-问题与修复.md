# 问题与修复

## SB-FIX-001 Web 工资文案仍绑定财务制单

- 现象：同一 BOSS 已完成工资全链，但页面仍显示“财务生成工资单”。
- 风险：与 `DEC-032` 的 BOSS 内部能力超集冲突，单人装企误以为必须邀请财务。
- 处理：改为“具备薪酬权限的账号生成工资单并由 BOSS 确认；单人企业可由 BOSS 依次完成生成、确认和发放”。

## SB-FIX-002 未释放提成发放文案不精确

- 现象：未回款时发放被正确拒绝，但错误提示为“发放金额不能超过员工应付未付金额”。
- 风险：用户无法判断是应付余额不足，还是提成尚未释放。
- 处理：员工提成批次改为“发放金额不能超过已释放且未发放的提成金额”。

## SB-FIX-003 旧会话并发回退与构建互相污染

- 现象：旧会话在后台执行 `git checkout --`，同时运行独立 Maven 测试，导致 `target/classes` 在测试期间被改写，出现类不存在。
- 风险：测试结果失真，并可能回退当前工作区未提交修改。
- 处理：终止旧会话；恢复 `PayableRepository.findByCompany_ComIdAndSourceTypeAndSourceId`；使用 Java 23 完成定向回归。

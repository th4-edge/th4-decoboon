## 问题详情

### XA-20261007-001 薪酬工作台周期切换入口

- 类别：UX
- 严重度：P3
- 状态：VERIFIED
- 发现角色与页面：Boss / `subpackages/payroll/pages/workbench`
- 用户目标：查看最近一次已发放工资和提成的结果。
- 最小复现：进入员工薪酬工作台，当前周期为 2026-10；历史工资单在 2027-01，工作台当前周期摘要显示 0。
- 期望结果：提供明确的“查看工资单/切换周期”入口，或显示最近一次有工资事实的周期。
- 实际结果：需要进入“工资单”列表才能看到 2027-01 数据。
- 影响：不阻断发放，但会让用户误以为没有工资记录。
- 频率：当前周期无工资、历史周期有工资时。
- 证据：`S25-workbench-latest-hint`、`S26-workbench-period-switch`、`S27-latest-sheet-link`、`S28-all-salary-sheets-entry`。
- 置信度：high
- 建议整改：在薪酬工作台标题旁增加“工资单历史/切换周期”入口，或在当前周期为零时显示最近一次已发生工资周期。
- 正向验收：从工作台一步可达最近工资周期。
- 反向验收：不得用 0 伪装历史工资不存在。
- 责任建议：App 产品/前端。
- 依赖/待确认：无需新增后端业务字段；本轮接口已返回最近工资单投影。

## Web 走查

分辨率：

- 1440x900
- 1280x800
- 1024x768

结果：

| 页面 | 1440x900 | 1280x800 | 1024x768 | 观察 |
| --- | --- | --- | --- | --- |
| 客户退款 | PASS | PASS | PASS | 无页面横向溢出，KPI 与表格完整 |
| 退款登记抽屉 | PASS | PASS | PASS | 1024 下抽屉宽 720，左右无溢出，底部按钮完整 |
| 提成负向调整 | PASS | PASS | PASS | 无页面横向溢出，金额、状态、说明完整 |

量测：

- 三种宽度下 `documentElement.scrollWidth` 均等于 viewport 宽度。
- 1024 下退款抽屉 `x=304,width=720,right=1024`，底部操作区完整。
- 键盘 Tab 可进入财务导航按钮，焦点顺序可见。

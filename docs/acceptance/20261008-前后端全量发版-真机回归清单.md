### R2 合同签约角色分离（DEC-040）

| 步骤 | 预期 | 反向/边界 |

## 3. 反向 / 越权 / 幂等 / 边界

1. **越权**：设计师/业务员/PM/财务调用“确认签约/确认生效”返回 403；PM/设计师调用增减项审批返回 403；PM 调用采购审批/下单返回 403。
2. **数据范围**：跨企业/跨门店/跨团队伪造 ID 返回无权限或空，不泄露对象存在性；客户只看自己项目。
3. **幂等**：重复确认签约、重复生效、重复客户确认、重复采购下单、重复收款均不产生第二份数据。
4. **金额红线**：变更后合同额 < 0 拒绝；减项超过未收应收余额拒绝；成本不完整利润/毛利率为 null。
5. **状态红线**：已生效增减项不可编辑/撤回；已下单材料不可改选材；已完工/已结算项目不可发起增减项。
6. **DDL 回归**：生产 SQL 核验迁移 90 的 8 个索引与迁移 91 的两列存在，账本 90/91 SUCCESS。

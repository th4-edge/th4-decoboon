# 执行计划与授权

- 模式：全角色业务闭环模式 · 财务分类最小切片
- 环境：local-dev；仅本地 `decoboon` 数据库，不连接生产。
- 企业：昭青装饰（`comId=1790000000000000001`）。
- 授权范围：本地开发库创建测试分类、编辑测试分类说明、登记小额测试手工流水；通过微信开发者工具真实页面操作。

- 验收目标：分类说明可维护、App 可选择、选择后回显说明、手工流水可保存并由数据库复核。

## 问题详情

### XA-20261007-001 分类选择器仍把闭环分类展示为可选择

- 最小复现：打开手工记账分类选择器，工程款、材料采购、工资等分类仍带“可选择”状态。
- 期望：不可用于手工记账的闭环分类应禁用或不出现在新记账选择器，并直接引导到正确入口。
- 实际：分类说明已提示正确入口，但 UI 仍可点击；提交后由服务端禁止。
- 建议整改：为分类增加服务端“手工可选”投影，或在分类选择器按手工用途过滤并禁用。
- 正向验收：可用分类可选，不可用分类不可选且显示正确入口说明。
- 反向验收：选择工程款/材料采购/工资/项目款不能进入手工流水保存。

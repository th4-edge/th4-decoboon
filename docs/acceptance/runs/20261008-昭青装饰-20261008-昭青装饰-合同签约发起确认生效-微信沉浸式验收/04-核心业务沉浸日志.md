# 核心业务沉浸日志

## 设计师

1. 打开合同签约页，报价、房屋、客户和金额正确带出。
2. 最终签约价只读，付款计划和施工计划可选择。
3. 提交后合同进入 PendingSign，按钮变为“已提交，等待负责人确认”。
4. 页面明确说明由企业负责人或店长复核确认。

## 店长

1. 打开同一合同，合同状态显示待签约。
2. 最终签约价变为可编辑字段，付款和施工计划可复核。
3. 点击“调整并确认签约”出现二次确认。
4. 确认后合同进入 Signed，未生成项目和应收。

## 企业负责人

1. 打开 Signed 合同，按钮为“确认生效并生成项目”。
2. 二次确认文案明确列出项目、施工计划、材料预计划和应收计划结果。
3. 确认后合同进入 Effective，唯一项目 P1791410475126 生成。

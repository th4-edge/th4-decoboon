# 核心业务沉浸日志 · 客户休眠（三角色）

> 本批次为聚焦功能验证（用户点名 3 个岗位 + 单一动作：设置为休眠用户），仅覆盖客户休眠主链；不覆盖客户-设计-报价-合同-项目-财务全闭环。

## S01 · 业务员设置与恢复休眠 —— PASS

- 角色/页面：黄贤杰（Marketer）/ subpackages/customer/pages/detail?id=228668918409986048
- 目标：把跟进中的王芳设为休眠客户
- 动作与结果：
  1. 详情页操作区显示按钮 设为休眠客户。
  2. 点击后弹出底部「选择休眠原因」面板，含 7 个原因与取消。
  3. 选择装修计划延期后，页面即时显示 休眠客户 / 已休眠，按钮变为 恢复跟进，Toast 已设为休眠客户。
  4. 点击 恢复跟进 → 二次确认「恢复客户跟进」 → 确认恢复，页面恢复 跟进中，Toast 已恢复跟进。
- 交叉核验：DB status Dormant → Following；cust_customer_status_log 记录 Following→Dormant(Dormant,PlanPostponed,Marketer) 与 Dormant→Following(Restore,Marketer)。
- 结论：PASS

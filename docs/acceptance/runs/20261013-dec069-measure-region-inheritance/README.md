### 页面级走查发现并修复的两个缺陷（Web `d843c03`）

1. **「原始结构（量房实测）」误报空态**：原实现只看最近一次量房单，若该次量房未录原始区域就显示「还没有录入原始区域」（走查 P4 真实复现）。改为按「最近一次**录入过**原始区域的已完成量房」取数（最多回溯 3 条）并显示来源量房时间。

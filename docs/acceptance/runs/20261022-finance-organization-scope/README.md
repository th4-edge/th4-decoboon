- 业务裁决：`DEC-081`
- 研发交接：`T12-BIZ-20261022-002`
- 状态：待独立验收
- 执行方：开发自测之外的责任人
- 通过条件：本包全部场景 PASS，且无阻断项残留

## 1. 范围

1. 门店候选按数据范围返回；
2. 财务邀请目标门店；
3. BOSS 跨店调整财务；
4. 默认总店唯一、创建时产生、不可切换；
5. App/Web 财务页面按组织结构展示全部门店/单店。

## 2. 测试环境

- 禁止生产环境写操作。
- 企业 A：默认总店 D、普通门店 A1、普通门店 A2；
- 企业 B：默认总店 X、普通门店 X1；
- 账号：BOSS、总部财务（D）、门店财务（A1）、店长（A1）、团队负责人、普通员工；
- 所有账号均使用可回滚的测试数据。

## 4. 阻断条件

任一命中即不通过：

- 门店财务或店长看到跨店合计；
- 总部财务/BOSS 无法取得本企业门店候选；
- BOSS 邀请财务可绕过目标门店选择；
- 非 BOSS 可跨店调财务；
- 调店回溯历史业务门店；
- 默认总店可停用、可切换，或新增门店成为默认总店；
- App/Web 同页同条件数字不一致；
- 接口失败被显示成空列表或 0 金额；
- 无真实页面/接口证据。

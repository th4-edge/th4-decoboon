- 游客首页新增业主专属场景和“我是业主，进入我的家”入口。

- 登录页首次直接请求手机号授权，不再先静默登录再二次授权。

- 邀请上下文保存为 `jzb_invite_intent_v1`：

  - 业主邀请 → 业主进入页；
  - 未加入企业页读取上下文后直接分流。
- 已接受邀请但本地会话丢失时，重新打开邀请后直接回对应首页。
- 未加入企业页统一图标底色、尺寸和描边图标风格；移除员工卡片无动作展开。

## 4. 微信平台边界

- 首次使用手机号按钮时，微信仍会展示隐私保护授权和手机号授权，这是平台机制，不能被业务代码跳过。
- 本次已移除额外微信个人资料授权，不会要求微信昵称和头像。
- 正式版提审和发布仍由用户本人完成。

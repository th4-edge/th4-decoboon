# App 客户页面角色投影截图

> 目的：对比同一客户列表在 Boss、财务、店长、业务员、设计师、项目经理六种角色下的可见任务与信息层级。
> 数据：微信开发者工具角色投影夹具，仅用于界面结构核验，不代表生产客户数据。

## 截图

| 角色 | 页面重点 | 截图 |
| --- | --- | --- |
| Boss | 统一负责人分组客户工作面；全企业范围并支持门店筛选 | `boss-customer-page.png` |
| 财务 | 与 Boss、店长相同工作面；负责人分组，无“待指派设计”筛选和派单动作 | `finance-customer-page.png` |
| 店长 | 与 Boss、财务相同工作面；固定本店范围，保留派单筛选 | `storeManager-customer-page.png` |
| 业务员 | 营销时段、跟进筛选与本人客户视图 | `marketer-customer-page.png` |
| 设计师 | 客户跟进视图，不显示派单入口 | `designer-customer-page.png` |
| 项目经理 | 关联客户视图，不显示派单入口 | `pm-customer-page.png` |

## 自动核验

`role-screenshots.json` 记录：

- 财务筛选无“待指派设计”；
- 财务无派单卡；
- Boss、财务、店长均渲染同一负责人分组与客户工作区；
- 店长保留待指派设计筛选；
- 各角色均成功进入客户页并渲染 5 张客户卡。

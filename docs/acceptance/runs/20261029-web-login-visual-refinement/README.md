> 本目录保留 CHG-017 的中间验证基线。当前登录页已按用户反馈移除装饰户型图、平台自述和企业概念，最新证据见 `docs/acceptance/runs/20261029-web-login-owned-system/` 与 CHG-018。

> 状态：`DEV_VERIFIED_PENDING_USER`  
> 风险级别：L0（文案、视觉、响应式；无业务语义变化）  
> 变更记录：`CHG-20261029-017-web-login-copy-visual-refinement.md`

## 1. 目标

在不改登录认证、品牌记忆、Provider、权限和本地缓存契约的前提下，优化 Web 登录页的文案层级与整体视觉，使页面从“深色营销海报”收敛为可信、克制、快速进入的企业工作台入口。

参考站酷 B 端研究后的执行原则：

- 浅中性画布为主，企业品牌色只承担识别与主行动；
- 保留家装场景，但作为低干扰项目隐喻，不与登录表单竞争；
- 登录页只保留一个主行动，不堆功能点、药丸标签、英文 eyebrow 或装饰性 3D；
- 沿用现有左右结构、企业品牌态、官方 Logo、favicon 和 last-login 逻辑，做渐进式优化。

## 2. 文案调整

| 位置 | 当前文案 | 目的 |
| --- | --- | --- |
| 左侧主标题 | 让客户、项目与财务，在同一处推进。 | 说明工作台覆盖的业务主线，不再使用泛化口号 |
| 左侧说明 | 从量房、设计、报价到施工、验收，项目进展与经营信息始终围绕同一个项目。 | 说明家装业务与项目上下文 |
| 右侧标题（装企态） | 登录昭青装饰工作台 | 直接说明登录的是当前企业 |
| 右侧标题（首次态） | 登录企业工作台 | 首次无品牌缓存时保持平台中立入口 |
| 登录提示 | 使用企业登记的手机号与 Web 登录密码进入工作台。 | 明确账号来源和密码类型 |
| 密码设置提示 | 还没有密码，或需要修改？请在小程序「我的 → 账号密码」设置或修改密码，设置完成后返回这里登录。 | 把“怎么获得密码”讲完整，替代错误的联系管理员提示 |
| 隐私说明 | 本机只记住企业品牌和手机号，不会保存密码。 | 说明品牌记忆边界，降低安全疑虑 |
| 主按钮 | 登录工作台 | 保持单一明确动作 |

## 3. 视觉调整

- 深色整屏品牌渐变改为暖中性画布、浅品牌晕染和轻量建筑网格。
- 企业品牌区使用企业 Logo/首字品牌标记，首次使用使用官方彩色装得清 Mark。
- 左侧加入低对比户型图纸（墙线、家具、尺寸线与节点），强化家装识别但不遮挡文字。
- 量房 → 设计 → 报价 → 施工 → 验收改为编号流程轨道，不再使用药丸式能力标签。
- 右侧独立白色登录面，使用现有 Token 的字阶、边框、圆角、聚焦和主按钮规范。
- 删除重复的“全角色工作台/岗位权限/经营闭环/财务穿透”四按钮式卖点。
- 所有新增视觉颜色均来自现有 `tokens.scss` 及企业品牌色派生 CSS Variables；没有页面级裸主色。
- 390px 下隐藏大幅户型图并压缩品牌说明，保留品牌、项目主线与完整登录表单。

## 6. 真实登录流程

使用测试账号完成：

```text
打开 /login
→ 手机号由 last-login 预填
→ 输入有效密码
→ 登录工作台
→ /workbench
→ 标题“工作台 | 昭青装饰”
→ 正文不包含“装得清”
```

错误密码路径：

```text
打开 /login
→ 输入错误密码
→ 登录工作台
→ 停留 /login
→ 显示“手机号或密码错误”
```

测试密码未写入本证据文件。

## 7. 视觉预检与两轮批判

视觉模型：`qwen2.5vl:7b`（本地 Ollama）。它是预检工具，不替代人工审美与用户验收。

- `vision-review-platform-1440.md`：首次平台态层级、留白、无模板卡片墙结论。
- `vision-review-enterprise-1440.md`：企业态登录区域可快速识别，配色比例合理，无卡片墙/药丸/英文 eyebrow。
- `vision-review-enterprise-390.md`：390px 排版、层级、配色预检；其中“增加图标、状态标签、更多对比色”等建议会重新制造装饰噪音，未采纳。

### 第一轮问题 → 修正

| 问题 | 修正 |
| --- | --- |
| 左侧深色面积过大，偏营销海报 | 改为暖中性画布 + 局部品牌晕染 |
| 功能点、流程、说明重复竞争 | 删除四能力点，保留一条业务说明和一条项目流程 |
| 企业态信息分散 | 主标题成为唯一视觉焦点，企业身份固定在左上 |
| 移动端品牌介绍过长 | 390px 隐藏大幅图纸与说明，压缩到登录表单之前 |

### 第二轮复核 → 修正

| 问题 | 修正 |
| --- | --- |
| 局部颜色与品牌 Token 存在耦合风险 | 暖底、图纸线、遮罩、焦点与按钮均收回 Token/品牌派生变量 |
| 小屏登录按钮下沉 | 390px 下登录卡片底部进入 844px 首屏范围，仅剩底部容器留白滚动 |
| 视觉模型建议增加图标/状态标签/辅助色 | 拒绝；登录页只需要品牌、流程语境和唯一主行动，不增加装饰性控件 |

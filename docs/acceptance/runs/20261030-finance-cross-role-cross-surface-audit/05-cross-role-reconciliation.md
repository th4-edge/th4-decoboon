# 跨角色对账

## 1. 角色范围

| 角色 | 页面身份 | 范围 | 结论 |
| --- | --- | --- | --- |
| Boss | 造数M负责人 / 企业负责人 | 全公司 | 可读全公司应收、应付、台账 |
| Finance | A 总店门店财务 / 财务 | 全公司 | 与 Boss 同口径金额一致 |
| StoreManager | A 总店店长 / 店长 | 本门店 | 跨店查询被拒绝或忽略，未越权 |

## 2. Boss vs Finance

| 事实 | Boss Web | Finance Web | DB |
| --- | ---: | ---: | ---: |
| 应收总额 | ¥135,672.23 | ¥135,672.23 | ¥135,672.23 |
| 累计已收 | ¥14,225.87 | ¥14,225.87 | ¥14,225.87 |
| 待收金额 | ¥121,446.36 | ¥121,446.36 | ¥121,446.36 |
| 应付总额 | ¥47,000.00 | ¥47,000.00 | ¥47,000.00 |
| 已付金额 | ¥9,000.00 | ¥9,000.00 | ¥9,000.00 |
| 待付金额 | ¥38,000.00 | ¥38,000.00 | ¥38,000.00 |
| 台账净现金流 | ¥-14,574.13 | ¥-14,574.13 | ¥-14,574.13 |

结论：Boss/Finance 可见财务事实一致。

## 3. StoreManager 范围

| 检查 | 结果 |
| --- | --- |
| 台账 A 总店 | 20 笔；收入 ¥3,743.65；支出 ¥8,000；净现金流 ¥-4,256.35 |
| 台账 URL 伪造 B 店 | Web/App 均未切到 B 店 |
| API 显式请求 B 店 | 应收/应付/台账均返回 `403 门店不存在或无权访问` |
| 直接打开应收计划 | Web/App 均可读本店 20 笔 |
| 菜单 `资金台账（只读）` | 页面同时存在手工记账、更正、删除动作；标签与能力不一致 |

## 4. 交接结论

- 财务汇总与总店台账可由 Boss/Finance 对齐。
- 店长只能看到本店事实，跨店负向通过。
- 由于 App 汇总为 0，Boss/Finance 无法在 App 端完成可信的资金判断，跨角色交接在 App 侧阻断。
- 本店应收入口未出现在店长菜单，但可通过 URL/业务跳转进入，导航与能力投影不一致。

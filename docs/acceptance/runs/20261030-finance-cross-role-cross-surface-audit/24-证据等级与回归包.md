## 测试覆盖边界

现有关键单测通过，但未覆盖：

- App 财务汇总报告与 Web 部门报告的同源一致性；
- 汇总接口失败时禁止显示 0；
- 手工应收/应付类型只允许 `BR-055` 白名单；
- 一条收款最多一条有效台账；
- 一笔付款必须有一条有效台账；
- 有业务数据但接口失败时的页面负向断言；
- Web 已收清应收不得出现“登记收款”。

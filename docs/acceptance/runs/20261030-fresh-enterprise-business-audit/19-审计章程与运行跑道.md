# 审计章程与运行跑道

## 跑道

`local-fixture + controlled-loop`：唯一写库为本地 `decoboon`，目标生产只作形态参照。

## 核心断言

1. 页面显示 = Provider = 数据库。
2. Web 与 App 使用同一后端、同一企业、同一角色和同一数据范围。
3. 正式事实缺失、接口失败时显示“暂不可确认”，禁止以 0 或空数组伪装。
4. 金额不使用前端公式；合同额、应收、已收、待收、应付、已付、台账必须服务端一致。
5. 成本不完整时利润和毛利率为空。
6. 店长跨店拒绝，财务/Boss 范围符合业务规则。

## 本轮角色线

- Boss：经营全局、客户/项目、财务总览。
- StoreManager：总店客户、项目、本店财务台账。
- Finance：应收、收款、应付、付款、台账、项目核算。
- Marketer / Designer / Pm：业务链事实的生产和交接来源。

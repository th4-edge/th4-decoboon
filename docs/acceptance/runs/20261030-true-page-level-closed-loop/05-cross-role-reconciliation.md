## 结论

- 本链的项目级合同、回款、待收、应付、付款、实际材料成本和结算 Draft 已跨角色、跨端一致。
- 未完成项是业务前置，不是数值不一致：业主本人未确认；最终成本仍有 2 个缺失项；因此结算保持 Draft、利润为空。
- `coreBalanced=true`：收款↔台账、付款↔台账、付款↔应付已付、净现金流均一致。

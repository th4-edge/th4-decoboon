## 二、正确引导

### 5. 六段引导

1. **入口**：Boss 客户列表/新增客户，Marketer 客户队列，Designer 客户与项目，Pm 我的项目，Finance 项目账本。
2. **队列**：客户/量房/报价/材料/施工/验收/财务均有角色入口。
3. **工作面**：项目、合同、材料计划、阶段验收、项目结算均有对象上下文。
4. **主行动**：阶段开工、任务推进、提交验收、收款、生成/确认结算均有明确按钮。
5. **交接**：Boss→Marketer→Designer→Pm/Finance 均能在下游看到同一对象或同一金额。
6. **异常**：成本未完整禁确认、业主手机号不匹配拒绝、员工无代确认入口，表达正确。

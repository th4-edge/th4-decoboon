## 角色汇总

- Boss：入口清晰，经营/项目/财务回读完整。
- Marketer/Designer：客户与项目上下文连续，多房屋和下游对象可定位。
- Pm：阶段和任务推进明确，上传证据是硬前置。
- Finance：资金链动作清楚，成本与结算门禁可解释。
- StoreManager：范围限制清楚，金额与 Boss/Finance 一致。
- 业主：当前环境身份不匹配，无法评价真实业主确认体验。

## App/Web 对比

- App 适合现场留证、任务推进与快速收付款查看；Web 适合多角色经营对账和批量/复杂表单。
- App 财务首页存在取整展示，业务值与 Web 一致。

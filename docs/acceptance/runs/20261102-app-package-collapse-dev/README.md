## 1. 验证场景

在本地测试套餐草稿中临时创建“卫生间”分区并添加一条施工分项，验证：

- 套餐详情按分区展示项目数和参考金额；
- 分区和分项类型支持展开/关闭；
- 项目配置页展示当前分区、分区项目数、参考金额和刷新入口；
- 卫生间显示 `1项`，而不是错误的 `0项`；
- 参考金额保留两位小数，例如 `¥6.80`；
- 项目行继续展示人工/材料价格。

临时测试分项和分区已在验证后清理。

## 4. 口径说明

- 分区/分组“参考金额”按项目库销售单价、计价方式和数量系数计算，只用于配置核对，不等同套餐整体牌价。
- 非成本角色不返回参考成本合计。
- 空分区由后端明确返回 `0`；统计字段缺失时前端显示“统计暂不可确认”，不再误显示为 0。

## 1. 修复后的访问模型

### 1.1 路由

| 路由 | 身份 | 验证结果 |
| --- | --- | --- |
| `file/private/grant` | 员工或业主 | 只对业务对象实际引用且当前身份可见的路径签发短期 URL |
| `file/private/download` | 签名 URL 持有者 | 校验 HMAC、有效期、路径规范化和 upload-dir 边界后返回文件 |
| `/public/**` | 匿名 | 只映射显式 `public-dir`，用于公开资源 |
| `/upload/**` | 无 | 不再注册静态资源处理器，匿名访问返回 404 |
| `{modelName}/download/{property}` | 无 | 由 `GenericDownloadBlockFilter` 统一返回 404 |

### 1.2 关键安全边界

- 员工文件授权按现有四级数据范围和项目参与关系校验。
- 业主文件授权只允许显式 `CustomerAccess` 项目内的客户可见业务对象。
- 本地私有文件签名默认有效期 300 秒，签名内容绑定规范化相对路径和过期时间。
- 下载阶段校验文件真实路径必须位于 upload-dir 内，路径穿越和不存在文件均拒绝。
- 旧 `/upload/talk/**` 和公开 PPT 下载入口已删除。
- 历史 `upload/...` 数据不改写，前端通过 `file/private/grant` 换取短期 URL。

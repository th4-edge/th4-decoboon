# 装得清运营管理端验收清单

## 1. 静态与构建

- [ ] `th4-decoboon-admin/npm run type-check` 通过。
- [ ] `th4-decoboon-admin/npm run build` 通过。
- [ ] `th4-decoboon/mvn -o -q -DskipTests compile` 通过。
- [ ] 生产构建确认 `VITE_DEMO_MODE=false`。
- [ ] 静态资源无明文密钥、账号和连接串。

## 2. 登录与权限

- [ ] 独立 PlatformUser/SuperAdmin 可以通过 `platform/auth/login` 登录。
- [ ] 租户 Employee token 访问平台路由返回用户类型不匹配。
- [ ] 匿名访问 `platform/tenant/page` 返回 401。
- [ ] 普通企业 token 访问平台路由返回 403。
- [ ] 不具备对应 PlatformPermission 的平台用户访问平台路由返回 403。
- [ ] 退出后本地 token 和最小会话资料被清理。

## 3. 企业查询

- [ ] 企业分页支持名称/简称搜索。
- [ ] 状态筛选 Trial/Active/Expired/Frozen/Closed 正确。
- [ ] 平台组织不会写入或出现在租户企业列表。
- [ ] 列表返回套餐、服务期、剩余天数、席位和门店摘要。
- [ ] 企业详情不返回员工凭证、密钥和隐私正文。
- [ ] CSV 导出只包含当前筛选结果。

## 4. 订阅人工管控

- [ ] 续费从当前到期日顺延；过期企业从当前时间计算。
- [ ] 套餐切换引用最新 PlanVersion。
- [ ] 席位/门店调整保存后权益立即变化。
- [ ] 冻结、恢复、关闭状态受规则保护。
- [ ] 恢复 Active 时服务期必须未过。
- [ ] 没有调整项时返回 400。
- [ ] 并发调整使用悲观锁，不出现覆盖写。
- [ ] 每次成功调整生成一条审计。

## 5. 审计

- [ ] 审计包含 PlatformUser 操作人、租户企业标量快照、动作、原因、前后值和时间。
- [ ] 审计按企业、动作和时间可检索。
- [ ] 普通租户不可读取平台审计。
- [ ] 平台表没有指向租户 Company/Employee/Credentials 的外键。
- [ ] 管理端不提供审计删除入口。
- [ ] 导出审计不包含密码、密钥和连接串。

## 6. 系统运维

- [ ] 状态接口返回主机、操作系统、Java、应用版本。
- [ ] CPU、内存、磁盘、系统负载和运行时长可展示。
- [ ] MySQL、Redis、应用进程健康状态可展示。
- [ ] 依赖不可用时接口不整体 500，而是标记 DOWN。
- [ ] 超过阈值时生成告警文本。
- [ ] 运维页面不展示连接串、密码和私钥。

## 7. 浏览器回归

- [ ] `/login` 可以登录。
- [ ] `/overview`、`/tenants`、`/subscriptions`、`/growth`、`/plans`、`/operations`、`/audit` 均正常渲染。
- [ ] 订阅调整对话框可打开、确认、提交和刷新。
- [ ] 刷新后不会误跳登录页。
- [ ] 无未处理 console error 和 warning。
- [ ] 1180px 以上桌面视口无关键内容遮挡。

## 8. 生产演练

- [ ] 在生产或隔离环境完成一次可回滚的人工续费。
- [ ] 验证审计记录与订阅快照一致。
- [ ] 验证 TLS 和 API 反向代理。
- [ ] 验证只读监控采集。
- [ ] 验证上一 release 回滚路径。

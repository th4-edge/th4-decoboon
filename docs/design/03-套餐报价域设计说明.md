# 套餐报价域设计说明

> 对应代码：`com.th4.edge.decoboon.bim.pack`、`com.th4.edge.decoboon.trade.quote`  
> 对应数据表：`bim_pack_*`、`dbquote`、`db_quote_item`
> 租户约束：套餐、报价和报价明细全部包含 `Company company`

面向企业负责人的套餐理解、配置、应用和操作说明见 `docs/product/装得清-套餐设计详细说明.md`。

## 1. 领域定位

套餐报价域包含两层：

1. `GiftPack`：可复用的整装套餐模板，归属 BIM 报价主数据。
2. `Quote`：某个客户、某个面积、某个时点的报价实例，保存套餐快照。

BIM 套餐是“报价模板”，Quote 是“客户报价事实”。项目只能引用 Quote，不能直接引用会变化的 GiftPack 作为最终价格依据。

## 2. BIM 套餐模型

### GiftGroup 装修空间

- `groupId`
- `name`
- `spaceTypes`
- `maxDeleteNum`
- `priority`

### GiftPackItem 套餐差项

- `itemId`
- `name`
- `unit`
- `spaceTypes`
- `priority`

### GiftItem 套餐分项

- `itemId`
- `group → GiftGroup`
- `name`
- `brand`
- `spec`
- `unit`
- `quantity`
- `constructions: Map<Construction, BigDecimal>`
- `materials: Map<Material, BigDecimal>`
- `criterions`

### GiftPack 装修套餐

- `giftId`
- `name`
- `area`：模板标准面积
- `price`：套餐标准面积对应的折前牌价
- `discount`
- `cost`：由套餐内所有材料/施工项成本计算
- `items`
- `measures`
- `criterions`

## 3. 套餐成本计算

`GiftPackContext.calculate(giftPack)`：

```text
cost = Σ 材料标准面积 × 材料成本规则
     + Σ 施工标准面积 × 施工成本规则
```

计算结果回写 `GiftPack.cost`。该字段是报价参考，不是财务流水。

## 4. Quote 报价实例

### 核心字段

- `quoteId`
- `no`
- `customer → Customer`
- `giftPack → GiftPack`
- `area`
- `amount`
- `cost`
- `discount`
- `status`
- `createdBy → Employee`
- `project → Project`（转为项目后回填）
- 审计时间

### QuoteItem 报价明细

- `itemId`
- `quote → Quote`
- `giftItem → GiftItem`
- `name`
- `brand`
- `spec`
- `unit`
- `quantity`
- `price`
- `cost`

### 状态机

```text
Draft → Submitted → Accepted → Converted
                  ↘ Rejected
```

规则：

- 报价创建时按 `项目面积 / 套餐标准面积` 比例换算牌价和成本，再应用报价折扣。
- 套餐报价版本按“同一客户 + 同一套餐模板”已有报价数量递增，不再固定为版本 1。
- 套餐报价创建后先形成 Draft，设计师可在提交客户前处理扣减、升级、替换和增项，由服务端重新计算汇总。
- 报价明细按套餐分项成本占比分配售价，保存快照。
- 只有 Accepted 报价可以生成项目。
- 报价生成项目后变为 Converted，不再允许修改金额。

## 5. Provider 规划

| 路由 | 能力 | 说明 |
| --- | --- | --- |
| `pack/template/page` | 分页 | 套餐模板列表 |
| `pack/template/info` | 详情 | 套餐、分项、差价项 |
| `pack/template/save` | 保存 | 新建套餐 |
| `pack/template/update` | 更新 | 修改并重算成本 |
| `quote/save` | 保存 | 从套餐创建客户报价 |
| `quote/page` | 分页 | 我的/公司报价 |
| `quote/update` | 更新 | 提交、接受、驳回、转项目 |

## 6. 强业务规则

- 创建 Quote 必须校验客户、套餐、面积。
- 金额不能由前端任意传入，必须由套餐和面积计算。
- Quote 必须拥有 `QuoteItem` 快照，禁止只保存 giftId。
- 接受 Quote 后触发生成项目，不允许重复生成。
- Quote 成本只对 Boss、财务和报价负责人可见。

## 7. 数据权限接入要求

- Quote、QuoteItem 的 page/info/update 必须接入统一数据权限。通用 `service/*` 由 `DataScopeRequestFilter` 和 `DataPermissionCrudAspect` 自动处理，自定义 Provider 禁止裸 `findById`。
- 当前 Quote 只明确 `createdBy`，后续接入四级权限前必须确定“可见负责人”字段，以及门店、团队归属是否随客户或报价负责人快照。
- 报价读取客户时只能通过 `DataScopeSpecification` 获取当前用户可见的 Customer，不能只按 `companyId` 查询。
- 成本字段的可见性属于字段级/角色能力权限，不能替代企业、门店、团队、本人四级数据范围。

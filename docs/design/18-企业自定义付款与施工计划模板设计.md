# 企业自定义付款与施工计划模板设计

> 日期：2026-09-20  
> 范围：企业负责人 App、付款/施工计划模板 Provider、合同签约快照联动  
> 状态：开发实现完成，待独立验收

## 1. 业务目标

平台提供的付款计划和施工阶段基线不能覆盖所有装企。成长型中小装企需要按自身收款习惯、施工组织方式和验收制度维护企业模板，同时保证已经签署的合同不被后续修改影响。

本能力采用三层模型：

1. 平台基线：系统预置、只读，可直接用于合同或复制为企业模板。
2. 企业自定义模板：企业维护节点、比例、阶段和工期，支持草稿、启用、停用和默认。
3. 合同快照：合同选择模板后复制节点和阶段，后续修改企业模板不回溯已签合同。

## 2. 真实场景

### 场景一：老板调整回款节奏

- 使用人：企业负责人。
- 触发事件：企业希望签约收 20%、水电验收收 30%、泥木验收收 30%、竣工收 20%。
- 当前动作：从「四段节点收款」复制为企业模板，修改比例并启用、设为默认。
- 系统下一步：新合同签约默认选择该企业模板，生成对应应收计划。
- 异常处理：比例合计不是 100% 时禁止启用。

### 场景二：老板调整施工阶段

- 使用人：企业负责人。
- 触发事件：企业不单独设置木作阶段，将其并入泥瓦阶段。
- 当前动作：复制「住宅标准八阶段」为企业模板，删除木作，调整阶段工期并启用。
- 系统下一步：新合同生效后按企业模板生成项目阶段和日期。
- 异常处理：阶段编码重复或工期非法时禁止保存或启用。

### 场景三：历史合同与模板隔离

- 使用人：企业负责人。
- 触发事件：企业修改已经使用过的付款计划模板。
- 当前动作：保存新版本。
- 系统下一步：新合同使用新版本，历史合同继续使用自己的付款节点和金额快照。
- 异常处理：合同生效后不提供更换模板入口。

## 3. 数据模型

### 企业付款计划

- `db_company_payment_plan`：模板主表。
- `db_company_payment_node`：收款节点。
- 关键字段：企业、编码、版本、名称、说明、状态、默认标记、来源基线、发布时间。
- 节点字段：名称、比例、应收类型、触发类型、触发阶段、偏移天数、排序。

### 企业施工计划

- `db_company_construction_plan`：模板主表。
- `db_company_construction_stage`：施工阶段。
- 关键字段：企业、编码、版本、名称、说明、标准总工期、状态、默认标记、来源基线、发布时间。
- 阶段字段：名称、阶段编码、标准工期、验收方式、说明、排序。

所有表均按 `com_id` 隔离，并建立企业、状态、默认和明细查询索引。

## 4. 生命周期

```text
平台基线 / 空白新建
-> 企业草稿
-> 启用
-> 设为默认
-> 停用
-> 再启用
```

- 新建模板默认为草稿，版本为 1。
- 编辑已启用模板时版本加 1，立即用于后续新合同，但历史合同快照不变。
- 启用时如果没有其他默认模板，自动成为默认模板。
- 停用模板时自动清除默认标记，历史合同不受影响。
- 只有已启用模板可以设为默认。

## 5. 权限

| 能力 | BOSS | Finance | PM | 其他员工 |
| --- | --- | --- | --- | --- |
| 查看可签约模板 | 是 | 是 | 是 | 是 |
| 维护付款计划模板 | 是 | 后续按权限开放 | 否 | 否 |
| 维护施工计划模板 | 是 | 否 | 后续按权限开放 | 否 |
| 发布、停用、设默认 | 是 | 后续按权限开放 | 否 | 否 |

本轮写 Provider 统一限制企业负责人；合同签约页只读取当前企业已启用模板和平台基线。

## 6. Provider 契约

### 可用模板

```text
plan/template/page
```

返回当前企业已启用模板 + 平台基线，供合同签约选择。企业默认模板排序优先。

### 管理目录

```text
plan/payment-template/page
plan/construction-template/page
```

返回企业草稿、启用、停用模板及平台基线，供模板管理页使用。

### 模板生命周期

```text
plan/payment-template/save
plan/payment-template/update
plan/payment-template/publish
plan/payment-template/disable
plan/payment-template/default

plan/construction-template/save
plan/construction-template/update
plan/construction-template/publish
plan/construction-template/disable
plan/construction-template/default
```

所有写接口仅允许 BOSS，并从登录员工覆盖企业归属。

## 7. 校验规则

### 付款计划

- 模板名称必填。
- 至少一个收款节点，最多十个。
- 节点名称必填。
- 比例必须大于 0 且不超过 100%。
- 全部节点比例合计必须为 100%。
- 阶段开工、阶段完成、阶段验收触发必须指定阶段编码。

### 施工计划

- 模板名称必填。
- 至少一个阶段，最多二十个。
- 阶段名称和编码必填且编码不能重复。
- 阶段工期为 1 至 365 天。
- 标准总工期由所有阶段工期自动汇总，不允许与明细不一致。

## 8. App 入口与页面

### 「我的 -> 经营工具」

- 付款计划模板。
- 施工计划模板。

### 付款计划页面

- 企业自定义模板列表。
- 平台基线列表。
- 复制基线、编辑、启用、停用、设为默认。
- 节点名称、比例、应收类型、触发类型、触发阶段、偏移天数编辑。

### 施工计划页面

- 企业自定义模板列表。
- 平台基线列表。
- 复制基线、编辑、启用、停用、设为默认。
- 阶段名称、编码、工期、验收方式、说明编辑。

合同签约页继续使用 `plan/template/page`，自动优先显示企业默认或已启用模板。

## 9. 合同快照边界

- 合同签约时复制模板名称、编码、版本、节点/阶段和比例/工期。
- 合同生效后不能更换模板。
- 企业模板编辑、停用、版本升级不得修改合同快照。
- 历史合同不依赖企业模板表继续运行。

# 客户经营聚合与负责人客户卡设计

> 日期：2026-09-20  
> 范围：企业负责人 App 客户 Tab、客户经营聚合 Provider、客户卡只读经营投影  
> 状态：开发实现完成，待独立验收

## 1. 设计目标

客户 Tab 同时服务业务操作和企业负责人经营判断。业务员关心下一次跟进，企业负责人更关心客户是否增长、团队是否行动、机会是否成交以及哪些客户正在流失。

页面保持统一结构：

```text
搜索输入
门店/团队范围
四张经营指标卡
风险/停留/金额排序
客户阶段筛选
客户列表
```

搜索和阶段只影响客户列表；门店/团队范围影响指标卡和客户列表；指标卡默认按本月统计。

## 2. 四项客户经营指标

### 新增客户

- 主数据：本月新增客户数。
- 辅助数据：今日新增、本周新增。
- 趋势：与上月同一日期区间的同比周期比较。
- 用途：判断客户增长是否健康。

### 有效跟进

- 主数据：本月发生过跟进、到店、量房或设计交底动作的客户数。
- 辅助数据：今日待跟进、跟进逾期。
- 用途：判断团队是否在推进客户，而不是只看客户存量。

### 签约客户

- 主数据：本月有合同签约时间的客户数。
- 辅助数据：本月签约额、当前报价中客户数。
- 用途：判断客户机会是否形成合同结果。

### 风险客户

- 主数据：高风险客户数。
- 辅助数据：需关注客户、停滞客户、本月流失客户。
- 用途：暴露负责人必须介入或协调的客户。

## 3. 风险规则

| 条件 | 等级 | 默认下一步 |
| --- | --- | --- |
| 未分配负责人 | 高风险 | 先分配负责人 |
| 下次跟进时间已逾期 | 高风险 | 立即处理逾期跟进 |
| 待量房且量房时间已过、未指派设计师 | 高风险 | 指定设计师并确认量房安排 |
| 待量房且未指派设计师 | 需关注 | 指定设计师并确认量房安排 |
| 7–14 天没有新的推进 | 需关注 | 安排下一次跟进 |
| 15 天以上没有新的推进 | 高风险 | 重新激活客户或评估流失 |

签约、施工、完工、流失状态不参与普通停滞预警。

## 4. 客户经营卡

BOSS 客户卡按以下顺序展示：

1. 客户姓名、当前阶段、客户等级、风险等级。
2. 负责人和设计师。
3. 小区、面积、预算。
4. 上次跟进时间、停留天数、下次跟进状态。
5. 最近报价金额或签约金额，以及关联项目。
6. 系统建议的下一步动作。

业务员卡保持下一次跟进、黄金期、微信/到店等执行信息；店长和团队长保留派单信息。

客户详情页的“编辑资料”和“编辑房屋”操作与“完善画像”保持一致的操作样式：使用编辑图标、品牌主色图标和主色文字，不再使用灰色资料型文案。

## 5. 聚合接口

```text
customer/customer/overview
```

请求：

```json
{
  "current": 1,
  "size": 20,
  "keyword": "刘",
  "stage": "quote",
  "sort": "risk",
  "storeId": 1
}
```

排序值：

- `risk`：风险优先，默认。
- `idle`：停留时间最长。
- `value`：报价或签约金额最高。
- `newest`：最新录入。

响应包含：

- `metrics`：四张负责人指标卡。
- `stageCounts`：全部、待指派设计及八个客户阶段的服务端计数。
- `customers`：当前分页客户及负责人卡片只读投影。
- `current/size/total/hasMore`：分页信息。

## 6. 只读卡片投影

在 `Customer` 响应中增加只读字段：

- `idleDays`：停留天数。
- `riskLevel`：`normal/attention/high`。
- `riskReason`：风险原因。
- `nextAction`：建议下一步。
- `quoteAmount`：最近报价金额。
- `signedAmount`：合同签约金额。
- `projectId/projectName`：关联项目。

这些字段由服务端装配，前端不得自行覆盖或写入。

## 7. 权限

- 普通列表继续按现有角色数据范围。
- 客户经营聚合第一版只允许 BOSS，企业范围从登录员工读取。
- BOSS 可选门店过滤，不信任前端企业参数。
- 请求门店不属于当前企业时，只能得到当前企业范围内的空结果，不能读取其他企业客户。

## 8. 验收矩阵

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| CUST-OV-01 | BOSS 首次进入客户 Tab | 四张指标卡和阶段计数来自服务端，不依赖当前页列表 |
| CUST-OV-02 | 客户超过一页 | 指标卡和阶段计数仍为当前企业/门店全量口径 |
| CUST-OV-03 | 搜索姓名/手机/小区 | 仅分页列表变化，指标卡不变成搜索结果口径 |
| CUST-OV-04 | 切换客户阶段 | 列表切换，指标卡保持经营纵览 |
| CUST-OV-05 | 风险优先排序 | 高风险、逾期、长期停滞客户优先 |
| CUST-OV-06 | 未分配负责人 | 显示高风险和“先分配负责人” |
| CUST-OV-07 | 跟进逾期 | 显示逾期天数和处理动作 |
| CUST-OV-08 | 待量房未指派设计师 | 显示风险和指派动作 |
| CUST-OV-09 | 存在本月签约 | 签约客户和签约额正确 |
| CUST-OV-10 | 非 BOSS 访问聚合接口 | 服务端拒绝 |
| CUST-OV-11 | 跨企业门店参数 | 不返回其他企业客户 |
| CUST-OV-12 | 接口失败 | 页面显示错误和恢复入口，不沿用旧指标冒充最新事实 |

## 9. 边界

- 本接口返回的是经营参考值，不替代客户详情和正式成交率口径。
- 报价金额使用最近一份报价；签约金额使用最近一份合同的签约金额，缺失时回退当前合同金额。
- 当前客户状态用于阶段计数；历史阶段流转后续如需要趋势，应建设独立状态历史。

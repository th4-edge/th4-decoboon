# 报价工作表批量保存接口契约

> 接口：`quote/lines/save`
> 定位：**Web 专用**批量保存入口（App 继续使用既有 `quote/line/save`，契约不变）
> 依据：`docs/product/consultations/ANS-BIZ-20261002-002-设计师Excel式报价五问答复.md` Q4 / Q5
> 状态：生效中（2026-10-06）

## 1. 适用范围

| 端 | 入口 | 承载能力 |
| --- | --- | --- |
| App | `quote/line/save` | 保持现状：工程量等既有入参；**不得改其契约与页面行为** |
| Web | `quote/lines/save` | 工程量、工程量公式、销售侧材料单价、人工单价、固定总价、行级优惠 |

服务端前置校验：仅 `Draft`；仅报价创建者本人（设计师）可调用。

## 2. 请求

```json
{
  "quoteId": 2316645249969024,
  "items": [
    {
      "itemId": 231664525017874439,
      "quantity": 30,
      "quantityFormula": "=5*6",
      "materialPrice": 40,
      "manualPrice": 30,
      "fixedTotalPrice": null
    }
  ]
}
```

- `items` 必填，单次 **最多 200 行**（`MAX_LINES`）；超出返回 400。
- 每个 `itemId` 必须属于该报价，否则 404。
- 未出现在 `items` 中的报价行不被修改。

## 3. 字段「是否显式提供」的口径（ECD-014 根修复）

`QuoteLine` 的 `quantity / materialPrice / manualPrice` 实体默认值分别是 `1 / 0 / 0`，
嵌套绑定新对象时**「未传」与「显式传默认值」无法区分**，
曾导致"只改材料价"的请求把工程量覆盖成 1（ECD-014）。

**解决方式**：请求为每个要修改的字段携带**显式提供标记**（`@Transient`，不持久化、
不在任何 `@Properties` 白名单内故不序列化，无需 `@JsonIgnore`）：

| 标记 | 作用 |
| --- | --- |
| `quantityProvided` | 为 `true` 时本次修改工程量 |
| `quantityFormula` 非空 | 以公式求值结果为准（优先于 `quantity`） |
| `materialPriceProvided` | 为 `true` 时本次修改材料价 |
| `manualPriceProvided` | 为 `true` 时本次修改人工价 |
| `fixedTotalPriceProvided` | 为 `true` 时本次修改固定总价 |

### 取值规则

```text
工程量：quantityFormula 非空 → 公式求值结果
        否则 quantityProvided=true → 请求的 quantity
        否则 → 保留原工程量（含 0）

价格：   *Provided=true → 使用请求值（按第 4 章校验）
        未标记       → 保留原值
```

**安全默认**：未携带标记的字段一律**保留原值**，绝不会被实体默认值覆盖。
因此漏传标记的客户端表现为"本次不修改"，而不是"静默改错"。

### 客户端要求

Web 批量保存只为**真正修改过的字段**置标记；未修改字段不发送值与标记。
App 的 `quote/line/save` **不使用这些标记**，其契约与行为不变。

## 4. 价格校验（按计价模式）

| 计价模式 | 有效价格要求 |
| --- | --- |
| `MaterialOnly` | 材料价 > 0 |
| `ManualOnly` | 人工价 > 0 |
| `MaterialAndManual` | 材料价 + 人工价 > 0（允许单侧为 0） |
| `FixedTotal` | 固定总价 > 0 |

另外，**明确传了该计价模式不适用的非零价格**时返回 400，不再静默忽略：

| 情况 | 结果 |
| --- | --- |
| `FixedTotal` 行传材料价或人工价（> 0） | 400 |
| `MaterialOnly` 行传人工价（> 0） | 400 |
| `ManualOnly` 行传材料价（> 0） | 400 |
| 非 `FixedTotal` 行传固定总价（> 0） | 400 |

**校验先于落库**：任何一行不合法都不会写入任何行，也不触发重算。

## 5. 公式

- 提供 `quantityFormula`（非空）时，工程量以**公式求值结果**为准（`quantity` 被忽略）。
- 仅提供 `quantity`（> 0）且未提供公式时，**清空**该行既有公式。
- 公式白名单与精度见 Q2；公式求值失败返回 400。

## 6. 金额与响应

- 正式行金额、区域小计、总价、税额一律**服务端重算**，前端不得提交计算结果。
- 响应为 `QuoteViewContext.apply(...)` 后的完整报价视图（含 `items` 与 `regionGroups`）。
- 客户端保存后应**重新读取**（或直接采用返回视图）并覆盖前端预览。

## 7. 不变更的字段

- `space`（区域归属）：本入口**不修改**报价行的区域归属。
  （App 单行入口 `quote/line/save` 此前会因请求缺省 `space` 而清空，已在 ECD-013 修复为「缺省即保留」。）
- 标准成本、采购执行价、利润：本入口不接收、不返回。

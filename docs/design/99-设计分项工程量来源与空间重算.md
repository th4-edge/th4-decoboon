# 设计分项工程量来源与空间尺寸重算

> 目标：修改方案空间长宽高时，只重算公式自动量，不覆盖设计师手工量。  
> 关联迁移：`docs/design/migrations/98-设计分项工程量来源.sql`。

## 1. 数量来源

`db_design_item.quantity_source`：

- `Formula`：由模版/专业变量公式自动计算。
- `Manual`：设计师手工填写或调整的数量。

模版实例化创建的分项默认为 `Formula`；设计师手工修改工程量后前端提交 `Manual`。

## 2. 空间尺寸保存

`design/space/save` 保存空间后：

1. 重算空间面积、周长。
2. 更新方案总面积。
3. 查询当前方案全部设计分项。
4. 只处理 `quantity_source = Formula` 的分项。
5. 区域分项按所属空间变量重算。
6. 全屋聚合分项按所有空间 `SUM(A)` / `SUM(P)` / `SUM(WP)` 重算。
7. 重新计算分项金额。
8. 尺寸不足时保留 `__PENDING_MEASURE__` 标记并将数量归零。

`Manual` 分项不会被尺寸变化覆盖。

## 3. 当前变量边界

方案空间当前只有 `length / width / height`，尚未采集门洞、窗洞和防水上返。重算时这些变量暂按 0 处理，后续如果增加空间字段，再替换适配器。

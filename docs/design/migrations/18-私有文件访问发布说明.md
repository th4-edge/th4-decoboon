# 私有文件访问发布说明

## 目标

- 移除 `/upload/**` 对业务上传目录的匿名静态映射。
- 业务文件统一通过 `file/private/grant` 授权后生成短期 URL，再由 `file/private/download` 读取。
- 只有 `th4.edge.framework.public-dir` 对应的 `/public/**` 允许匿名访问。

## 发布配置

| 配置 | 必填 | 说明 |
| --- | --- | --- |
| `TH4_FILE_SIGNATURE_SECRET` | 生产必填 | 文件 URL HMAC 密钥；多实例必须使用同一密钥，轮换时保留旧密钥验证窗口 |
| `TH4_FILE_SIGNATURE_TTL_SECONDS` | 否 | 签名有效期，默认 300 秒，限制在 30 到 3600 秒 |
| `TH4_FILE_UPLOAD_DIR` | 是 | 私有业务文件根目录，只允许后端进程和运维访问 |
| `TH4_FILE_PUBLIC_DIR` | 是 | 明确公开目录，与 upload-dir 物理隔离 |

## 数据迁移

本方案不新增数据库表，不需要数据回填。业务实体保留原始 `upload/...` 路径；文件响应在返回前端前换取短期签名 URL。

## 历史 URL

- `/upload/**` 不再注册静态资源处理器，历史匿名 URL 统一返回 404。
- `/upload/talk/**` 旧下载入口已移除。
- 框架通用 `{modelName}/download/{property}` 路由被统一阻断，避免通过 `file` 参数读取 upload-dir 任意路径。
- 历史业务记录中的路径无需改写，前端通过 `file/private/grant` 重新签发即可访问。
- 外部 `http/https` 文件继续按原地址使用，不进入本地签名流程。

## 发布顺序

后端和小程序必须同步发布。先发布前端会造成旧后端仍暴露 `/upload/**`；先发布后端会造成未升级客户端的历史 URL 立即失效。建议维护短时维护窗口并同时切换。

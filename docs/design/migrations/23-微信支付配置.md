## 2. 证书部署

- `apiclient_cert.p12`
- `apiclient_cert.pem`
- `apiclient_key.pem`

私钥文件权限必须为 `600`。生产环境建议将证书放在应用外部目录，并通过绝对路径注入。

## 3. 环境变量

本地开发使用 `.env.wechat-pay.local`，由 `run-dev.sh` 自动加载：

```bash

WECHAT_PAY_APP_ID=wxe5cc5fec9e50a9a9
WECHAT_PAY_MCH_ID=1750623009
WECHAT_PAY_MCH_SERIAL_NO=24A00BDC638A9B5BE07C8E6BF396096BA379AE07
WECHAT_PAY_PRIVATE_KEY_PATH=/absolute/path/to/apiclient_key.pem
WECHAT_PAY_API_V3_KEY=<32-byte-secret>
WECHAT_PAY_NOTIFY_URL=https://decoboon.joytsing.com/api/order/callback
WECHAT_PAY_PLATFORM_PUBLIC_KEY_ID=PUB_KEY_ID_0117506230092026091600211597001000
WECHAT_PAY_PLATFORM_PUBLIC_KEY_PATH=/absolute/path/to/pub_key.pem
WECHAT_PAY_CONNECT_TIMEOUT_MS=3000
WECHAT_PAY_READ_TIMEOUT_MS=8000
```

API v3 密钥和商户私钥禁止提交到 Git，禁止写入 README、日志或工单。

## 4. 启动校验

当 `WECHAT_PAY_ENABLED=true` 时，应用启动阶段校验：

- 商户号、AppID、证书序列号、回调地址和公钥 ID 是否齐全。
- API v3 密钥是否为 32 字节。
- 商户私钥是否可以按 PKCS#8 RSA 格式加载。
- 微信支付公钥是否可以按 PEM 或证书格式加载。

任一条件不满足时应用拒绝启动。

## 5. 配置验证

- 商户证书公钥与 `apiclient_key.pem` 匹配：通过。
- 商户证书 CN 与商户号一致：通过。
- 正式交易查询接口签名：接受。
- 微信支付响应验签：通过。
- 响应公钥 ID：与下载的微信支付公钥 ID 一致。
- 无副作用查询返回：`ORDER_NOT_EXIST`，说明请求身份和签名链路正常。

API v3 密钥用于解密真实支付回调，需在首笔支付或微信支付测试回调时完成端到端确认。

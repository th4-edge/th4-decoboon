# 迁移目录约定（2026-10-05 起）

## 编号规则

- 文件名必须是 `{序号}-{中文说明}.sql`，序号为**全局唯一**的连续整数。
- 新增迁移取「当前最大序号 + 1」。**当前最大序号：76**；下一个新迁移用 **77**。
- 序号重复会让 `scripts/build-release.sh` 把多份同号脚本一起打进发布包，DBA 极易只执行其中一份。
  2026-10-05 的 `quote_line.quantity_formula` 缺失事故就是这个原因。
- 双重守卫：
  - `scripts/build-release.sh` 构建时遇到未登记的同号迁移直接失败；
  - `src/test/java/com/th4/edge/decoboon/common/migration/MigrationNumberingTest.java` 固化唯一性。

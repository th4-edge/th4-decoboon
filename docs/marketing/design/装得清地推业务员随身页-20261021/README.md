# 装得清地推业务员随身页

- 状态：**双面地推样稿，待用户复核；未对外发布**
- 日期：2026-10-21
- 目标：让不熟悉装企业务的业务员，也能通过一页纸和一套口语话术，让装企老板快速感受价值
- 形式：A4 双面。正面给客户看，背面给业务员自己看

## 为什么做成双面

业务员现场真正需要的不是一张“功能清单”，而是：

1. 一张客户愿意看、看得懂的价值页。
2. 一套不依赖业务员自由发挥的拜访脚本。
3. 一条能在 3 分钟内演示完的业务链。
4. 一组客户异议出现时可以马上接住的原话。
5. 一个不会一上来就报年费、能自然推进到真实项目试用的收口方式。

因此：

- **正面**：给装企老板看，用微信群、Excel、催进度、验收、月底对账等熟悉场景讲价值。
- **背面**：给业务员看，写清 0–1 分钟开场、1–3 分钟追问、3–6 分钟演示、6–8 分钟异议与收口。

> 背面明确标注“客户不看 · 自己用”，不应递给客户。

## 正面怎么用

1. 先让老板讲最近最麻烦的项目，不急着展示页面。
2. 当老板讲到“客户催进度、报价改版、验收扯皮、月底对账”时，把正面递过去。
3. 只指四个价值场景中的一个，不要从头到尾念完。
4. 确认老板对某一个场景有反应后，再翻到背面按顺序演示。

正面核心话术：

> 装得清不是再多一个群，是把一单生意收进一个地方。

> 客户少问一句，员工少翻一次，老板少猜一遍。

> 先别换掉 Excel。拿最烦的一单，跑一遍。

## 背面怎么用

### 0–1 分钟：开口

> 老板，你们现在客户改方案、催进度、对收款，平时都在哪儿记？

### 1–3 分钟：只问四句

1. 最近哪个项目最麻烦？
2. 客户改完以后，谁去通知合同、材料、现场和财务？
3. 客户问“做到哪了”，现在谁回、去哪儿找？
4. 月底这单赚多少，谁说得清？

### 3–6 分钟：只演示一条链

报价版本 → 变更 → 客户手机视图 → 项目台账。

每步只停 10 秒，只演示客户刚才讲的那个问题，不展开全部菜单。

### 6–8 分钟：异议与收口

背面提供 5 个常见异议：

- 我们有 Excel 和微信群。
- 员工不会用。
- 客户不会看。
- 我们已经有 ERP。
- 太贵了。

收口统一为：

> 我今天不急着让你买。拿你最烦的一单，我用 15 分钟给你走一遍。你觉得像，再叫项目经理和财务一起看。下周哪天方便？

## 事实与边界

### 可引用事实锚点

- 客户、房屋、报价、合同、项目、履约与验收对象关系：`EV-003`、`BR-001`、`BR-002`。
- 客户查看、阶段任务、现场留证与验收整改：`SCN-003`、`SOL-006`、`DEC-015`、`BR-008`、`EV-037`、`EV-038`。
- 材料到货、实际成本与应付归集：`SOL-002`、`EV-010`、`EV-017`。
- 财务边界“管项目和钱，不管税和账”：`DEC-016`。
- 成本不完整时利润不可确认：`EV-008`。
- 客户只看本人被授权项目；内部成本、供应商价格、员工数据和其它项目不开放：`SOL-006`、`SOL-002`、`EV-005`。

### 必须保留的表达边界

- 业务员不得说“利润一定涨、工期一定不延、投诉一定少、员工不用学”。
- 不得说“所有装企都适合”或“什么都能做”。
- 不得把标准年费说成最终成交价；价格、优惠、实施和服务范围以正式报价单/合同为准。
- 不得把客户查看写成客户审批所有环节；阶段验收由业主本人确认或驳回。
- 不得使用未经授权的客户名称、Logo、项目地址、金额或案例。
- 演示测试数据时必须标注“演示数据”。
- 本页不把 AI 作为卖点，避免业务员在不理解产品的情况下堆概念。

# 地推业务员随身页｜背面话术执行稿

> 用途：业务员内部使用，不递给客户。目标不是一次讲完产品，而是让老板讲出一个真实项目，再用一条链把价值演给他看。

## 8 分钟节奏

- 0–1 分钟：开口。
- 1–3 分钟：追问。
- 3–6 分钟：只演示一条链。
- 6–8 分钟：处理异议并收口。

## 一、开口只说一句

> 老板，你们现在客户改方案、催进度、对收款，平时都在哪儿记？

不要一上来讲功能、讲 AI、讲数字化，也不要说“了解一下贵司”。

## 二、只问四句

1. 最近哪个项目最麻烦？
2. 客户改完以后，谁去通知合同、材料、现场和财务？
3. 客户问“做到哪了”，现在谁回、去哪儿找？
4. 月底这单赚多少，谁说得清？

判断信号：老板开始讲具体项目、具体人、具体群，再打开产品。

## 三、3 分钟只演示一条链

### 1. 打开报价版本

说：

> 你看，这是第几版，签的是哪一版，能回去查。

### 2. 打开变更

说：

> 客户改完以后，后面谁接、到哪一步，不用在群里猜。

### 3. 打开客户手机视图

说：

> 客户自己看自己家，验收要本人确认，员工不能代点。

### 4. 打开项目台账

说：

> 月底看这单，成本不全就显示暂不可确认，不拿 0 算利润。

演示规则：每步只停 10 秒，只演示客户刚才讲的那一个问题，不展开全部菜单。

## 四、价值翻译

- 客户权限：客户只看到自己家。说：不会把别的客户和你的成本给他看。
- 成本口径：成本不全不装懂。说：利润显示暂不可确认，不拿 0 糊弄你。
- 验收责任：业主本人确认。说：员工不能代点，整改前后都有记录。
- 企业资产：人走了记录还在。说：以后客户问起，翻记录，不翻人情。

## 五、老板常说的 5 句话

| 老板说 | 这样接 |
| --- | --- |
| 我们有 Excel 和微信群 | 不换。先把最烦的一单放进来，看能不能少翻一次群。 |
| 员工不会用 | 先一个项目、四个角色，不全公司上；我们陪着走第一遍。 |
| 客户不会看 | 客户只做两件事：看自己家，确认验收。其他不用学。 |
| 我们已经有 ERP | 不抢 ERP。先补你现在看不清、没人维护的那一段。 |
| 太贵了 | 先别比软件价，先算一单漏项、返工、扯皮、回款。不合适就停。 |

## 六、什么时候报价

顺序：先问试点 → 再谈范围 → 最后报年费。

当前标准年费口径：

- 基础版：¥5,980 / 年。
- 专业版：¥11,980 / 年。
- 旗舰版：¥21,800 / 年。

不按客户数收费，不按项目抽成。对外价格、优惠和实施范围以正式报价单为准。

## 七、能说与不能说

能说：

- 客户只看自己家。
- 成本不全显示“暂不可确认”。
- 关键记录能追。
- 先拿一个真实项目试。

不能说：

- 利润一定涨。
- 工期一定不延。
- 员工不用学。
- 所有装企都适合。
- 什么都能做。

## 八、收口

> 我今天不急着让你买。拿你最烦的一单，我用 15 分钟给你走一遍。你觉得像，再叫项目经理和财务一起看。下周哪天方便？

拜访后必须记录：

- 最烦的项目。
- 谁最烦。
- 现在在哪里记。
- 下次谁一起听。
- 是否愿意提供真实项目做一次走查。

## 九、现场禁用词

- 数字化转型。
- 闭环。
- 赋能。
- 生态。
- 全链路。
- 利润一定涨。
- 投诉一定少。
- 员工不用学。
- 我们什么都能做。
- 所有装企都适合。

## 十、成功与停止信号

值得推进：

- 老板开始讲自己公司的真实项目和真实人。
- 老板追问客户能看到什么、不能看到什么。
- 老板问项目经理现在怎么做。
- 老板愿意拿一个真实项目走一遍。

暂时停止：

- 老板只问永久免费，不愿提供真实项目。
- 老板只评价页面好看，不讲现在的问题。
- 老板要求全部定制，不谈验证标准。
- 老板认为员工不需要改变，也不愿让项目经理参与。

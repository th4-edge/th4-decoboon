## 页面回答的四个问题

1. **解决哪些问题**：报价漏项、变更只在群里说、工地靠人追、月底账对不上。
2. **帮装企做什么**：把报价版本、合同、项目履约、变更、材料到货、验收和回款放回同一项目事实链。
3. **提升哪些效率**：报价效率、协同效率、履约效率、核算效率；只表达步骤被合并、信息可追溯，不承诺未经证实的百分比。
4. **为什么需要**：项目变多后靠人记会漏；换系统最怕上不动；客户与经营数据应成为企业资产，而不是留在个人手里。

## 事实与边界

### 可引用事实锚点

- 客户、房屋、报价、合同、项目、履约与验收对象关系：`EV-003`、`BR-001`、`BR-002`。
- 业主查看、阶段任务、现场留证与验收整改：`SCN-003`、`SOL-006`、`DEC-015`、`BR-008`、`EV-037`、`EV-038`。
- 材料到货、实际成本与应付归集：`SOL-002`、`EV-010`、`EV-017`。
- 财务边界“管项目和钱，不管税和账”：`DEC-016`。
- 成本不完整时利润不可确认：`EV-008`。

### 对外表达边界

- 页面未使用客户名称、客户案例、收益比例、行业排名或演示数据冒充真实成效。
- 页面不承诺“一定不漏项”“一定提升利润”“ERP 全部替换”“所有装企都适合”。
- “报价有基线、变更不丢链、下一步到人、赚钱有依据”是流程结果表达，不是收益保证。
- 成本或费用不完整时，系统必须显示“暂不可确认”，不得按 0 计算利润。
- 对外发布前仍需完成用户复核；如用于公开投放，还需按营销智能体流程完成事实门禁、合规门禁和人类接受度检查。

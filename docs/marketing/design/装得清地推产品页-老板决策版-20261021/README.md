## 六个问题怎么回答

### 1. 解决哪些问题

1. 报价改了又改，最后用哪版说不清。
2. 客户改方案，合同、材料、现场、收款没跟上。
3. 业主催进度，验收整改靠口头和群记录。
4. 月底想知道每单赚不赚钱，只能拍脑袋。

### 2. 提升哪些效率

1. 找资料：不用翻群、翻电脑，项目里直接找。
2. 回客户：客户打开手机看自己家，少接重复电话。
3. 交接变更：谁处理、到哪一步、下一步是什么，能接着走。
4. 月底对账：每个项目的应收、已收、待收和付款放在一起。

页面没有编造提升百分比，只表达具体步骤的变化。

### 3. 给你什么保证

“敢保证”只写产品规则和服务边界：

- 客户只看到自己家，不开放内部成本、供应商价和员工资料。
- 成本没录全就显示“暂不可确认”，不拿 0 算利润。
- 报价、合同、变更、验收这些关键事，能按项目找得到。
- 先拿一个真实项目试，范围和验收标准先写清。

同时明确“不保证”：

- 不保证利润一定增长。
- 不保证工期一定不延、回款一定提前。
- 不保证员工不用学、不用改习惯就会用。
- 不保证所有装企都适合，也不承诺替代现有全部系统。

### 4. 带来什么成本

- 钱：按年订阅，按套餐、门店、账号计；实施、迁移、培训按范围确认。
- 时间：要安排老板、项目经理、财务和客户，用真实项目走通。
- 习惯：关键事情要从“群里说一句”改成“项目里留记录”。
- 管理：老板要真的看卡点、追下一步，不是买完就等自动变好。

页面原话：**最贵的不是软件费，是买了不用；最省的不是便宜，是少返工、少扯皮、少漏账。**

## 事实与边界

### 可引用事实锚点

- 客户、房屋、报价、合同、项目、履约与验收对象关系：`EV-003`、`BR-001`、`BR-002`。
- 客户查看、阶段任务、现场留证与验收整改：`SCN-003`、`SOL-006`、`DEC-015`、`BR-008`、`EV-037`、`EV-038`。
- 材料到货、实际成本与应付归集：`SOL-002`、`EV-010`、`EV-017`。
- 财务边界“管项目和钱，不管税和账”：`DEC-016`。
- 成本不完整时利润不可确认：`EV-008`。
- 客户只看本人被授权项目；内部成本、供应商价格、员工数据和其它项目不开放：`SOL-006`、`SOL-002`、`EV-005`。

### 必须保留的表达边界

- 不把“敢保证”写成收益保证；页面已区分“产品规则保证”和“经营结果不保证”。
- 不承诺利润、工期、回款、客户满意或员工零学习成本。
- 不把标准年费写成最终成交价；正式价格、优惠、实施范围和服务内容必须以正式报价单/合同为准。
- 不承诺全部替换 ERP 或适配所有装企。
- 不把“客户可以看到”写成“客户审批所有环节”。
- 页面不含客户名称、真实项目地址、真实手机号或未授权案例。

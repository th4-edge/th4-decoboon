## 解决哪些问题，提升哪些效率？

不讲百分比。先看你原来要重复做几次，用了以后能不能少做一步、少翻一次、少问一遍。

### 解决哪些问题

1. 报价改了又改，最后用哪版说不清。签约依据要能回去查，不靠文件名猜。
2. 客户改方案，后面的事没跟上。合同、材料、现场、收款要跟着一起走。
3. 业主催进度，验收整改靠口头和群记录。客户自己看，确认和整改有记录。
4. 月底想知道每单赚不赚钱，只能拍脑袋。成本不全就不装懂，利润显示“暂不可确认”。

### 提升哪些效率

1. 找资料：不用翻群、翻电脑。项目里直接找，照片、报价、合同、记录跟着项目走。
2. 回客户：不用每次都人工解释。客户打开手机看自己家，少接重复电话。
3. 交接变更：不用群里说一句就算完。谁处理、到哪一步、下一步是什么，能接着往下走。
4. 月底对账：不用东拼西凑。每个项目的应收、已收、待收和付款放在一起。

## 哪些敢保证，哪些不保证

不靠“肯定有效”卖软件。能写进规则的写清楚，不能承诺的也提前说明。

### 我们敢保证的

- 客户只看到自己家，不开放内部成本、供应商价和员工资料。
- 成本没录全，就显示“暂不可确认”，不拿 0 算利润。
- 报价、合同、变更、验收这些关键事，能按项目找得到。
- 先拿一个真实项目试，范围和验收标准先写清。

这些是产品规则和服务边界，不是收益承诺。

### 我们不能保证的

- 不保证你用了利润一定增长。
- 不保证工期一定不延、回款一定提前。
- 不保证员工不用学、不用改习惯就会用。
- 不保证所有装企都适合，也不承诺替代你现有全部系统。

结果取决于你的报价、采购、施工、回款和管理执行。

## 你要付出的，不只是钱

1. 钱：按年订阅。按套餐、门店和账号计；实施、迁移、培训按范围确认。
2. 时间：要有人跑一遍。安排老板、项目经理、财务和客户，用真实项目走通。
3. 习惯：从群里搬到项目里。关键事情要留记录，不能只说一句“群里说过了”。
4. 管理：老板要真的看。看卡点、追下一步，不是买完就等系统自动变好。

最贵的不是软件费，是买了不用；最省的不是便宜，是少返工、少扯皮、少漏账。

## 六、执行与核对命令

导入当前企业报价项目库：

```bash
mysql -h127.0.0.1 -uroot -pmysqladmin decoboon < data/import/maihong-9.5/import.sql
```

生成业务数据：

```bash
python3 scripts/seed-maihong-business-scenarios.py
```

核对数据：

```bash
python3 scripts/verify-maihong-business-simulation.py
```

脚本按 manifest 幂等续跑，已完成对象不会重复创建。

## 七、当前业务边界

1. 项目验收只能由业主本人授权会话确认，员工不能代确认。因此项目批次停在“验收待业主确认”，没有伪造 Finished 项目。
2. 客户接受报价后设计锁定；谈单 PPT 必须在此之前生成。本次首次执行的部分已接受案例没有补做 PPT，脚本已修正为先生成 PPT 再接受报价。
3. 麦鸿历史导入没有独立真实采购成本，当前成本来自导入口径，不能作为真实毛利结论。
4. 演示手机号使用 `13910000001` 至 `13910000044`，仅用于本地展示，不用于短信或生产。

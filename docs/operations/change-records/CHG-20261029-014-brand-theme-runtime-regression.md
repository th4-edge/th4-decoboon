## 2. 目标与范围

- 目标：修复企业信息编辑时原生 TabBar API 报错，以及深色企业品牌 Logo 首字被误判为黑色。
- 范围内：App 品牌主题 chrome 应用、Logo 首字对比度、品牌契约。
- 非范围：Web 主题算法、企业字段、权限和业务状态。

## 3. 业务与决策

- 装企品牌色继续作为应用主题主源。
- App 使用自定义 TabBar，不调用原生 `setTabBarStyle`。
- Logo 首字属于大字号品牌标记，使用 3:1 对比度阈值；正文仍使用 4.5:1。

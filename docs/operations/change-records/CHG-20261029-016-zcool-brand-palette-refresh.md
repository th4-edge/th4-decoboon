## 2. 目标与范围

- 目标：根据站酷高赞 B 端样本的浅中性画布、单一低饱和强调色原则，重做装企推荐品牌色。
- 范围内：App/Web 默认色、推荐色板、品牌色说明、主题派生默认值。
- 非范围：业务状态色、权限、字段、合同/PDF 快照。

## 3. 业务与决策

- 装得清产品默认色继续保留 `#16A394`；松石墨绿 `#2F6E63` 作为企业可选主题，不替换平台产品色。
- 删除科技蓝、亮紫、橙棕等不符合长期业务工作台的推荐色。
- 所有基色与白字对比度不低于 4.5:1。
- 页面大背景继续使用装得清中性产品色。

## 4. 验收条件

| 序号 | 场景 | 预期结果 |
| --- | --- | --- |
| 1 | 默认品牌 | 装得清原有产品品牌色 `#16A394` |
| 2 | 推荐色板 | 松石墨绿、青瓷、岩蓝、赤陶、胡桃、黛紫、墨灰 |
| 3 | App 点击岩蓝 | `#2F6E63 → #4F708C`，取消恢复 |
| 4 | Web 点击岩蓝 | root/Element Plus 立即变为 `#4F708C`，取消恢复 |
| 5 | 移动端对比度 | 所有推荐基色白字至少 4.5:1 |

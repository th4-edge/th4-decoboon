## 2. 目标与范围

- 目标：停止窗口回焦/页面重新可见时无条件刷新完整登录会话，消除重复 `auth/session/info` 请求及错误的最近登录时间重写。
- 范围内：Web 根组件品牌主题监听；会话 Store 的最近登录记忆写入时机；浏览器请求计数回归。
- 非范围：登录协议、`auth/session/info` 后端实现、企业品牌字段、主题 Token、权限和数据范围。
- 受影响端：Web

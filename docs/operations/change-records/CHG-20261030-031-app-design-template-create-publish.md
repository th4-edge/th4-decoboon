## 2. 目标与范围

- 目标：补齐 App 设计模板创建、草稿区域维护、分项公式维护和发布主链。
- 范围内：
  - App 新建模板基础信息；
  - 草稿区域新增/编辑/删除；
  - 报价项目库分项选择、公式或固定数量维护、删除；
  - 发布前校验与发布；
  - 模板库状态筛选、新建入口、草稿继续编辑入口。
- 非范围：
  - App 模板复制、停用、已发布模板新建版本；
  - 价格、成本、供应商历史价展示；
  - 后端 DDL、权限语义修改和生产发布。
- 受影响端：App、Web（Web 仅清理未使用的单行模板分项 API 包装）。

## 3. 业务与决策

- 业务依据：
  - `DEC-084`：App/Web 设计模板双端完整；
  - `DEC-050`：模版归属、Draft/Published/Disabled、发布不可变、实例化快照；
  - `BR-040`：模板不含价格/成本，公式使用专业变量，发布前校验区域、项目库、单位和公式；
  - `OBJ-005`：模板对象定义。
- 不改变：模板状态机、权限矩阵、后端公式求值、报价金额/成本/利润口径。
- 尚存缺口：
  - App 复制、停用、已发布模板新建版本；
  - 真实开发者工具/真机模板编辑与发布复核；
  - `GAP-WEB-025` 房屋删除仍独立待裁决。

## 10. 复盘与沉淀

- 是否出现重复问题：模板编辑与发布只有 Web 入口，App 无法完成资产沉淀。
- 是否需要新增门禁：已有模板后端测试和 Provider 巡检；真实页面门禁待下一阶段。
- 候选 `EXP/ANT/PATH`：
  - `PATH`：先保证草稿生命周期闭环，再做复制、停用和版本管理；
  - `ANT`：在编辑器中用前端默认公式或默认价格伪装完成；
  - `EXP`：草稿只允许编辑，发布后不可直接修改；公式/固定数量由服务端权威校验。
- 后续动作与负责人：用户真机复核模板创建/区域/分项/发布；随后实现复制、停用、已发布模板新建版本。负责人：用户 + codex。

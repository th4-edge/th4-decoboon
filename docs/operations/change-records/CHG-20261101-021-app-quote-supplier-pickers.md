## 2. 目标与范围

- 目标：清除 App 合同来源报价和供应商价格中的普通下拉、全量数组、200 条固定页和弱回显。
- 范围内：
  - 新增客户已确认报价专用选择页、一次性回传通道、路由和权限。
  - 合同创建页改用全宽报价业务卡，移除报价大数组和显示文本反查。
  - 供应商选择页改为服务端关键词/类型/状态分页。
  - 供应商价格页接入 `supplier-picker` 与现有 `CatalogPicker`。
  - 采购价编辑按 ID 精确回读，不再拉取全部采购价、供应商和报价项目。
  - 报价、供应商、采购价 Provider 改为数据库分页；供应商应付摘要批量聚合，移除逐供应商 N+1。
  - 增加契约与后端定向测试。
- 非范围：不修改合同状态机、价格公式、成本/利润口径、付款规则、供应商保存规则、权限角色矩阵或数据库结构。
- 受影响端：后端、App。

## 3. 业务与决策

- 是否涉及业务对象、状态、权限、金额、成本、利润、支付或数据范围：涉及报价/供应商/报价库对象读取及成本页回显；不改变公式和权限结论。
- 业务事实来源与裁决编号：`DEC-021` / `BR-019`、`BR-059` / `OBJ-010`、`DEC-095` / `BR-060`；跨端规范 `docs/design/35-业务对象选择器与选择结果展示规范.md`。
- 尚存 GAP 或假设置：当前租户没有采购价记录，采购价编辑态用 Provider 单测和精确查询覆盖，未做有数据编辑保存；未做微信真机和独立验收。

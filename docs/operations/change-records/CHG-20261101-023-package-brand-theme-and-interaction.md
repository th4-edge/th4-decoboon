## 2. 目标与范围

- 目标：让套餐交互使用企业品牌色；避免颜色过浅导致主按钮白字不可读；修正套餐步骤可跳过未完成项和关键动作热区偏小的问题。
- 范围内：企业品牌色选择与预览、运行时 CSS 变量、套餐管理/配置/选择页、套餐步骤导航、套餐动作热区、企业资料 Provider 响应契约。
- 非范围：调整套餐价格或成本口径；修改成功/警告/风险语义色；新增租户级 Logo；生产发布。
- 受影响端：App、后端。

## 3. 业务与决策

- 是否涉及业务对象、状态、权限、金额、成本、利润、支付或数据范围：否；仅有既有 `Company.color` 的展示与输入闭环。
- 业务事实来源与裁决编号：`docs/租户设计方案.md` 企业档案包含品牌色；UI 继续遵守 `DEC-095`/`BR-060` 内部编号隐藏。
- 尚存 GAP 或假设置：品牌色只用于承载品牌主操作与选中态，不代替成功、警告、风险状态色；自定义输入只接受 `#RRGGBB`。

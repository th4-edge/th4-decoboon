## 2. 目标与范围

- 目标：移除套餐选品固定 `size: 200` 与客户端全量过滤，改为服务端关键词分页；保证跨页选择不丢失，加载失败可恢复。
- 范围内：App `CatalogPickerSheet`、套餐项目库查询调用、选择器静态契约与负向夹具。
- 非范围：报价项目字段、价格、成本、权限、套餐金额公式、后端 Provider 语义、生产发布。
- 受影响端：App。

## 3. 业务与决策

- 是否涉及业务对象、状态、权限、金额、成本、利润、支付或数据范围：否；仅改变既有报价项目库的检索与分页方式。
- 业务事实来源与裁决编号：BR-001、BR-002、DEC-071、OBJ-010；选择器规范见设计 35 与本次 T15/T16 评审。
- 尚存 GAP 或假设置：无；`catalog/item/page` 已支持类型、关键词和分页。

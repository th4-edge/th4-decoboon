- 非主材项目生成履约任务；主材、定制、软装、电器生成材料计划。
- 合同变更新增/替换定制、软装、电器、综合项目时同步生成履约对象。
- 自定义报价面积无效时回退房屋面积，仍无有效面积则阻断报价。
- 套餐调整额改为与面积折算后的套餐基准金额比较。
- 合同页补齐折前明细、合同金额、折扣/税金调整勾稽。
- 合同页和报价详情移除内部 Q/C/P 编号，修正套餐无设计来源文案。

## 2. 目标与范围

- 目标：把 Figma Make 中实际可访问的经营总览、智能报价、财务中心和共享壳层转为可实施的 Web UI 规范与机器可读 Token 基线；接入 Figma 靛紫可选主题；固化字体与壳层决策。
- 范围内：页面结构、响应式、颜色、字体、间距、圆角、阴影、动效、组件、交互状态、可访问性、与现有 Web Token 的映射及缺口；`COMPANY_BRAND_PRESETS` 的“云序紫”可选主题；字体与壳层决策说明及契约检查。
- 非范围：业务规则、权限、金额/成本/利润公式、Provider、运行时代码、小程序设计、品牌最终裁决和独立验收。
- 受影响端：Web 文档与设计参考；运行时视觉真源仍为 `src/styles/tokens.scss`。

## 3. 业务与决策

- 是否涉及业务对象、状态、权限、金额、成本、利润、支付或数据范围：否；仅整理设计与交互边界。
- 业务事实来源与裁决编号：不适用。
- 用户裁决：Figma 靛紫 `#5B5CE2` 仅作为企业可选主题“云序紫”，装得清默认品牌绿色 `#2F7D5A` 保持不变。
- 用户裁决：字体继续使用生产系统字体栈，不加载远程 Web 字体；壳层继续使用 236px 侧栏、64px 顶栏、1440px 内容最大宽度和 32px 左右边距。
- 尚存 GAP 或假设置：字号偏小、弱文本对比度不足、部分业务动作仅为本地演示、移动导航覆盖不全；已在规范中以 `UI-GAP-01` 至 `UI-GAP-08` 标记。

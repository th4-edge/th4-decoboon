# CHG-20261110-003 · Web 全站无关文案与 AI 腔收敛

## 1. 基本信息

| 字段 | 内容 |
| --- | --- |
| 变更 ID | CHG-20261110-003 |
| 类型 | 文案 / UI 收敛 |
| 风险级别 | L1 |
| 状态 | 开发完成，待用户查看 |
| 负责人 | Codex |
| 日期 | 2026-11-10 |
| 关联需求/业务裁决 | 用户要求去除 Web 系统所有无关文案，特别是 AI 味道的解释性描述 |

## 2. 目标与范围

- 目标：让 Web 界面只保留业务对象、动作、状态、必要警告和恢复信息，删除营销话术、界面自述、重复状态与 AI 腔描述。
- 范围内：共享页面头、面板、工作台入口卡、Boss 经营总览、设计师工作台入口说明、文案门禁规范。
- 非范围：业务字段、权限、金额、状态机、接口、操作顺序和必要错误恢复文案。
- 受影响端：Web。

## 3. 改动

1. `PageHeader` 不再渲染页面摘要。
2. `PanelCard` 不再渲染面板描述。
3. `WorkbenchEntryCard` 只保留入口名称和进入动作。
4. Boss 经营总览删除重复说明、重复成本提示、可见风险级别文字和顶部重复面包屑。
5. 工作台入口和设计工作台删除区域说明、图表说明和底部权限注脚。
6. `check:ai-flavor` 增加“解释界面本身”规则，并锁定共享组件不再恢复描述渲染。

## 4. 保留内容

- `暂不可确认`、加载、失败、无权限、空态恢复。
- 金额、日期、项目、客户、状态、责任人。
- 成本不完整、付款/收款、合同、权限等高风险警告。
- 字段级必要约束和表单错误。

## 5. 验收条件

| 序号 | 场景 | 预期结果 |
| --- | --- | --- |
| 1 | Boss 经营总览 | 不再出现漏斗重复数字、重复状态标签、重复成本提示、说明性段落 |
| 2 | 全站页面头 | 不再展示页面摘要 |
| 3 | 全站面板 | 不再展示面板描述 |
| 4 | 工作台入口 | 只展示名称与进入动作 |
| 5 | AI 腔门禁 | 命中营销词或界面自述时失败 |
| 6 | 业务恢复 | 错误、空态、权限、成本和金额提示仍存在 |

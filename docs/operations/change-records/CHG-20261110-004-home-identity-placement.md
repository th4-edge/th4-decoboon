## 2. 目标与范围

- 目标：企业负责人首页左上角只显示公司 Logo 和公司名称，右上角只显示当前用户姓名与角色。
- 范围内：Boss 壳层、桌面侧栏、顶栏、移动抽屉、首页页头。
- 非范围：权限、数据范围、Provider、业务动作、金额和状态。

## 3. 改动

1. 恢复行业通用身份布局：侧栏顶部为公司 Logo 与公司名称。
2. 顶栏右侧为用户头像、姓名和角色。
3. 顶栏用户区不再重复显示数据范围，数据范围保留在账号菜单内。
4. 门店维度从右侧移到顶栏左侧。
5. 首页页头移除重复用户姓名与“负责人工作台”眉题，只保留“经营总览”和经营摘要。
6. 本地造数企业标题改为“昭青家装”，员工显示名改为张伟等常规姓名。

## 4. 验收

| 场景 | 预期 |

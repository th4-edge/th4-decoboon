## 2. 目标与范围

- 目标：移除 Web 业务界面中与业务动作无关的员工、企业、报价、合同、项目、方案、费用等内部编号，降低认知负担；新增稳定门禁防止后续页面重新暴露内部标识。
- 范围内：Web 个人中心、企业信息、项目/报价/合同/方案/费用/凭证相关页面、业务选择器和搜索提示、构建门禁。
- 非范围：数据库主键、Provider 契约、数据权限、状态机、金额、审计、二维码协议、法定打印模板和 App/Admin 本批存量页面。
- 受影响端：Web；业务规则对 App/Web/Admin 后续页面生效。

## 3. 业务与决策

- 是否涉及业务对象、状态、权限、金额、成本、利润、支付或数据范围：涉及信息展示与可见性，不改变事实、权限或金额。
- 业务事实来源与裁决编号：`DEC-095`、`BR-060`、`USER-DEC-20261029-008`。
- 尚存 GAP 或假设置：无。
- 核心口径：编号保留在数据、接口、权限、审计、二维码和法定单据中，但不进入默认业务界面。
- 例外：统一社会信用代码、法定证照号码、发票法定号码和凭证套打模板所需号码。

- 是否出现重复问题：是，内部编号在多端页面被当作“专业信息”展示。
- 是否需要新增门禁：是；`check:identifier-exposure` 已纳入 Web build 与 AGENTS 必跑清单。

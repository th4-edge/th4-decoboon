## 2. 目标与范围

- 目标：按“客户卡片场景”生成 Web 客户概念交互原型，验证企业负责人、店长、财务三种角色投影。
- 范围内：角色统计、门店筛选、负责人分组、客户卡片、业务链摘要、客户详情抽屉、七态和交互预演。
- 非范围：生产页面替换、后端 Provider、权限、金额/成本/状态机、DDL、真实 Provider 接入、正式发布。
- 受影响端：Web 原型；后端、App、数据库均未修改。

## 3. 业务与决策

- 是否涉及业务对象、状态、权限、金额、成本、利润、支付或数据范围：仅展示能力结构，使用示例数据
- 业务事实来源与裁决编号：`USER-DEC-20261029-007`、客户页面能力清单、客户页面规则 v2
- 尚存 GAP 或假设置：企业负责人统计可复用现有 App Provider 形态；店长统计、财务客户聚合字段在真实生产落地前需 Provider 对账

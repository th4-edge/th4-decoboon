## 2. 目标与范围

- 目标：Boss、店长、财务复用同一客户工作面；业务员、设计师、项目经理按责任关系读取客户；列表过滤、分组、计数和分页全部下沉数据库。
- 范围内：
  - 小程序管理层客户页统一为负责人分栏工作区；
  - 店长固定本店范围，Boss 保留企业范围和门店筛选；
  - 财务沿用同一布局，但无设计师派单；
  - 业务员本人负责客户；
  - 设计师本人维护客户 ∪ 指派给本人设计的客户；
  - 项目经理本人负责项目的关联客户；
  - 客户经营概览改为聚合查询 + 数据库分页；
  - 客户分页与项目经理客户分页改为数据库分页；
  - 新增项目负责人客户查询索引迁移。
- 非范围：客户金额公式、合同、财务成本利润、客户状态机、正式发布。
- 受影响端：后端 / App / Web / 数据库迁移。

## 3. 业务与决策

- 是否涉及业务对象、状态、权限、金额、成本、利润、支付或数据范围：涉及角色权限与数据范围；不改变既有金额公式和状态机。
- 业务事实来源与裁决编号：`USER-DEC-20261029-010`、`USER-DEC-20261029-009`、`DEC-065`、`DEC-067`、`DEC-080`、`DEC-082`。
- 尚存 GAP 或假设置：无；新用户决策明确要求统一客户工作面。

- 是否出现重复问题：是；上一批只统一了财务与 Boss 的分组数据，未统一负责人分组页面结构。

  暴露出**迁移账本 `db_schema_migration` 与真实 schema 不一致**，故做全量对账。

## 对账方法

```bash
# 1) 账本已登记版本
mysql -N -e "SELECT version FROM db_schema_migration ORDER BY CAST(version AS UNSIGNED)"
# 2) 迁移目录全部版本
ls docs/design/migrations/*.sql | sed -E 's#^([0-9]+)-.*#\1#' | sort -nu
# 3) 差集 = 有文件但未登记；再逐个到生产库验证「该迁移的签名（表/列）是否存在」
```

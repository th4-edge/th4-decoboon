# INC-20261102-FIN-LIST-TRACE 财务列表可追溯性缺陷

## 1. 分类与影响

- 分类：`code_bug`
- 发现时间：2026-11-02
- 影响端：Web 财务角色；部分查询契约涉及共享财务 Provider
- 影响：项目资金流水只显示最近 12 条且完整入口丢失项目筛选；提成调整、工资项、月度考勤固定查询 200 条；应收应付选择器状态筛选仅作用于当前页；财务工作台将前 8 条列表长度显示为总笔数。
- 数据影响：只读展示与检索缺陷，未发现金额落库错误、越权或数据删除。
- 紧急处置：不直接改生产数据；从 `prod` 建独立热修分支，完成验证后按用户确认发布。

## 2. 根因

- 增长型列表与详情摘要边界未统一：`recent/top N` 被页面当作完整集合。
- 前端保留固定大页查询（`size=200`），未接入服务端翻页。
- 项目上下文通过 URL 传递但目标页面未消费。
- 选择器将状态筛选放在客户端当前页执行。

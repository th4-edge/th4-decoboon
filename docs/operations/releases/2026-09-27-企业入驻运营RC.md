## 7. 已知边界与风险

- 最近登录时间来自 `Credentials.lastTime`，只代表重新登录时间；用户保持登录时需后续增加事件活跃时间。
- 入驻台账当前按筛选后的企业集合在应用层聚合；企业规模增长后需改为专用只读报表或事件聚合。
- 完整手机号揭示已按角色授权，但隐私保留期、离职后号码处理和导出审批仍需业务智能体正式裁决。
- Admin 工程当前不是独立 Git 仓库，本轮前端变更尚未形成提交，必须先补建仓库和发布归档。
- 本 RC 不含内容运营、消息群发、活动、实验和自动化服务任务。

## 2. 变更内容

- `WechatMiniProgramClient.unlimitedQrCode(scene, page, envVersion)`：复用既有 access_token 进程内缓存；`check_path=false`（发布前可生成）；微信返回 JSON 错误时显式失败并记录 errcode/errmsg，禁止把错误 JSON 当图片落库。
- `project/owner-qrcode/build`（Security + 项目可见性）：scene = 项目编号；图片落私有存储 `owner-qrcode/{comId}/{projectId}-{env}.jpg`（**键含版本环境**，避免切环境复用旧码）；幂等复用；返回短期签名地址。
- `identity/customer-access/scan-enter`（Security）：scene → 项目 → 以**房屋所属客户**档案手机号比对授权手机号 → upsert `CustomerAccess`（`invite` 为空，锁键与邀请接受一致）。
- 安全基线：路由 477 → **479**（public 16 + protected 463）；两条新路由未登录 401 已入用例。
- App：项目详情新增「业主项目码」入口；新页 `subpackages/project/pages/owner-qrcode`（保存相册/复制说明/刷新/体验版提示）；业主入口页支持 `scene`。

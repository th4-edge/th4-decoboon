## 3. 发布步骤（窗口内执行，逐条可复制）

> 前置：**执行生产动作前必须由用户确认窗口**；`deploy-prod.sh` 会重启 systemd 并做 HTTPS 冒烟，失败自动回滚到 `/opt/decoboon/releases/.previous`。

```bash
# ── 0) 本地构建发布包（已验证：117/118 正迁移与回滚脚本均进包）
bash scripts/build-release.sh
R=$(ls -td dist/releases/*/ | head -1); echo "$R"
ls "$R" | grep -E '11[78]-.*\.sql'                      # 正迁移
ls "$R/rollback" | grep -E '11[78]-.*\.sql'             # 回滚脚本（2026-10-15 起随包交付）
(cd "$R" && shasum -a 256 -c SHA256SUMS)                 # 校验发布包

# ── 1) 生产备份（失败即停止，不得跳过）
ssh root@120.55.15.159 'STAMP=$(date +%Y%m%d%H%M%S); mkdir -p /backup/th4-decoboon/$STAMP &&   mysqldump --single-transaction --routines --triggers decoboon > /backup/th4-decoboon/$STAMP/decoboon.sql &&   ls -l /backup/th4-decoboon/$STAMP'

# ── 2) 执行迁移 117、118（账本登记；遇 CHECKSUM_DRIFT 立即停止）
#    按 docs/design/migrations/19-生产发布基线.md §3：上传迁移目录后执行 run-migrations
#    目标版本：117（主材下单作业单）→ 118（主材采购结算）

# ── 3) 发布应用（含重启 + HTTPS 冒烟 + 失败自动回滚）
bash scripts/deploy-prod.sh --release-dir "$R"

# ── 4) 回滚（如需）
bash scripts/rollback-prod.sh            # 默认回滚到 .previous
# 数据库回滚按逆序：rollback/118-主材采购结算-rollback.sql → rollback/117-主材下单作业单-rollback.sql
# 回滚数据库必须同步回退代码，否则 ddl-auto=validate 启动失败
```

**窗口执行需要用户提供/确认**：① 窗口时间；② BOSS 登录口令（§4 冒烟用例 2–10 需认证调用）；③ 是否授权执行 `deploy-prod.sh`（含 systemd 重启）。

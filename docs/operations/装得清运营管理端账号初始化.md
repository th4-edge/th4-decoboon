# 装得清运营管理端账号初始化

## 1. 目标

在不提供演示账号的前提下，初始化第一个真实平台运营超级管理员账号。初始化器默认关闭，只有显式设置环境变量才会执行。

## 2. 前置条件

- 数据库已执行 `24-运营管理端基础.sql`。
- 后端使用真实 MySQL/Redis 配置。
- `server.port` 或反向代理 `/api/` 已配置。
- 初始化手机号未绑定其他客户企业。

## 3. 启动参数

```bash
export PLATFORM_BOOTSTRAP_ENABLED=true
export PLATFORM_BOOTSTRAP_COMPANY_TITLE='装得清平台运营中心'
export PLATFORM_BOOTSTRAP_COMPANY_NAME='平台运营'
export PLATFORM_BOOTSTRAP_PHONE='<平台运营手机号>'
export PLATFORM_BOOTSTRAP_PASSWORD='<至少8位且含字母数字>'
```

然后启动后端：

```bash
./run-dev.sh
```

生产环境不要将密码写入仓库、文档或聊天记录。初始化完成后必须：

```bash
export PLATFORM_BOOTSTRAP_ENABLED=false
```

并重启后端或从生产环境中删除相关环境变量。

## 4. 初始化行为

- 按企业名称查找平台运营企业；不存在则创建。
- 将企业标记为 `Company.platform=true`。
- 创建默认总店。
- 创建或复用平台 Boss 员工。
- 创建或更新 BCrypt 密码凭证。
- 不创建演示企业、演示订阅或演示订单。
- 不记录明文密码。

## 5. 冲突处理

以下情况启动会失败，避免错误提升权限：

- 手机号已属于其他企业。
- 已有员工不是 Boss。
- 企业名称非法。
- 密码不符合策略。
- 未提供手机号或密码。

## 6. 首次登录验证

1. 打开 `th4-decoboon-admin`。
2. 使用平台运营手机号和密码登录。
3. 确认进入运营总览。
4. 确认企业列表显示的客户企业来自后端数据库。
5. 确认操作审计为空或只有真实人工操作记录。
6. 确认普通客户企业账号无法访问平台路由。

## 7. 初始化后的安全动作

- 关闭 bootstrap 开关。
- 修改初始密码并确认 BCrypt 已更新。
- 在 `docs/product/装得清运营管理端用户组织与权限设计.md` 的 Phase 2 实施后，按岗位拆分账号。
- 为平台账号建立定期复核和离岗回收流程。

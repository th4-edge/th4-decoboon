# 2026-09-16 装得清运营管理端实施基线

## 1. 结论

首版 `th4-decoboon-admin` 采用 Vite + Vue 3 + TypeScript + Element Plus 构建，定位为平台内部运营与运维控制台，而不是租户业务 Web 的重复实现。

## 2. 交付范围

### 已完成

- 独立 admin 工程和登录态。
- 运营总览、客户企业、订阅与续费、增长运营、套餐策略、系统运维、操作审计。
- 平台运营企业白名单和 Boss 权限。
- 跨企业只读查询。
- 人工续费、套餐、席位、门店、状态调整。
- 操作审计表与查询。
- 资源、依赖服务、运行时长监控。
- 前端真实 API 门禁，不允许 mock、演示账号或断网回退。
- 数据库迁移脚本。

### 不在首版

- 线上支付退款/发票后台。
- 企业员工明细、客户隐私正文和项目正文跨租户浏览。
- SSH 命令执行、数据库 SQL 控制台。
- 直接修改服务器配置。
- 自动营销群发。

## 3. 技术边界

- 前端：`../../前端代码/th4-decoboon-admin`
- 用户组织：`docs/product/装得清运营管理端用户组织与权限设计.md`
- 实时对接：`docs/operations/装得清运营管理端实时后端对接.md`
- 账号初始化：`docs/operations/装得清运营管理端账号初始化.md`
- 后端：`com.th4.edge.platform`
- 数据迁移：`docs/design/migrations/24-运营管理端基础.sql`
- 系统指标：OSHI + JVM + DataSource + Redis 即时采样。
- 首次初始化：默认关闭的 `PlatformAdminBootstrap`，通过 `PLATFORM_BOOTSTRAP_*` 显式创建平台运营 Boss。
- 审计：MySQL 关系表，不使用日志文本作为事实来源。

## 4. 权限基线

- 平台运营企业：`db_tenant_company.platform = true`
- 操作员角色：`EmployeeRole.Boss`
- 普通企业账号：禁止访问 `platform/*` 路由。
- 人工写操作：必须填写原因，写审计。
- 只读查询：不得返回密码、密钥、连接串和隐私正文。

## 5. 验收门禁

- `th4-decoboon-admin`：`npm run type-check`、`npm run build`。
- `th4-decoboon`：`mvn -o -q -DskipTests compile`、平台验收测试、Provider Security 测试。
- 浏览器：登录、7 个路由、订阅调整对话框、成功回执、无 console error。
- 后端：普通企业 token 访问平台路由返回 403；匿名返回 401。
- 数据：订阅调整后服务期、席位、门店和审计同步变化。

## 6. 上线前置

1. 在目标库创建/标记平台运营企业。
2. 创建平台运营负责人 Employee 和 BCrypt Credentials。
3. 执行迁移 `24-运营管理端基础.sql`。
4. 构建 admin 静态资源并配置独立域名或路径。
5. Nginx 反向代理 `/api/` 到后端。
6. 完成生产只读冒烟和一次可回滚的人工订阅调整演练。

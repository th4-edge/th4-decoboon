## 四、客户分级 A/B/C 自动规则

### 4.1 评分模型（0–100，可解释）

```text
总分 = 需求明确(0-30) + 预算匹配(0-25) + 时间紧迫(0-20)
     + 互动深度(0-15) + 跟进时效(0-10) - 负向扣分
```

| 维度 | 计分 |
|---|---|
| 需求明确 (0-30) | 已量房 +12；画像关键项（P2 动机 / P3 现状 / P4 开工时间 / P5 风格 / P1 决策角色）每完成 1 项 +6，上限 30 |
| 预算匹配 (0-25) | 按企业配置区间：高预算 25 / 达标 18 / 低于均值 10 / 未填 0 |
| 时间紧迫 (0-20) | 1个月内 20 / 1-3个月 14 / 3-6个月 8 / 半年以上 3 / 待定 0 |
| 互动深度 (0-15) | 到店每次 +2（上限 6）；已加微 +3；已完成量房 +6 |
| 跟进时效 (0-10) | 最近跟进 ≤3天 10 / 4-7天 6 / 8-15天 2 / >15天 0 |
| 负向扣分 | 命中「预算不实 / 同行 / 爽约」标签各 −10；逾期未跟进 −5 |

### 4.2 分级阈值

| 分级 | 分数 | 含义 | 默认动作 |
|---|---|---|---|
| A | ≥ 75 | 高价值、重点跟进 | 提醒优先、置顶、店长可见 |
| B | 50–74 | 标准培育 | 按节奏跟进 |
| C | < 50 | 低优先/待培育 | 进入培育名单 |

规则要点：

- 分数与分级**由服务端按期重算**，前端只读展示。
- 每条分级必须能展示"为什么是这个分"（各维度得分 + 命中项），保证可解释。
- 阈值与预算区间为**企业可配置**；未配置时使用默认值。
- 客户进入 `lost` 阶段时直接判为 C，不参与 A/B。

## 五、客户标签体系

### 5.1 标签分类

| 分类 | 示例 | 生成方式 |
|---|---|---|
| 来源标签 | 抖音、小红书、转介绍、老客户、自然到店 | 系统（来自 source） |
| 行为标签 | 已加微信、已到店、已量房、看过报价、多次到店 | 系统（来自行为事实） |
| 意向标签 | 急装修、婚房、学区房、改善、投资出租、局改 | 人工 + 规则 |
| 需求标签 | 毛坯新房、旧房翻新、精装改造、全屋整装 | 人工 |
| 偏好标签 | 现代简约、轻奢、新中式、奶油风 | 人工（可由画像 P5 派生） |
| 价值标签 | 高意向、高预算、决策人、价格敏感、比价多 | 人工 + 规则 |
| 风险标签 | 长期未跟进、预算不实、同行、爽约 | 规则 + 人工 |

> Q5 已确认：**画像字段设计师可编辑**，但限定范围为「`customer.designer` 为当前员工」的客户；标签字典仍只有老板/店长可维护。

- 系统标签由事实自动生成，不可人工删除。
- 标签字典停用后不再可选，历史关联保留。

### 5.3 标签使用

1. 列表按标签多选筛选；
2. 组合筛选（分级 + 标签 + 提醒 + 阶段）；
3. 触发提醒（见第六节）；
4. 分派与协作依据；
5. 统计维度（成交客户共性标签）。

## 六、提醒规则（D5 冻结）

| 编号 | 条件 | 颜色 | 动作 |
|---|---|---|---|
| R1 | A 级客户且距上次跟进 > 3 天未跟进 | 红 | 置顶 + 高亮提醒 |
| R2 | 未流失客户且已逾期未跟进 | 红 | 提醒 + 可筛选 |
| R3 | 建档 ≤3 天且尚未首联（黄金期） | 橙 | 提醒 + 可筛选 |
| R4 | 待量房且 >3 天未推进 | 橙 | 提醒 + 可筛选 |
| R5 | A 级客户今日应跟进 | 蓝/高亮 | 置顶 |

约束：

- 提醒仅展示/排序/筛选，**不阻断**任何业务动作。
- 提醒必须可解释（显示触发条件与时间）。
- 提醒可筛选，客户列表新增「提醒」筛选组：待跟进 / 已逾期 / 黄金期 / 待量房 / 风险。

## 八、数据与权限

- 标签、画像、分级均归属 `company`，遵循 `OBJ-001` 归属链与现有数据范围（`@DataPermission`）。
- 画像修改留痕：操作人、时间、字段、旧值、新值。
- 分级为**派生值**，允许不落库按需计算，或缓存并标注计算时间；无论哪种都必须可解释。
- 前端隐藏不构成权限，服务端必须校验。

## 九、验收标准

1. 业务员不能新建/改名/删除标签字典项（服务端拒绝）。
2. 系统标签不可手工删除。
3. A/B/C 分级规则可复算、可解释，每条展示得分明细。
4. A 级客户 3 天未跟进，客户列表与客户 360 均出现红色提醒，且可被筛出。
5. 提醒不改变客户阶段、不可阻断任何动作。
6. 标签/画像/提醒严格按 `company/store/team/owner` 隔离，跨企业不可见。
7. 画像 10 个字段均可空，缺失不报错、不阻断主链。
8. 多房屋客户切换房屋时，标签/画像/提醒不串号。

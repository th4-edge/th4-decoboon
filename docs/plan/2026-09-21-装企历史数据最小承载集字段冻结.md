## 1. 最小承载集定义

只承载两类数据：

1. **在跑业务**：仍在施工/验收/收尾的项目，以及这些项目对应的客户、房屋、合同基线、期初应收应付。
2. **主数据**：报价项目库、标准成本、供应商、品牌关系——它们直接决定未来报价与采购能否开始。

已完工历史**只做档案，不导入**；已结清的往来不导入；历史报价明细不重建。

判定口径（任一命中即"在跑"）：

- 项目状态非终态（未完工/未关闭/未终止）。
- 存在未结清应收或应付。
- 客户仍在跟进、未成交或已成交但有未完结项目。

## 2. 导入范围总表

| 批次 | 对象 | 是否最小必做 | 承载渠道 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | 组织与员工（在跑项目责任人 + 财务） | 是 | A / C | 只导参与承接的人员 |
| 2 | 客户与房屋（在跑业务相关） | 是 | A / B / C | 一客户多房屋逐套建 |
| 3 | 报价项目库 + 标准成本 | 是 | A / B | 唯一已实现导入接口的领域 |
| 3 | 供应商 + 品牌关系 | 按需 | A / B | 需要采购时再建 |
| 4 | 合同基线（在跑） | 是 | A / C | 编号 + 金额 + 签署日期 + 扫描件 |
| 4 | 在跑项目 | 是 | A / C | 含当前状态与阶段 |
| 5 | 期初应收 / 应付 | 是（有余额时） | A / C | 独立来源，不伪装成正常收付款 |

**明确不导入**：已完工项目、已结清往来、历史报价明细、历史采购流水、逐项历史采购价、离职员工、历史材料计划/到货/库存。

## 3. 字段冻结

## 5. 统计隔离规则（本次决策）

- 带 `sourceType = legacy_import` 或 `service_import` 的数据**不参与经营指标**。
- 报表、转化率、毛利、排名等查询显式排除历史导入数据。
- 历史导入数据仍可用于查看、追溯、继续履约、补录后续事实。
- `DEC-001` 决策一：历史导入报价不进入报价接受率统计。

## 6. 幂等与回滚

```text
company + importType + sourceFileHash + 业务键（code / legacyId / phone / 关系键）
```

- 重复上传同一文件不产生重复数据。
- 分块事务写入，失败不产生半套数据。
- 已提交批次在窗口期内可整批回滚。
- 跨企业 `legacyId` 不互相覆盖。

## 7. 归属与异常处理汇总

| 情形 | 处理 |
| --- | --- |
| 归属（store/team/owner）缺失 | 进待确认队列，禁止猜测（`OBJ-001`） |
| 客户无房屋 | 客户条目不完成，提示补房屋 |
| 品牌匹配不上报价项 | 进待确认，不静默丢弃 |
| 金额无法确认 | 允许暂缺，标记未完成，进待补清单 |
| 历史成本缺失 | 利润/毛利率为空，不按 0 计算 |
| 格式/值域错误 | 定位行号 + 字段 + 原因，可导出修正 |
| 涉及金额/归属的错误行 | 不允许静默跳过 |

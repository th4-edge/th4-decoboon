## 2. 研发顺序

```text
B1 平台基础模板目录
-> B2 企业模板/版本/实例对象和迁移
-> B3 后端 Provider
-> W1 Web 模板库和复制
-> A1 App 模板库和复制
-> W2/A2 编辑、发布、版本
-> W3/A3 凭证生成和预览
-> Q1 跨端验收
```

Web 和 App 可以在 B3 Provider 契约冻结后并行开展。两端不得各自实现模板字段、金额或版本算法。

## 4. 研发门禁

- 平台模板只读，企业复制后编辑；
- 必填字段不可删除；
- 发布版本不可变；
- 历史凭证绑定模板版本和数据快照；
- Web/App 同 Provider、同字段、同权限、同版本；
- 跨企业、跨店、越权拒绝；
- 敏感字段和 PDF 权限一致；
- 会计记账凭证不在本期范围。

## 5. 验证与发布

本功能涉及 DDL、权限、财务凭证和跨租户，按 L3 变更处理：

- 全量测试；
- 备份和回滚点；
- 迁移可重复、可回滚；
- 生产发布前用户确认；
- 发布后健康检查和核心路径冒烟。

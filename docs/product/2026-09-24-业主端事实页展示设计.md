# 业主端「事实页」展示设计（2026-09-24）

> 触发：业主端应用功能结构没有问题，但所有入口都指向同一条「客户旅程」，展示以文本行为主，
> 不符合装企服务业主的期望。装得清展示的是**结果、确定的痕迹、避免纠纷的凭证**，必须让业主
> 看得清、看得懂、看得放心，而不是被塞进一张长文本清单。

## 1. 设计判断

- 入口结构（我的家 + 量房/设计/报价/选材/增减项/验收/付款/合同/意见投诉）保留。
- **每个业务事实独立一个页面**，不再全部下钻到「项目旅程」。
- 「项目旅程」从唯一入口降级为**全貌总览**，用于回看时间线，不再承担全部细节。
- 展示原则：能看图就不只写文字；能结构化就不堆文本行；能带时间/归属就不省略。

## 2. 页面与展示契约

| 页面 | 展示什么（业务期望） | 数据来源 |
| --- | --- | --- |
| 量房档案 | 房屋**原样照片**、拍摄时间、照片数量、量房设计师、尺寸记录、现场结论 | `measure` 分区 `media`（Photo/Structure，含 time） |
| 设计方案 | **CAD 平面图**、原始结构/拆改/砌筑/优化图、效果图；**各区域长宽高与面积**；区域设计内容 | `design` 分区 `media` + `regions` + `priceGroups` |
| 报价清单 | 报价总额、清单小计、税金、折扣；**按区域分组的项目清单**（名称/分类/品牌/规格/数量/单价/金额） | `quote` 分区 `priceGroups` + `facts` |
| 选材记录 | 选材版本、状态、材料计划、品牌规格、到场时间 | `material` 分区 |
| 增减项 | 变更单号、原因、金额、客户确认状态、明细 | `change` 分区 |
| 验收整改 | 阶段验收单、结论、问题清单、整改截止、凭证图片 | `acceptance` 分区 |
| 付款计划 | 应收总额/已收/未收、各节点名称/金额/到期/到账 | `payment` 分区 |
| 合同档案 | 合同编号、签约金额、当前金额、签约日期、状态 | `contract` 分区 |
| 意见与投诉 | 独立入口，提交与跟踪处理结果 | `feedback` 分区 + 独立 Provider |

## 3. 后端数据契约

`customer/project/journey/info` 在原有 `sections[].items[]` 基础上补充三个结构化字段：

- `Item.media[]`：`key/url/kind/title/time/room`，`kind` 取值
  `Photo 现场照片`、`Structure 原始结构`、`Cad CAD图`、`Render 效果图`、
  `Original 原始结构`、`Demolition 拆改`、`Masonry 砌筑`、`Optimization 优化`、
  `SitePhoto`、`SurveyPhoto`。
- `Item.regions[]`：`name/type/length/width/height/area/perimeter/itemCount/images/remark`。
- `Item.priceGroups[]`：`name/total/summary/rows[]`，`rows[]` 为 `name/category/brand/spec/unit/quantity/price/amount/role/type`。

装配规则：

- 量房：`sitePhotos` → `Photo`（带 `measureTime`），`structureImages` → `Structure`，同一时间归为一组。
- 设计：按方案加载 `Space`（区域尺寸）与 `DesignItem`（区域设计内容），图纸字段转 `media`。
- 报价：按 `QuoteLine.space` 分组，服务端汇总每个区域小计与全部区域合计。

## 4. 权限与边界

- 业主只能看自己授权项目/房屋的事实；跨项目 404。
- 业主文件授权新增：量房 `structureImages`、设计 `cadUrl`/区域图片/分项图片（本就属于业主房屋）。
- 响应**不包含**成本、利润、内部备注和报价来源等内部字段。
- 图片统一走 `file/private/grant` 短期签名，不暴露原始对象路径。

## 5. 验收要求

- 正向：量房照片带时间、设计区域尺寸完整、报价按区域可切换。
- 反向：无数据时显示关怀文案而非空白；跨项目访问 404。
- 数据：`CustomerJourneyEnrichmentTest` 断言 media/regions/priceGroups 真实产出。

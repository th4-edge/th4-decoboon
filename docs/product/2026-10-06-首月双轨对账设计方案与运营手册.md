# 首月双轨对账设计方案与运营手册

> 状态：设计冻结（2026-10-06）
> 适用：存量装企入驻、在跑项目承接、首月账务切换
> 业务依据：`DEC-004`、`SCN-011`、`BR-010`、`SOL-005`、`MET-002`、`OBJ-001`
> 关联方案：`docs/product/2026-10-06-装企入驻账务承接与账务体系对齐方案.md`
> 边界：首月双轨是过渡期对账机制，不做永久双账、不做会计科目、不做税务申报、不自动调平装得清金额

## 1. 定位与目标

首月双轨是装企从原账本切换到装得清的**过桥机制**：

```text
接管日：账务切换点
首月：接管日 -> 当月最后一天
双轨：原账本继续记（法务/税务/对外）
      装得清同步记（项目经营/应收应付/现金流）
      月末对四个主题做差异对账
```

目标：

1. 让客户看到差异在哪里、为什么产生；
2. 让财务知道哪些继续用原账、哪些迁到装得清；
3. 让 BOSS 在切换期仍能看到真实经营；
4. 让装得清数据不被历史已结清事实污染；
5. 差异收敛后退出双轨，新业务全部走装得清。

## 2. 边界与不做

| 做 | 不做 |
| --- | --- |
| 对四个主题做对账 | 全科目对账、借贷分录、法定总账 |
| 原账金额只读对照 | 把原账全量导入经营指标 |
| 装得清金额自动带出、只读 | 在对账页直接改装得清金额调平 |
| 差异分类、责任人、处理动作 | 只写“对不上”不分类 |
| 首月过渡、差异收敛后退出 | 永久双账、长期两套账 |
| 期初余额独立 | 把期初余额当收入/支出 |

## 3. 适用场景

### 场景 A：麦鸿型存量装企

- 已有 Excel + 代账公司两套账；
- 有 8 个在跑项目；
- 未收、未付、账户余额分散；
- 首月双轨用于把四个主题对上，差异分类收敛。

### 场景 B：原账只有总额

- 成本只有总额，明细缺失；
- 双轨对成本主题只对总额，完整性标记为不完整；
- 项目毛利显示为空，不按 0 计算。

### 场景 C：私户收付款

- 客户或老板用私户收款/垫付；
- 属于主体差异；
- 本期分类确认，后续要求新业务走对公/装得清闭环。

## 4. 核心原则

1. **只对四个主题**：项目未收、项目未付、资金余额、项目成本。
2. **原账只做对照**：原账金额进入对账表，不进入装得清经营指标。
3. **装得清金额只读**：从应收、应付、资金台账、项目成本自动带出。
4. **差异必须分类**：时间、主体、含税、口径、数据缺失。
5. **期初不是收入**：期初资金余额、期初应收应付不进入本月收入/支出。
6. **历史不进指标**：已完工、已结清历史只做档案。
7. **成本不完整利润为空**：不按 0 计算，不生成伪利润。
8. **差异不改账**：调整走补录来源、更正、冲正。

## 5. 对账期间与状态机

### 5.1 期间

```text
首月正式期间：接管日 -> 当月最后一天
周快照：每周固定日做临时对账
月末正式：生成《首月双轨对账表》
延长对账：差异未收敛时进入第二个月
```

### 5.2 状态机

```text
Draft 草稿
-> Pending 待对账
-> DiffHandling 差异处理中
-> Confirmed 已确认
-> Closed 已关闭
```

规则：

- 有未分类差异不能进入“已确认”；
- 有未处理差异不能进入“已关闭”；
- 关闭后如发现新差异，新建调整期，不改历史对账结果；
- 延长对账时保留首月快照。

## 6. 四个主题口径

### 6.1 项目未收

```text
装得清侧 = 期初应收 - 接管后已收款核销金额
原账侧   = 原账本科目“应收账款/预收账款”对应当前未收余额
差异     = 原账侧 - 装得清侧
```

常见差异：时间、主体、含税、口径、数据缺失。

### 6.2 项目未付

```text
装得清侧 = 期初应付 - 接管后已付款核销金额
原账侧   = 供应商/班组/人工对应的当前未付余额
差异     = 原账侧 - 装得清侧
```

常见差异：个人垫付、账期、未建应付、含税差异。

### 6.3 资金余额

```text
装得清侧 = 期初资金余额 + 接管后资金净流量
原账侧   = 银行流水 + 现金 + 微信/支付宝等实际账户余额
差异     = 原账侧 - 装得清侧
```

常见差异：银行未达账、私户、现金未入账、期初缺失。

红线：期初资金余额不是收入/支出，不进入利润。

### 6.4 项目成本

```text
装得清侧 = 接管前成本快照 + 接管后材料成本 + 人工/项目应付 + 项目零星成本
原账侧   = 原账本已发生成本（或成本总额）
差异     = 原账侧 - 装得清侧
```

规则：成本不完整时，项目毛利与毛利率显示为空，并提示“成本未完整”。

## 7. 领域模型

| 对象 | 职责 |
| --- | --- |
| `CarryoverReconciliation` | 对账批次/期间：企业、接管日、期间、状态、责任人 |

### 7.1 主题枚举

```text
Receivable 项目未收
Payable    项目未付
Cash       资金余额
Cost       项目成本
```

### 7.2 差异分类枚举

```text
Time        时间差异
Entity      主体差异
Tax         含税差异
Scope       口径差异
MissingData 数据缺失
```

### 7.3 差异状态

```text
Pending   待处理
Handling  处理中
Resolved  已解决
Accepted  已确认接受
```

## 8. 完成度投影（rules.md §13）

| key | label | required | 完成条件 | 异常态 |
| --- | --- | --- | --- | --- |
| `receivable` | 项目未收 | 是 | 原账金额 + 装得清金额 + 差异分类 | 暂不可确认 |
| `payable` | 项目未付 | 是 | 同上 | 暂不可确认 |
| `cash` | 资金余额 | 是 | 期末余额已核对 | 暂不可确认 |
| `cost` | 项目成本 | 是 | 成本金额 + 完整性确认 | 成本不完整 → 利润为空 |
| `difference` | 差异分类 | 是 | 每条差异有分类和责任人 | 未分类 → 不能确认 |
| `owner` | 责任确认 | 是 | 财务确认 + BOSS 确认 | 缺失 → 待确认 |

## 10. 运营手册

### 10.1 时间线

```text
第0周：财务启动会 + 账本摸底 + 范围确认
第1周：完成承接六步 + 期初资金/期初应收应付/成本快照
第2周：第一次周对账，建立差异清单
第3周：差异处理，补录来源，分类确认
第4周：第二次周对账 + 月末正式对账表
第5周：首月经营对账会 + 退出判断 + 遗留问题
```

### 10.2 角色分工

| 角色 | 职责 |
| --- | --- |
| 装企财务 | 原账金额录入、差异处理、日常记账 |
| 装企 BOSS | 确认口径、接受差异、最终退出确认 |
| 装得清实施 | 主持对账、模板、口径解释、差异跟踪 |
| 装企 PM | 提供项目成本、现场事实 |
| 装得清系统 | 自动带出装得清侧金额、计算差异、导出 |

### 10.3 每周节奏

- 固定对账日（建议周五）；
- 更新差异清单，明确责任人；
- 周末前处理可解决差异；
- 下周对上次差异复审。

### 10.4 客户沟通话术

对财务：

> 我们不是来替代你的会计账，而是把“项目经营”从原账本里独立出来。首月双轨只对四个主题，把差异分类说清楚；之后新业务走装得清，你的原账本继续做法定会计。

对 BOSS：

> 首月双轨是过渡期，不是让你记两套账。差异收敛后，你只看装得清的项目毛利和现金流。

## 11. 指标与退出条件

| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 双轨完成率 | 完成四个主题对账的期间占比 | 100% |
| 差异率 | 未解释差异金额 / 对账总额 | 逐步收敛 |
| 差异处理时长 | 从发现到分类确认的平均天数 | 越短越好 |
| 期初准确率 | 期初余额无差异或差异已确认占比 | ≥95% |
| 新业务装得清覆盖率 | 接管后新业务走装得清的比例 | 100% |

退出条件：

```text
连续两个对账周期差异率为 0 或所有差异已分类确认
新业务 100% 走装得清
原账本只保留法定会计/税务用途
BOSS 确认关闭首月双轨
```

未满足时进入延长对账期，不强行关闭。

| 角色 | 查看 | 维护原账金额 | 处理差异 | 确认关闭 |
| --- | --- | --- | --- | --- |
| BOSS | 是 | 是 | 是 | 是 |
| 财务 | 是 | 是 | 是 | 否（提交 BOSS 确认） |
| 店长 | 本店只读 | 否 | 否 | 否 |

| 其他员工 | 否 | 否 | 否 | 否 |

所有读写按企业隔离；前端不得指定其他企业。

## 13. 验收标准

1. 四个主题都能录入原账金额并自动带出装得清金额；
2. 差异自动计算，差异必须选择分类和责任人；
3. 有未分类/未处理差异时不能确认和关闭；
4. 对账不影响装得清金额、项目毛利和现金流；
5. 期初余额不进入收入/支出；历史已结清不进入指标；
6. 成本不完整时利润为空；
7. 对账表和差异清单可导出；
8. 关闭后可新建调整期，不修改历史对账结果。

## 14. 风险与反模式

| 风险/反模式 | 后果 | 正确做法 |
| --- | --- | --- |
| 长期双账 | 工作量翻倍、数据分裂 | 约定退出条件，首月收敛 |
| 用差异直接改装得清金额 | 破坏审计与口径 | 走补录/更正/冲正 |
| 差异不分类 | 永远说不清、无法退出 | 每条差异必须有分类和责任人 |
| 历史已结清进指标 | 本月收支失真 | 只做档案 |
| 成本不完整按 0 算 | 假利润 | 利润置空 |
| 期初余额当收入 | 现金流和利润错误 | 期初独立 |
| 只让财务对账、BOSS 不参与 | 口径无人拍板 | BOSS 参加月末对账会 |

## 15. 一句话总结

> 首月双轨是装企从原账本切换到装得清的过桥机制：只对四个主题，差异必须分类，装得清金额不改，历史不进指标；首月收敛后，新业务全部走装得清，原账本只保留法定会计用途。

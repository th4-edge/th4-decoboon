# 企业自定义凭证模板体系 P0 产品规格

> 状态：可研发使用
> 日期：2026-10-07
> 业务裁决：`DEC-020`、`BR-018`、`SCN-013`、`SOL-009`
> 回答单：`ANS-BIZ-20261007-003`
> 适用端：Backend、Web、App
> 本期边界：业务/原始凭证模板；不做法定会计记账凭证

## 1. 产品目标

装得清先提供行业基础凭证模板，装企可以复制为企业自己的模板，编辑字段、版式、样式和打印参数；Web/App 使用同一后端模板和版本，凭证发行后保存模板版本、数据快照和 PDF。

## 2. 两个真实业务场景

### 场景一：单店装企复制客户进度款收款单

- 使用人：财务。
- 触发事件：企业原来使用 Excel 打印客户进度款收据。
- 当前动作：进入模板库，选择“客户进度款收款单”，复制为企业模板；修改企业名称、字段顺序、签字栏和字号。
- 系统下一步：校验必填字段和业务来源，发布企业版本；登记收款时选择该模板生成 PDF。
- 异常处理：删除收款日期、金额或来源字段时拒绝发布；跨企业模板不可见。

### 场景二：三店企业统一基础、门店差异化

- 使用人：BOSS、财务。
- 触发事件：总部要求工资和付款凭证统一，但门店签字栏不同。
- 当前动作：总部先复制基础模板并发布为企业标准模板；门店在自身数据范围内复制后调整打印样式。
- 系统下一步：保存来源模板关系和企业版本；凭证实例绑定实际使用版本。
- 异常处理：门店不能删除法规或业务必需字段；模板修改不回溯历史凭证。

## 3. 产品结构

```text
财务
  -> 凭证模板
      -> 平台基础模板
      -> 我的模板
          -> 草稿
          -> 已发布版本
          -> 已停用版本
  -> 凭证列表
  -> 凭证生成
  -> 预览/打印/重打
```

## 5. 模板页面能力

### Web

1. 模板库首页：平台基础模板 / 我的模板两个页签。
2. 列表筛选：凭证类型、业务场景、状态、更新时间、编码。
3. 模板详情：只读预览、字段清单、版本、来源、发布人。
4. 复制：输入企业模板名称，生成草稿。
5. 编辑：
   - 模板名称和说明；
   - 纸张、方向、页边距；
   - 字段显示名、顺序、分组、显隐；
   - 表格列顺序和列宽；
   - 字体、字号、颜色、行距；
   - 签字栏、盖章位、附件区、备注区；
   - 企业附加字段。
6. 预览：使用脱敏样例数据和服务端真实数据两种模式。
7. 发布：校验通过后生成不可变版本。
8. 版本历史：查看、对比、停用；已发布版本不可编辑。
9. 删除：仅允许草稿删除；已发布版本停用，不物理删除历史。

### App

1. 模板列表：常用模板、我的模板。
2. 模板详情：横向预览、字段、版本和来源。
3. 复制模板。
4. 轻量编辑：
   - 名称；
   - 字段显隐和顺序；
   - 标题、字号、颜色；
   - 纸张方向；
   - 签字栏；
   - 打印参数。
5. 发布、停用。
6. 从资金台账、收款、付款或工资页选择模板生成凭证。
7. 预览、分享和打印 PDF。

## 6. 企业模板编辑规则

### 可以编辑

- 模板名称、说明；
- 字段显示名、顺序、分组、显隐；
- 纸张、方向、页边距；
- 表格列顺序和列宽；
- 字体、字号、颜色、行距；
- 签字栏、盖章位、附件和备注区；
- 企业附加字段；
- 打印份数和联次。

### 不可删除或替换

- 凭证类型和业务方向；
- 凭证编号、日期；
- 对方、项目或来源字段；
- 业务内容、金额、金额大写；
- 制单、审核、出纳、收款或付款证明；
- 原始凭证张数和附件关系。

## 7. 状态与幂等

```text
基础模板：只读/平台发布
企业模板草稿：新建/复制
企业模板版本：草稿 -> 已发布 -> 已停用
凭证实例：有效 -> 已作废
```

- 同一来源事实重复生成凭证，返回原实例；
- 同一模板发布重复提交，只生成一个版本；
- 并发编辑冲突提示重新读取；
- 模板发布失败不产生可用版本；
- 停用模板不删除历史实例和文件。

## 8. 权限和敏感字段

| 动作 | 角色 |
| --- | --- |
| 查看基础模板 | 所有已登录财务相关角色 |
| 复制/编辑/发布/停用企业模板 | BOSS、店长、财务 |
| 生成/打印凭证 | BOSS、财务 |
| 查看完整身份证号和银行账号 | BOSS、财务 |
| 店长/设计师查看敏感字段 | 按既有工人隐私规则脱敏 |

Web/App 前端隐藏不代替服务端权限。保存、发布、生成和重打均重新校验企业、门店、团队和项目范围。

## 9. 后端 Provider 规划

| Provider | 能力 |
| --- | --- |
| `document/baseline/list` | 返回平台行业基础模板目录 |
| `document/voucher-template/page` | 企业模板分页 |
| `document/voucher-template/info` | 企业模板详情、版本关系 |
| `document/voucher-template/save` | 从基础模板复制或新建草稿 |
| `document/voucher-template/update` | 编辑草稿、发布、停用、删除草稿 |
| `document/voucher-template/delete` | 删除草稿或逻辑停用 |
| `document/voucher/build` | 凭证发行，可选指定企业模板版本 |
| `document/voucher/page` | 凭证实例列表 |
| `document/voucher/reprint` | 历史凭证重打或下载 |

Provider 必须继承 `Security`；列表和自定义更新/删除按 `DataScopeSpecification`；响应字段按 `@Properties` 裁剪；实体必须含 `Company`。

## 10. 数据对象规划

```text
VoucherTemplateCatalog（平台静态或平台只读表）
VoucherTemplate（企业模板）
VoucherTemplateVersion（不可变版本）
VoucherRecord（凭证实例，可扩展现有对象）
VoucherItem（凭证明细，可复用现有对象）
VoucherTemplateSnapshot（模板和业务数据快照）
```

需要在现有 `DocumentTemplate` / `VoucherRecord` 基础上增量演进，避免破坏报价、材料、合同现有单据能力。

## 11. 验收矩阵

| 类型 | 用例 |
| --- | --- |
| 基础模板 | 平台基础模板只读，企业不可编辑 |
| 复制 | 复制成功生成企业草稿，保留来源编码和版本 |
| 编辑 | 字段、样式、纸张、签字栏可编辑；必填字段不可删除 |
| 发布 | 发布后生成不可变版本，重复发布幂等 |
| 版本 | 修改新版不影响历史凭证；历史重打同号同文件 |
| 权限 | 跨企业、跨店、越权、非财务角色不可维护 |
| 敏感信息 | BOSS/财务完整；店长、设计师脱敏；PDF 权限一致 |
| Web/App | 同一模板版本、同字段、同权限、同凭证结果 |
| 凭证生成 | 金额只取来源事实；合并、编号、重打符合 BR-006/BR-018 |
| 异常 | 无模板、金额缺失、来源失效、并发冲突显示“暂不可确认” |

## 13. 不在本期

- 会计记账凭证、会计科目、借贷分录、总账；
- 税务、审计、个税和社保申报；
- 预印纸自由坐标和背景底图套打；
- 电子签名、电子印章和 OFD/PDF-A 正式归档能力。

## 13.1 高级设计器进展

- `designerConfig` 已模型化并支持版本快照。
- Web 已提供四区高级设计器：字段库、打印画布、属性面板、设计工具栏。
- 支持文本、活动字段、表格、图片、二维码、签字栏的添加和基本拖动/缩放。
- 支持表格列、行高、每页行数和表头重复配置。
- PDF 渲染器完整读取 `designerConfig` 的坐标和合并模型仍待下一阶段。

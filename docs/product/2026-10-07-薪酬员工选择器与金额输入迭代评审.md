# T15 / T16 · 薪酬员工选择器与金额输入迭代评审

```text
选择器名称: 薪酬域员工选择器
对应角色: BOSS、财务；店长按本店薪酬只读场景不进入编辑选择器
关联业务对象/概念: Employee
提出人: 用户
日期: 2026-10-07
关联需求: App 员工薪酬金额输入展示修复、员工选择规范化、薪酬方案配置月应出勤天数
```

## 1. 使用场景

### 场景 A：单店 15 人月末工资

- 使用人：财务或兼任财务的 BOSS。
- 选择和动作：新增薪酬方案、录入月度考勤或计提员工提成时选择员工。
- 选择前：已经确定本月要处理的员工，但列表较长，需要按门店、岗位和状态快速缩小范围。
- 选择后：员工作为领域对象回传给表单，表单继续填写固定工资、月应出勤天数、考勤或提成金额。
- 错误选择影响：会写错员工工资、考勤或提成归属，后续影响应付、成本和工资条。

### 场景 B：三店 26 人跨店发薪

- 使用人：财务。
- 选择和动作：先按门店和岗位定位设计师、项目经理、业务员，再为不同员工录入薪酬和提成。
- 选择前：只知道岗位和门店，不确定全部姓名。
- 选择后：员工卡片显示姓名、岗位、门店、团队、状态；服务端保存时再次校验企业归属和薪酬权限。
- 错误选择影响：跨店误选会泄露或写入不应处理的工资与考勤事实。

## 2. 业务概念与数据结构

- 概念定义：企业内可被薪酬、考勤、提成处理的员工。
- 唯一标识：`empId`。
- 展示名称：姓名。
- 业务摘要：岗位、门店、团队、在职状态、头像。
- 数据规模：试点企业通常 3–50 人，后续按分页和远程搜索扩展。
- 上下文关系：薪酬方案、考勤汇总、提成明细均保存 `Employee` 对象关系，不保存裸姓名。

## 3. 决策维度

1. 门店：财务最先按组织定位。
2. 岗位：设计师、项目经理、业务员等角色决定工资或提成处理方式。
3. 状态：默认在职，可查看停用/离职以处理历史或补录。
4. 精细搜索：姓名、手机号。

## 4. 首屏数据与布局

- 打开后立即展示员工列表，不经过多层下拉。
- App 使用全屏选择页：搜索框、门店/岗位/状态筛选、员工卡片、加载更多。
- 员工卡片必须显示姓名、岗位、门店、团队、状态。
- 已选员工在表单中使用全宽对象卡展示，不塞进普通输入框。

## 5. 统一机制

- 选择：一次性存储回传完整 `Employee` 领域对象。
- 清除：回传 `clear`，表单清空当前员工。
- 加载/空/失败：显示加载、空态和可重试错误态。
- 分页：服务端支持 `keyword/role/storeId/status/current/size`。
- 权限：服务端按登录员工的薪酬编辑权限和企业范围过滤；前端不传可信企业或负责人。
- 服务端复核：保存薪酬、考勤、提成时再次校验员工企业归属和薪酬数据范围。

## 6. T16 表单分区与结果确认

- 上下文对象选择区：薪酬、考勤、提成表单均使用全宽员工选择卡；提成项目继续复用财务项目选择器。
- 短字段输入区：月固定工资、合同签约额、提成金额统一使用金额输入组件，显示 `¥`、右对齐数字和 `元` 单位。
- 考勤天数：薪酬方案填写月应出勤天数；考勤页只读展示快照，保存时由服务端按当前生效薪酬方案写入，不再默认 22 天。
- 结果预览区：提成展示预计提成；工资项金额最终以服务端计算为准。
- 主行动区：保存薪酬方案、保存考勤、确认计提提成。

## 7. 异常与边界

- 无薪酬方案：保存考勤时阻断并提示先配置薪酬方案。
- 月应出勤天数无效：必须为 1–31 天。
- 历史考勤：保留当时快照，后续修改薪酬方案不反改已确认月份。
- 员工不存在或跨企业：服务端拒绝，且不泄露记录是否存在。
- 金额输入：只允许数字和两位小数，失焦后格式化为两位小数。

## 8. 验收矩阵

| 类别 | 用例 | 预期 |
| --- | --- | --- |
| 正向 | 财务按门店+岗位选择员工完成薪酬方案 | 员工对象正确回传，方案保存成功 |
| 正向 | 薪酬方案配置 24 天，录入当月考勤 | 考勤快照为 24 天，不以 22 天兜底 |
| 正向 | 金额输入 6000 后失焦 | 展示 `¥6000.00 元`，不溢出裁切 |
| 反向 | 同一员工同月重复考勤 | 服务端拒绝 |
| 反向 | 薪酬方案天数 0 或 32 | 服务端拒绝 |
| 越权 | 跨企业员工 ID 保存 | 服务端拒绝且不泄露存在性 |
| 上下文失效 | 已选员工被删除或离职 | 服务端保存前复核，失败可重新选择 |
| 大数据 | 员工超过 20 人 | 首屏立即可见，搜索筛选服务端执行，可加载更多 |
| 失败恢复 | 员工列表加载失败 | 展示错误态和重试，不用空数组伪装完成 |

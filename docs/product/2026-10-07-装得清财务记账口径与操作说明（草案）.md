## 2. 记账边界

### 2.1 装得清是什么账

> 项目经营账 + 资金台账 + 经营核算。

| 账种 | 回答的问题 |
| --- | --- |
| 合同与收入账 | 签了多少、变更后多少、应收多少、已收多少 |
| 成本与利润账 | 预计/承诺/实际成本多少、应付多少、项目毛利多少 |
| 资金与现金账 | 实际收付、账户余额、现金流 |
| 风险与核校账 | 哪些账不一致、逾期、缺成本、超预算 |

### 2.2 装得清不是什么账

不是法定会计总账、会计科目、借贷分录、财务报表、税务申报、发票管理、社保公积金、完整 HR、合并报表。装得清输出不能作为会计、税务、审计依据。

**红线**：成本或费用不完整时返回 `null` 或「暂不可确认」，不得按 0 计算伪利润。

## 3. 记账对象与四本账

| 对象 | 职责 | 关键状态 |
| --- | --- | --- |
| `ProjectContract` | 合同金额、变更、签约 | Draft/Signed/Effective/Changed/Completed/Settled/Terminated |
| `Receivable` | 合同节点应收 | Pending/Partial/Received/Overdue/Closed |
| `Receipt` | 客户实际收款、核销应收 | 持久事实，错误走冲正 |
| `Payable` | 材料/工资/项目/费用/供应商应付 | Pending/Partial/Paid/Overdue/Closed |
| `Payment` | 实际付款、核销应付 | 持久事实，错误走冲正 |
| `Ledger` | 不可变资金流水 | Income/Expense；来源 Receipt/Payment/Manual/Adjustment |
| `ProjectCostContext` | 项目预计/实际成本与完整性 | `costComplete` |
| `Settlement` | 项目收入、成本、利润、关闭快照 | Draft/Confirmed/Closed |
| `OpeningBalance` | 期初资金余额 | 按 as_of_date；不计收支/利润 |
| `CarryoverCostSnapshot` | 历史接管成本快照 | Complete/Unknown |
| `PayrollSheet`/`Payable` | 员工工资应付与发放（待建设） | BR-015 |

事件链：

```text
客户 -> 合同 -> 项目
  ├── 应收 Receivable -> 收款 Receipt -> Ledger(Income)
  ├── 材料计划 -> 采购 -> 到货 -> 材料应付 Payable -> 付款 Payment -> Ledger(Expense)
  ├── 工人/班组 -> 工资应付 Payable(Salary) -> 付款 Payment -> Ledger(Expense)
  └── 员工薪酬 -> 工资单 PayrollSheet -> 员工工资应付 -> 付款 Payment -> Ledger(Expense)
```

## 4. 自动记账事件链

| 业务事件 | 自动形成/更新 | 是否写 Ledger |
| --- | --- | --- |
| 合同签署 | 合同基线、签署归档；不生成项目 | 否 |
| 合同生效 | 项目、收入基线、应收计划、预计成本预算、合同归档 | 否 |
| 合同变更客户确认 | 合同当前金额、未来应收、预算、任务和材料范围 | 否（实际退款/收款除外） |
| 采购单批准 | 承诺成本、材料执行范围 | 否 |
| 材料到货/入库 | 实际材料成本、供应商应付 | 否 |
| 客户收款 | 应收核销、资金收入流水 | 是 Income |
| 供应商/班组付款 | 应付核销、资金支出流水 | 是 Expense |
| 员工工资单确认 | 员工工资应付、项目/企业成本 | 否 |
| 工资发放 | 应付核销、资金支出流水 | 是 Expense |
| 提成确认 | 提成应付、项目成本 | 否 |
| 提成发放 | 应付核销、资金支出流水 | 是 Expense |
| 项目费用确认 | 项目其他成本、应付或直接成本 | 视是否付款 |
| 项目结算关闭 | 最终收入、成本、利润、结算快照 | 否 |
| 手工调整 | 调整账务事实或冲销错误流水 | 是/视方向 |

**幂等**：事件必须带来源单据和幂等键；重复提交不得重复记账。

## 5. 核心口径与公式

### 5.1 合同与应收

```text
合同当前金额 = 原合同金额 + 已确认变更
应收计划     = 按合同收款节点分解
已收金额     = Receipt 核销合计
待收金额     = 应收金额 − 已收金额（逐条不小于 0）
逾期应收     = 到期未收/状态逾期的未收余额
收款额       = Receipt.amount（按 receivedAt 归期）
```

规则：

- 合同生效才生成项目和应收；合同签署本身不生成项目。
- 收款必须选择应收节点，金额不得超过余额。
- 收款、应收核销、`Ledger(Income)` 同事务。
- 合同金额是项目收入基线，不是现金收入。
- 手工非工程款收入关联项目时计入项目收入，未关联时只进现金流与收入台账。

### 5.2 应付与付款

```text
应付金额 = Payable.amount
已付金额 = Payment 核销合计 / Payable.paidAmount
待付金额 = 应付金额 − 已付金额（逐条不小于 0）
付款额   = Payment.amount（按 paidAt 归期）
```

规则：

- 能追溯到采购、工资、项目、供应商的金额必须走来源单据，不能走手工记账。
- 应付 ≠ 成本；付款 ≠ 成本。
- 付款、应付核销、`Ledger(Expense)` 同事务。

### 5.3 项目成本与毛利

```text
项目收入 = 合同当前金额 + 关联项目的非工程款收入
项目成本 = 材料实际成本 + 人工/班组应付 + 项目归属员工工资/提成
         + 手工项目零星成本 + 其他应计成本
项目毛利 = 项目收入 − 项目成本
项目毛利率 = 项目毛利 ÷ 项目收入
```

成本分层：

| 层级 | 来源 | 用途 |
| --- | --- | --- |
| 预计成本 | 合同行成本快照/报价快照 | 预算与预计毛利 |
| 承诺成本 | 已批准采购单 | 风险占用、超预算预警 |
| 实际成本 | 到货/入库、人工、费用、工资确认 | 动态毛利 |
| 已付金额 | Payment | 现金流与应付余额 |

规则：

- 实际材料成本只在到货/入库累计；领料、损耗只流转库存，不重复累计。
- 手工零星成本只有「关联项目 + 用途=项目零星成本」才进项目成本。
- 项目归属员工工资/提成进项目成本；企业归属不进项目毛利。
- 成本不完整：`costComplete=false`、`grossProfit=null`、`grossMargin=null`，显示「成本未完整」，禁止按 0 计算。
- 同一笔成本只能落一处，禁止项目成本与企业费用双计。
- **当前待裁决**：成本价=销售价是否视为成本未完整（见第 14 节）。

### 5.4 资金与现金

```text
资金收入 = 期间内 Ledger Income 合计
资金支出 = 期间内 Ledger Expense 合计
现金流   = 资金收入 − 资金支出
账户余额 = 期初余额 + 累计资金收入 − 累计资金支出
```

规则：

- `Ledger` 不可变；手工流水仅 BOSS 可逻辑作废，自动流水不可作废。
- 期初余额不计入收入/支出，不参与利润，只作账户起始。
- 现金流 ≠ 利润；借款/还款、押金、备用金、股东往来不得解释为经营收入或成本。
- 往来是否剔除由公司经营利润口径决定；现金流仍完整呈现。

### 5.5 公司经营利润（参考，待建设）

```text
公司经营利润 = 项目毛利合计
             + 非项目其他收入
             − 企业费用（企业归属员工工资 + 房租 + 推广 + 税费 + 办公 + 其他运营）
```

规则：

- 往来类（借款/还款、押金、备用金、股东往来）必须剔除。
- 任一项目成本不完整 → 公司经营利润标记「成本未完整」，不得按 0 拼假利润。
- 对外必须称「经营利润（参考）」，不得称净利润/税务利润。

### 5.6 工资（BR-015）

```text
应发工资 = 固定工资折算 + 提成 + 奖金 + 补贴
扣款     = 考勤扣款 + 社保个人字段 + 个税字段 + 其他扣款
实发工资 = 应发工资 − 扣款
```

## 6. 手工记账口径

### 6.1 定位

```text
手工记账 = 非计划内、无业务单据来源、无法通过应收/应付闭环自动形成的其他账务。
```

### 6.2 允许用途

项目零星成本 / 企业费用 / 其他收入 / 资金往来 / 其他；使用当前企业的业务分类并回显分类说明。

### 6.3 禁止清单

| 禁止内容 | 正确入口 |
| --- | --- |
| 客户工程款（首期/进度/尾款/质保金/增项） | 应收计划 → 收款 |
| 材料款、供应商款 | 采购到货 → 应付 → 付款 |
| 工人工资 | 人工/班组应付 → 工资发放 |
| 员工工资 | 工资单 → 员工工资应付 → 付款 |
| 项目款、分包款 | 项目应付 → 付款 |
| 可追溯采购、到货、材料计划、合同变更的金额 | 对应来源单据 |
| 法定会计凭证、科目、借贷分录、税务申报 | 不在装得清范围 |

### 6.4 分类维护

- 平台提供标准两级业务分类和默认分类说明；企业 BOSS/财务可在当前企业新增、改名、改说明和停用。
- 新记账优先选择二级业务分类；分类说明用于解释适用场景、举例和禁止用途，摘要记录每笔业务事实。
- 自定义分类必须填写分类说明。停用分类只影响新记账，不改写历史流水。
- 历史文本分类保留原文本快照，不静默匹配、不批量改写。

### 6.5 作废与更正

- 仅 BOSS 可逻辑作废手工流水；不物理删除，保留审计与凭证。
- 已参与冲正重记的流水不可作废。
- 自动流水（收款、付款、工资、调整）不可作废，错误走冲正。
- 已月结期间只能新增调整/冲销，不能改历史金额。

## 7. 期初、结转与历史归档

| 项 | 口径 |
| --- | --- |
| 期初资金余额 | `OpeningBalance`，按 as_of_date；不计收支/利润；未承接时页面应显示「期初未承接」 |
| 剩余收款计划 | 复用 `Receivable`，只补未来计划，不改历史核销 |
| 剩余付款计划 | 复用 `Payable`，只补未来计划，不改历史核销 |
| 历史接管成本 | `CarryoverCostSnapshot`；`Unknown` 视为成本未完整 |
| 历史归档项目 | `Carryover + Settled`；财务工作台整体排除，驾驶舱当前未排除，**待统一裁决** |
| 原账口径备注 | 只备注对应科目/账本，不建科目体系 |
| 双轨对账表 | 原账 vs 装得清 vs 差异分类，只读不改账 |

## 8. 期间与月结

```text
月度自动核校 -> 财务处理异常 -> BOSS/财务确认月结
-> 锁定该期间应收、应付、Ledger、工资单、结算快照
-> 后续修正只能新增调整或冲销
```

月结后禁止：修改历史收付款金额、物理删除 Ledger、无来源调整项目利润、用模板新版本回写历史 PDF、直接修改已确认工资单。

## 9. 操作说明（场景 SOP）

### 9.1 建立应收计划

- 前置：合同已生效；项目已创建；收款节点已确认。
- 步骤：进入应收计划 → 选择项目/合同 → 按节点登记金额、类型、到期日 → 保存。
- 系统结果：生成 `Receivable`；合同金额与应收合计形成核校关系。
- 验证：应收合计 = 合同当前金额（允许差异需有原因和留痕）。
- 异常：节点不完整时阻断合同生效或标记待补。

### 9.2 登记收款

- 前置：存在待收应收节点；金额 > 0；有权限（BOSS/财务）。
- 步骤：财务工作台 → 登记收款 → 选择项目 → 选择应收节点 → 填写金额、账户、收款日期、凭证 → 提交。
- 系统结果：`Receipt` 生成；应收 `receivedAmount` 增加；状态 Pending→Partial→Received/Overdue 重算；`Ledger(Income)` 写入；财务工作台已收/待收/回款/现金余额变化。
- 验证：
  ```text
  本次核销 = 应收已收增量
  收款合计 = Ledger 中 source=Receipt 的收入合计
  待收金额 = 应收金额 − 已收金额
  ```
- 异常：金额超过余额阻断；重复提交按幂等键返回原单据；错记走冲正，不物理删除。

### 9.3 采购到货与形成应付

- 前置：采购单已批准/下单；到货/入库事实确认。
- 步骤：到货验收 → 入库（直送/入仓）→ 形成供应商应付。
- 系统结果：实际材料成本累计；`Payable(Material)` 生成；项目成本完整性重算。
- 验证：到货数量 ≤ 采购数量；材料成本只累计一次；应付金额与来源单据一致。
- 异常：部分到货标记 PartiallyReceived；无成本/缺价标记成本未完整。

### 9.4 登记付款

- 前置：存在待付应付；金额 > 0；有权限。
- 步骤：应付账款 → 选择应付单 → 填写付款金额、账户、付款日期、凭证 → 提交。
- 系统结果：`Payment` 生成；应付 `paidAmount` 增加；`Ledger(Expense)` 写入；财务工作台待付/本月支出/现金流变化。
- 验证：
  ```text
  本次核销 = 应付已付增量
  付款合计 = Ledger 中 source=Payment 的支出合计
  待付金额 = 应付金额 − 已付金额
  ```
- 异常：不得用付款直接冲项目成本；成本只认到货/入库/确认。

### 9.5 手工记账

- 前置：确认不属于第 6.3 节禁止清单；有权限（BOSS/财务）。
- 步骤：资金收付 → 手工记账 → 选择方向/用途/二级业务分类并确认分类说明 → 关联项目（零星成本必须关联）→ 填写金额、账户、日期、摘要、凭证 → 提交。
- 系统结果：`Ledger` 生成；项目零星成本进项目成本；企业费用进企业费用；现金流变化。
- 验证：
  ```text
  手工收入：Ledger Income(source=Manual)
  项目零星成本：Ledger Expense(source=Manual, purpose=ProjectIncidentalCost, project 非空)
  企业费用：Ledger Expense(source=Manual, purpose=CompanyExpense, project 空)
  ```
- 异常：禁用词/已有来源单据的业务被阻断并引导到正确入口；错记账走作废/冲正。

### 9.6 项目结算

- 前置：项目完工/验收；应收应付核销情况确认；成本完整性检查。
- 步骤：项目账本 → 结算 → 核对收入、成本、毛利 → 确认 → 关闭。
- 系统结果：结算快照生成；项目状态关闭；利润归集。
- 验证：结算前系统核校通过；应收清零、应付清零、成本完整；关闭后不可直接改。
- 异常：成本不完整阻断关闭或标记「成本未完整」。

### 9.7 期初承接

- 前置：入驻承接清单确认；原账/双轨对账数据准备。
- 步骤：导入/登记期初资金余额、剩余应收、剩余应付、历史项目归档 → 形成双轨对账表。
- 系统结果：`OpeningBalance`、`Receivable`、`Payable`、历史归档项目建立；不写历史收支。
- 验证：期初 + 累计流水 = 账户余额；剩余应收/应付与承接清单一致。
- 异常：不承接的账不得留空冒充完成；差异分类记录。

### 9.8 月结对账

- 前置：当月业务结束；异常核校处理完成。
- 步骤：运行核校 → 处理差异 → BOSS/财务确认月结 → 锁定期间。
- 系统结果：期间锁定；历史数字不再变化。
- 验证：第 10 节对账公式全部通过；差异有原因和留痕。
- 异常：月结后只能调整/冲销，不能改历史。

## 10. 记账结果验证

### 10.1 对账公式

```text
1. 合同当前金额 = 原合同 + 已确认变更
2. 应收合计 ≈ 合同金额（差异需有原因）
3. 应收已收 = 收款核销合计
4. 收款合计 = Ledger 中 source=Receipt 的收入合计
5. 应付已付 = 付款核销合计
6. 付款合计 = Ledger 中 source=Payment 的支出合计
7. 待收金额 = max(应收金额 − 已收金额, 0)
8. 待付金额 = max(应付金额 − 已付金额, 0)
9. 项目毛利 = 项目收入 − 项目成本（成本完整时）
10. 账户余额 = 期初余额 + 累计资金收入 − 累计资金支出
11. 现金流 = 资金收入 − 资金支出
12. 工资单确认 = 员工工资应付 + 成本；工资发放 = 应付核销 + Ledger
13. 成本不完整时：costComplete=false、毛利=null、毛利率=null
14. 月结期间内数字不得因新操作变化
```

### 10.2 操作后验证步骤

1. 找到来源单据（合同/应收/应付/采购/到货/工资单/手工流水）。
2. 用对账公式核对金额与余额。
3. 核对 `Ledger` 是否只写一次、方向正确、来源正确。
4. 核对财务工作台/驾驶舱/项目账本同一指标是否一致或可解释。
5. 核对成本完整性、期间、归档、权限是否符合口径。

### 10.3 正反例

| 场景 | 正确 | 错误 |
| --- | --- | --- |
| 客户交首期款 | 应收计划 → 收款 → 核销 + Ledger | 手工记账写「工程款」 |
| 材料款 | 采购到货 → 应付 → 付款 | 手工记账写「材料款」 |
| 工人工资 | 人工/班组应付 → 工资发放 | 直接手工记支出 |
| 员工工资 | 工资单 → 应付 → 付款 | 与工人工资混算 |
| 成本缺失 | 显示「成本未完整」 | 按 0 成本计算利润 |
| 现金余额 | 期初 + 流水净额 | 把现金流当利润 |
| 历史归档项目 | 按统一归档口径处理并标注 | 两页面一个含一个不含且无说明 |

### 10.4 线上麦鸿样例（2026-10-07 只读）

| 项 | 数值 | 说明 |
| --- | ---: | --- |
| 项目合同额（财务工作台） | 190,100.00 | 4 个非归档项目；不含历史归档项目 38,520 |
| 应收 / 已收 / 待收 | 190,100.00 / 80,380.00 / 109,720.00 | 资金闭环口径 |
| 逾期 | 15,900.00 | 谢欣项目首期款，2026-10-06 到期 |
| 本月回款（Web 收款口径 / App 台账口径） | 8,780.00 | 当前两端均排除历史归档项目的 10-06 收款 19,350；10 月恰好两口径同值，但公式不同，待统一 |
| 本月支出 | 540.00 | 手工公司费用 |
| 现金流 | 8,240.00 | 8,780 − 540 |
| 账户余额 | −11,937.36 | 期初未承接 + 手工费用大于累计收入 |
| 成本/利润 | 成本未完整，利润 `null` | 3 个结转项目成本快照 Unknown |
| 驾驶舱回款额 | 28,130.00 | 与财务工作台 8,780 不一致，待裁决统一 |

> 麦鸿 2026-10-07 口径核对（防止把「收款额」和「资金收入」混用）：
> - **累计收款（收款额 Receipt） = 118,900.00（11.89 万）** = 非归档项目收款 80,380.00 + 历史归档项目收款 38,520.00。
> - **资金收入（Ledger Income） = 120,900.00（12.09 万）** = 收款 118,900.00 + 手工「其他收入」2,000.00；这 2,000.00 不是收款。
> - **已收金额（应收核销，排除归档应收） = 80,380.00（8.04 万）**。
> - **账户余额 = 资金收入 120,900.00 − 资金支出 94,317.36 = 26,582.64**。
> - 三个数字差异来自「收款单 / 台账收入 / 应收核销」三种口径，页面命名和口径说明必须分别标注。

## 11. 异常处理

| 异常 | 处理 |
| --- | --- |
| 错记收款/付款 | 冲正 + 重记；保留原单据与审计 |
| 漏记应收/应付 | 补建计划或来源单据；不得用手工账替代 |
| 重复提交 | 幂等键返回原单据，不重复生成应付/流水 |
| 跨期调整 | 月结后新增调整/冲销，不改历史 |
| 成本缺失 | `costComplete=false`、利润 `null`，提示来源补齐 |
| 期初缺失 | 显示「期初未承接」，先承接再解读余额 |
| 历史归档项目 | 按统一归档口径处理；页面标注已排除 |
| 命名/口径冲突 | 登记 GAP/REQ-BIZ，不得先改代码或文案 |

## 12. 权限与留痕

- BOSS/财务：全公司查看与记账；工资/提成核算与发放。
- 店长：本店只读；敏感字段脱敏。

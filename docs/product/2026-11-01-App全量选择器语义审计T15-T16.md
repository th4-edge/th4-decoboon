## 1. 真实业务场景

### SCN-1 · 项目经理在工地现场写汇报

- 使用人：可写汇报的项目经理、设计师、店长或负责人。
- 触发事件：现场发生进度、材料进场、问题整改或阶段开工，需要选择本次汇报项目。
- 当前动作：打开项目选择页，按状态、来源和设计师筛选，比较客户、地址、阶段和责任人后选择。
- 系统下一步：一次性回传项目并按项目 ID 打开汇报表单；服务端再次校验项目访问权。
- 异常处理：无项目、无权限、接口失败、取消选择均保留原页面，不使用 ActionSheet 或默认第一项兜底。

### SCN-2 · 客户有多套房屋时约定量房

- 使用人：业务员、设计师、店长或负责人。
- 触发事件：客户有多套装修房屋，需要明确本次量房对象。
- 当前动作：进入房屋选择页，查看客户归属、小区、房号、面积、状态和最近量房时间后显式选择。
- 系统下一步：用所选 propertyId 保存量房预约，并回读该房屋已有预约。
- 异常处理：清除选择后不自动回退第一套；新增房屋后返回可重新选择。

### SCN-3 · 客户/项目指派人员

- 使用人：企业负责人、店长或有指派权限的角色。
- 触发事件：客户负责人/设计师变更，或项目项目经理/设计师变更。
- 当前动作：进入员工专用选择器，按岗位、门店、团队和状态检索。
- 系统下一步：按员工 ID 调用原客户或项目 Provider，服务端重新校验权限与数据范围。
- 异常处理：页面不再预先拉取员工全量数组，也不在来源页自建员工 ActionSheet/JzSheet。

### SCN-4 · 内容任务选择模板、费用录入选择分类

- 使用人：内容运营、财务或负责人。
- 触发事件：创建内容任务需要模板结构与时长；费用录入需要企业费用分类。
- 当前动作：分别进入内容模板/费用分类专用选择页，打开即展示数据并支持搜索、分页和业务摘要。
- 系统下一步：保存模板 ID 或费用分类 ID，服务端按企业范围再次校验。
- 异常处理：空列表、加载失败、搜索无结果均有明确恢复路径，不退回普通下拉。

### 有界子集例外

- 项目内阶段、施工区域、报价分区、设计空间、固定枚举、日期/时间仍可使用普通选择控件；这些都依赖当前父对象且不作为独立增长主数据。
- 门店选择仍按登录企业授权门店列表处理，属于有界组织集合。

## 3. T16 表单与结果确认

- 汇报项目选择完成后直接进入汇报表单，项目上下文头展示客户、地址和当前阶段。
- 量房页的房屋占整行，展示房号、地址、面积、户型、状态和最近量房；提供“更换房屋”，清除后不默认第一套。
- 客户/项目人员变更完成后回读客户或项目详情，不在来源页保留员工数组。
- 内容模板选择结果展示名称、画幅、建议时长和片段范围。
- 费用分类选择结果展示名称、说明和基础/企业分类；取消选择后表单不保留旧 categoryId。
- 所有选择页均具备加载、空、失败、搜索无结果、加载更多失败和清除状态。

## 4. 全量语义审计

- 命令：`npm run audit:selectors`
- 范围：263 个 App Vue 文件。
- 规则：识别 `JzSelectField` 标签、业务数组 ActionSheet、身份全量读取线索。
- 当前结果：92 个 JzSelectField 均通过固定枚举/有界子集初筛，硬违规 0。
- 3 处身份全量读取仅用于只读人数或绩效汇总，不承载对象选择：
  - `src/pages/mine/index.vue`：企业成员数量统计。
  - `src/subpackages/team/pages/designers.vue`：设计绩效汇总来源。

## 5. 负向用例

| 用例 | 预期 |
| --- | --- |
| 项目、员工、房屋、模板、费用分类使用 JzSelectField | 语义门禁失败 |
| 项目、员工列表作为 ActionSheet actions | 语义门禁失败 |
| 量房多套房 | 未选择时不能提交，不自动第一套 |
| 取消选择 | 清除当前对象；依赖字段回退，不保留旧值 |
| 项目/员工接口失败 | 显示失败和重试，不悄悄落到第一项 |
| 内容模板/费用分类搜索无结果 | 显示空态和重置条件 |
| 模板/分类请求 `size=200` | Provider 硬上限 50 |
| 内部编号 | 结果卡不以编号替代业务身份 |

## 6. T17 判定

- 本批不新增单据模板，不重做合同、费用、项目或内容任务的单据结构与状态机。
- 只替换业务对象入口、分页 Provider 和结果回显，`T17` 对单据化重做为不适用。
- 未完成独立验收、真机和有数据保存，不得据此宣称全端验收完成。

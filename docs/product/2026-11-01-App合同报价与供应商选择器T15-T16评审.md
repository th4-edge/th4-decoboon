## 1. 真实业务场景

### SCN-1 · 设计师从客户已确认报价发起合同

- 使用人：设计师；复核人：企业负责人/店长。
- 触发事件：客户已接受报价，需要生成合同基线并进入签约。
- 当前动作：设计师从合同创建页选择来源报价，核对客户、房屋、金额和设计师，再选择付款/施工计划。
- 系统下一步：服务端按报价 ID 回读合同上下文，保存时重新校验报价属于当前企业且状态为客户已确认。
- 异常处理：无已确认报价、接口失败、无权限、报价失效时不保留伪选中；重新加载或联系负责人确认报价状态。
- 下游影响：决定合同基线、签约金额默认值、项目来源和后续冻结明细。

### SCN-2 · 财务维护供应商/班组价格

- 使用人：企业负责人、店长或财务。
- 触发事件：同一报价库项目需要绑定具体供应商或班组的成本条件。
- 当前动作：先选供应商，再选报价库项目，维护人工/班组价、起订量、交期和账期。
- 系统下一步：服务端按 ID 校验合作方、项目均属于当前企业，并校验项目启用状态和金额非负。
- 异常处理：供应商停用、项目停用、无权限、接口失败时明确提示；不得用全量数组或默认第一项兜底。
- 下游影响：影响后续成本引用，不覆盖报价项目对客销售价。

## 2. T15 选型判定

| 字段 | 数据概念 | Provider / 组件 | 主筛选 | 最低业务摘要 | 结果契约 |
| --- | --- | --- | --- | --- | --- |
| 客户已确认报价 | 远程增长对象 `remote-search-page` | `quote-picker` + `tradeApi.page` / `quote/page`、`quote/designer/page` | 固定 `accepted`；当前客户/房屋或全部；关键词；分页 20 | 客户、房屋、金额、设计师、版本、确认状态 | `{action:'select',value:Quote}` / `{action:'clear'}` |
| 供应商/合作方 | 远程增长对象 `remote-search-page` | `supplier-picker` + `supplyApi.partnerPage` / `partner/page` | 合作类型、状态、关键词；分页 20 | 名称、合作状态、类型、结算账期、联系人、品牌、待付 | `{action:'select',value:Partner}` / `{action:'clear'}` |
| 报价库项目 | 树形远程对象 `tree-remote-search-page` | `CatalogPicker` + `catalogApi.page` / `catalog/item/page` | 类型、分类树、品牌、规格、关键词；分页 30 | 名称、分类、品牌规格、单位、可报价状态 | `select(CatalogItem)` |

### T15 硬约束

- 禁止原生 `picker`、`JzSelectField`、可筛选下拉承载上述对象。
- 报价选择器打开即加载已确认报价，不只显示搜索框。
- 供应商选择器默认展示合作中对象；切到停用状态时可见但不可用于新价格。
- 报价库项目继续使用 `CatalogPicker`，不另造第二套项目树选择器。
- 内部报价编号、供应商 ID、项目 ID 不作为用户识别依据。
- 所有列表由数据库分页；默认 20，硬上限 50。禁止 `size: 200`、`findAll` 后过滤和页面内全量数组。

## 3. T16 表单与结果确认

### 合同创建页

- 报价字段占整行，使用全宽已选业务卡。
- 已选卡展示：客户、报价名称/用途、房屋地址、报价金额、面积、版本、设计师、客户已确认状态。
- 提供“更换报价”和“清除”，合同生成后锁定并说明原因。
- 无选择时展示明确选择入口和业务说明，不显示空下拉。
- 报价变化时清空旧付款/施工计划等来源依赖，重新回读合同；从计划页返回不得覆盖用户已填最终签约金额。

### 供应商价格页

- 供应商和报价库项目分别使用全宽业务卡。
- 供应商卡展示名称、合作状态、类型、结算账期、联系人、更换、清除。
- 项目卡展示名称、分类、品牌规格、单位、可报价状态、更换、清除。
- 固定短枚举“项目分类”使用 chips，不使用业务对象下拉。
- 保存提交 `partnerId` 和 `itemId`，服务端重新做企业归属、权限和状态校验。

## 4. App/Web 同源对账

| 能力 | App | Web/后端同源要求 | 结论 |
| --- | --- | --- | --- |
| 客户已确认报价 | `quote-picker` 调 `tradeApi.page` | 同 `quote/page` / 设计师 Provider，同 `Accepted` 状态、企业/门店/本人范围 | 同 Provider 语义 |
| 供应商 | `supplier-picker` 调 `partner/page` | 同企业范围、状态、关键词和分页上限；应付摘要同源批量聚合 | 同 Provider 语义 |
| 报价库项目 | `CatalogPicker` 调 `catalog/item/page` | 同企业、类型、分类、品牌、规格、启用状态和成本权限裁剪 | 同 Provider 语义 |
| 保存复核 | `partner-price/save` | 服务端按登录员工企业和 ID 重新读取合作方、项目 | 不信任前端归属 |

## 5. 负向与异常用例

| 用例 | 预期 |
| --- | --- |
| 请求 `size=200` | Provider 硬上限为 50，不得返回 200 |
| 报价状态不是 `Accepted` | 选择页不返回；合同页拒绝绑定并提示重新确认报价 |
| 供应商已停用 | 可在“已停用/全部”中识别，但不能用于新价格 |
| 报价库项目停用 | `CatalogPicker` 默认不返回；编辑按 ID 回读时可识别停用并阻止保存 |
| 搜索无结果 | 显示真实空态与重置路径，不自动选第一条 |
| 接口失败 | 显示失败与重试，不清空当前有效回显 |
| 合同已生成 | 来源报价锁定，不能更换或清除 |
| 内部编号 | 合同、报价、合作方、项目结果卡不显示系统内部编号 |

## 6. T17 判定

- 本批不新增或重做单据形态，只替换既有合同创建表单与采购价维护表单中的业务对象入口和回显。
- 合同状态机、供应商价格公式、成本口径、权限矩阵均未改变。
- `T17` 对“新单据模板/重复预览重构”为不适用；不以此免除此后的独立验收。

## 1. 业务问题

- 当前场景：试用装企已有报价项目库，但数据量通常在数百条，逐条录入会直接阻断试用激活；当前只有小程序，没有可用的电脑端批量导入入口。
- 用户/角色：首期由 BOSS 在电脑上整理标准模板，再通过手机小程序上传；店长、财务保留逐条维护，不开放批量导入。
- 现有处理方式：已有个案脚本或服务器导入基础，但客户不能自助下载模板、选择微信文件、查看预览和确认导入。
- 希望解决的问题：建立“模板下载 → 电脑整理 → 手机上传 → 解析校验 → 预览确认 → 导入结果”的最小闭环，让试用客户能独立建立报价项目库。

## 2. 涉及条件

- 主对象：`CatalogItem` 及六类项目类型明细。
- 关联对象：登录员工 `Employee`、企业 `Company`、上传文件、导入批次记录。
- 当前/目标状态：无导入批次 → 已上传 → 已解析 → 待确认 → 导入中 → 已导入 / 导入失败 / 已撤销。
- 组织与数据范围：一级企业主数据；企业必须从登录员工加载，禁止接受前端传入 `companyId`、`maintainerId` 或跨企业归属。
- 权限：P0 仅 BOSS 可批量导入；标准成本仅 BOSS、店长、财务可见；普通员工、设计师、项目经理不得获得导入入口或成本字段权限。
- 金额/成本/指标：导入只形成企业报价项目主数据，不参与报价接受率、转化率、项目毛利等经营指标；成本缺失必须标记 `costComplete=false`，利润为空。

## 4. 候选方案

1. **标准模板导入（推荐 P0）**：客户从微信聊天下载 V1.0 模板，在电脑复制整理，手机端上传解析、预览确认后导入。优点是可校验、可回滚、误导入风险低，适合试用阶段。
2. **原表映射导入（下一阶段）**：客户上传自己的 Excel，系统识别列并由客户确认映射。优点是少整理，缺点是表头差异大、手机端映射复杂、错误责任不清，不进入本次开发范围。

## 5. 产品规划需要冻结的内容

1. 报价项目库维护页的“批量导入”入口、模板下载和文件选择交互。
2. 上传后的解析状态、预览字段、确认按钮、错误行处理和导入结果页。
3. 导入批次状态机、错误清单、撤销入口和撤销窗口。
4. 成本待维护在项目库列表、详情、设计选择和报价计算中的展示与阻断规则。
5. 固定总价字段在后端的映射方式，以及导入后报价计算的一致性。

## 8. 小程序操作流程

### 8.1 入口与模板下载

1. BOSS 进入“报价项目库维护”。
2. 页面顶部显示“批量导入”入口和 V1.0 模板说明。
3. 点击“下载模板”后打开文件，用户可通过微信发送到电脑或文件传输助手。
4. 页面同时提供简版操作说明，但不复制模板字段规则，避免两套口径漂移。

### 8.2 上传解析

1. 点击“批量导入”，打开“从微信聊天选择文件”。
2. 选择 `.xlsx` 或 `.csv` 文件后上传。
3. 页面显示上传、解析、校验进度。
4. 解析完成前不展示“导入成功”，也不写入正式表。

### 8.3 预览确认

预览页至少包含：

- 文件名、模板版本、总行数；
- 可导入、重复跳过、错误、成本待维护数量；
- 前 5 行样例；
- 错误行号 + 项目名称 + 错误原因；
- “确认导入”主按钮；
- “导出错误清单”或“转发错误清单”入口。

存在错误行时：

- 默认不允许直接导入；
- 用户可返回电脑修改后重新上传；
- 如允许“仅导入合格行”，必须二次确认，并明确显示将跳过多少行。

### 8.4 导入结果

结果页展示：

- 批次号、导入时间、操作人；
- 新增、重复跳过、错误、成本待维护数量；
- 导入结果的跳转入口；
- 在撤销窗口内显示“撤销本次导入”。

导入成功的项目必须立即在设计分项、套餐配置和报价选择中可见。

## 9. 研发侧建议边界

- 解析、预览不得写 `CatalogItem`；正式导入与预览必须是两个阶段。
- 预览和正式导入必须使用同一个校验版本，防止预览通过后写入时口径变化。
- 正式导入需批次化、幂等和失败回滚；不得留下半套项目。
- 成本空白不能落为 0。需要在报价项目模型上明确“成本待维护”的表达方式。
- 固定总价需要独立解析并映射到现有计价模型；不得把它误写成材料单价。
- 复用文件上传能力，但必须单独控制报价项目导入的文件类型、大小和权限。
- 不新增客户、房屋、报价、合同、项目或财务对象。

## 10. 需要产品规划输出

1. 小程序页面流程图和异常状态图。
2. 报价项目库批量导入的产品规格和字段展示口径。

5. 给开发的前后端接口范围、数据模型影响和迁移清单。
6. 给验收的正向、反向、越权、重复、边界和恢复用例。

## 11. 影响与截止时间

- 影响模块：小程序报价项目库、文件上传、报价项目库后端、设计报价选择、套餐配置、成本完整性。
- 不确认会阻塞：试用客户无法在短时间内建立报价项目库，影响设计、套餐和报价激活；历史数据迁移安排也会缺少清晰边界。
- 最晚决策时间：下一轮产品规划开始前。
- 本咨询单只解锁报价项目库主数据导入，不进入历史项目、合同、报价和财务迁移开发。

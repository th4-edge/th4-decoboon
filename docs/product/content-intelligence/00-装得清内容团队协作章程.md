# 装得清内容团队协作章程

> 日期：2026-10-29  
> 状态：`APPROVED_TEAM_MODEL`  
> 依据：`USER-DEC-20261029-001`、`USER-DEC-20261029-002`、装得清业务智能体  
> 目的：让装得清的场景事实同时支撑对外营销、入驻使用、理解比较、业务兼容和持续学习。

## 1. 团队定位

装得清内容团队由三个核心知识成员和多个执行/审查成员组成：

| 成员 | 主要职责 | 产物 |
| --- | --- | --- |
| `zhuangdeqing-business` | 业务事实、规则、场景、能力和证据 | `SCN/OBJ/BR/SOL/CAP/MET/EV/GAP`、T05/T06/T12 |
| `zhuangdeqing-marketing-content` | 把已核验场景转成对外营销内容资产 | `MC-*` 内容包、选题、价值主张、比较、证据边界 |
| `zhuangdeqing-usage-content` | 把同一场景转成入驻和使用内容资产 | `UC-*` 入驻、教程、FAQ、App/Web 对比、兼容台账 |
| `zhuangdeqing-marketing` | 渠道策略、发布、投流、线索和复盘 | `TOPIC/CONTENT/PUB/LEAD/EXP-*` |
| `zhuangdeqing-short-video-os` | 短视频内容和生产运营 | 短视频内容包、发布与复盘 |
| `zhuangdeqing-xiaohongshu` | 小红书图文、搜索和私域承接 | 图文笔记、关键词、私信承接 |
| `zhuangdeqing-product-app-development` | 产品应用路径、角色核验和产品缺口 | 场景核验、需求、产品改进 |
| `zhuangdeqing-ui-craft` | Web 页面理解、交互和视觉证据 | 页面设计/评审/渲染证据 |
| `zhuangdeqing-smb-reviewer` | 独立中小装企视角审查 | 反例、风险和学习建议 |

## 2. 一场景，两种表达

同一业务场景只能有一套事实，允许有不同表达目标：

```text
装得清业务智能体：事实
  ├→ 营销内容智能体：为什么值得了解/信任/比较/行动
  └→ 使用内容智能体：入驻后如何理解/操作/恢复/兼容
```

营销内容不得改写使用步骤，使用内容不得改写对外承诺。

## 3. 共享编号

- `SCN-*`：业务场景。
- `BR-*` / `CAP-*` / `MET-*` / `EV-*` / `GAP-*`：事实、能力、指标、证据和缺口。
- `MC-*`：营销内容包、选题、价值主张、证据表达和学习。
- `UC-*`：使用任务、入驻路径、FAQ、对比和学习。
- `UC-COMPAT-*`：实际业务与产品模型差异。
- `T05/T06/T12`：需要业务裁决和研发交接的问题。

## 4. 标准内容链

```text
真实场景/业务问题
→ 业务智能体核验事实
→ 场景内容简报（共享）
→ 营销内容智能体产出对外表达
→ 使用内容智能体产出入驻/操作/兼容内容
→ 渠道发布或客户成功交付
→ 线索、使用、客服和培训反馈
→ MC-LEARN / UC-LEARN
→ 业务复核或产品改进
```

## 5. 冲突处理

| 冲突 | 处理 |
| --- | --- |
| 业务事实冲突 | 停止内容，交 `zhuangdeqing-business` |
| 营销承诺与产品不符 | 停止发布，营销内容智能体 + 业务智能体 |
| 教程与当前页面不符 | 使用内容智能体 + 当前产品页面证据 |
| 企业实际做法无法兼容 | 使用内容智能体登记 `UC-COMPAT-*`，必要时 T05 |
| 内容问题还是产品问题不清 | 使用内容学习卡分流，禁止直接要求大改 UI |
| 数据/指标不清 | 业务智能体裁决，营销不得自行计算 |

## 6. 内容学习

- 营销：看内容质量、分发、人群、销售承接和产品事实五层。
- 使用：看用户卡点、内容理解、产品路径、数据问题和业务缺口五层。
- 只有重复出现且有证据的经验，才晋升为团队规则。
- 不用一次播放、一个客户问题或一次培训反馈改写业务事实。

## 7. 存储与边界

- 营销内容知识库：`推广营销/装得清营销内容智能体/`
- 使用内容知识库：`推广营销/装得清使用内容智能体/`
- 营销渠道产物：`docs/marketing/**`
- 使用内容产物：`docs/product/usage-content/**`（后续建立）
- 正式业务事实：`推广营销/装得清业务智能体/**`

## 8. 发布与外部动作

- 营销内容智能体不直接发布。
- 使用内容智能体不直接改产品。
- 渠道发布、投流、私信、上传素材、客户联系仍由现有营销执行成员按授权执行。
- 产品变更由产品研发/UI 成员执行，内容成员只提出证据和缺口。

# 装得清产品决策档案

> 用途：长期保存用户明确确认、会影响产品边界、角色、权限、跨端、对象、状态、金额或验收口径的产品决策。
> 边界：本目录保存产品侧决策与影响投影；正式业务事实仍以装得清业务智能体知识库为准，需要时通过 T05/T06/T12 同步。

## 决策状态

- `APPROVED`：用户已明确确认，可作为产品基线；
- `PENDING_SYNC`：用户已确认，但业务知识卡尚未同步；
- `SUPERSEDED`：已被后续决策替代；
- `REVOKED`：用户撤回；
- `SCOPED`：只适用于指定产品或阶段。

## 使用规则

1. 用户明确确认的关键产品边界必须进入本目录，不只保留在聊天中；
2. 每条决策必须写清影响范围、生效时间、关联矩阵和后续动作；
3. 与业务知识库不一致时，先登记同步问题，不静默覆盖；
4. 决策影响研发时，转入 `docs/product/issue-governance/` 或领域交付包；
5. 产品基线、角色矩阵、跨端矩阵必须引用决策编号。

## 决策内容

1. 报价在 App、Web、业主端、项目、合同、客户钻取和报价入口中必须是统一视图；
2. 统一视图必须基于同一个 `quoteId + version` 和同一组报价行；
3. 必须同时支持按区域、按类型查看；
4. Web 设计师报价工作台的三栏、区域表格、版本和决策面板交互作为主要参考；
5. 场景差异只允许体现在宿主上下文、权限、动作、字段可见性和设备密度；
6. 不允许各页面分别重算金额、合并行、重做分组或显示不同版本；
7. 该规则应先形成报价统一视图契约，再交给现有修复会话研发和验收。

## 决策内容

1. 项目视图必须成为项目事实追踪的主入口；
2. 通过项目视图可以查看量房、设计方案、报价、签约合同、增减项、选材及其他项目事实；
3. 项目视图展示事实摘要、来源、版本、状态和跳转，不复制完整对象明细；
4. 每个事实节点必须能追溯到来源对象和版本；
5. 业主端看到同一项目事实链的授权子集，不看到内部成本和内部动作；
6. 现有业主旅程可以作为项目事实追踪的一种场景投影，但不能成为另一套事实源。

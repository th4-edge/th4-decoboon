## 决策内容

1. 项目可以作为事实追踪根，合同同样可以；
2. 合同视图必须能看到合同之前的量房、设计方案、报价等上游事实；
3. 合同视图还必须能看到合同之后形成的项目、增减项、选材、材料、验收和财务事实；
4. 上游事实只显示摘要、版本、状态和跳转，不复制完整明细；
5. 合同必须绑定其实际引用的报价版本，并沿报价追溯设计方案与量房快照；
6. 合同、项目、业主等场景不得显示“最新报价/最新设计”替代合同签约依据；
7. 事实链应复用 `USER-DEC-20261022-003` 的统一业务对象视图规则。

# USER-DEC-20261029-002 · 装得清内容团队职责边界

- 决策日期：2026-10-29
- 决策人：用户
- 状态：`APPROVED`
- 类型：智能体团队、营销内容、使用内容、学习闭环
- 关联：`USER-DEC-20261029-001`

## 1. 用户确认

装得清产品价值需要持续转化为两类可复用内容：

1. 对外营销内容；
2. 入驻以后使用、理解、比较和业务适配内容。

两类内容必须来自同一业务事实源，不能各自编一套产品口径。

## 2. 新增团队成员

### `zhuangdeqing-marketing-content`

职责：

- 把已核验装企场景转成营销价值主张、场景内容矩阵、短视频/图文简报、对比内容和证据边界。
- 维护 `MC-*` 营销内容资产。
- 向现有 `zhuangdeqing-marketing`、`zhuangdeqing-short-video-os`、`zhuangdeqing-xiaohongshu` 移交内容包。
- 接收发布、线索和销售反馈，形成内容学习。

不负责：

- 业务事实裁决；
- 渠道发布、投流、私信；
- 使用操作教程；
- 产品研发和 UI 实现。

### `zhuangdeqing-usage-content`

职责：

- 把同一已核验场景转成入驻路径、角色使用手册、单任务教程、FAQ、App/Web 对比、异常恢复和兼容记录。
- 维护 `UC-*` 和 `UC-COMPAT-*` 资产。
- 处理企业实际做法与产品模型不对称的兼容分类。
- 向客户成功、培训、产品帮助和营销内容提供真实使用路径。

不负责：

- 业务事实裁决；
- 修改产品代码、权限、金额或状态机；
- 对外营销主张；
- 把 workaround 写成正式功能。

## 3. 共同规则

- 业务事实只来自 `zhuangdeqing-business`。
- 同一场景可分别产出营销表达和使用内容，但共享业务事实和证据边界。
- 营销内容与使用内容互相引用，不互相改写。
- 内容复盘沉淀到各自学习日志，重复证据后再升级为团队规则。
- 现有渠道营销执行、产品研发、UI Craft 和独立审查职责不变。
- 用户保留发布、高风险内容、业务取舍和正式发版最终决定权。

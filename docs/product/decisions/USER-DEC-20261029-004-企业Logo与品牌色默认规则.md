# USER-DEC-20261029-004 · 企业 Logo 与品牌色默认规则

- 决策日期：2026-10-29
- 决策人：用户
- 状态：`APPROVED`
- 关联：`USER-DEC-20261029-003`、`enterprise-brand-profile`

> 后续决策：`USER-DEC-20261029-006` 已确认企业可自定义品牌色，并将品牌色作为 App/小程序/Web 的统一主题色主源。本文件中“后续允许企业替换品牌色时另行确认”的待决部分现已关闭。

## 1. 企业 Logo

1. Logo 首先使用企业真实上传/维护的品牌资产。
2. 未上传 Logo 时，默认以企业简称首字生成中性品牌占位。
3. 简称首字占位只属于展示投影，不写入企业真实 Logo 资产字段。
4. 占位不冒充平台 Logo，也不用于正式合同/凭证中的“企业已上传 Logo”语义。
5. 若企业尚未填写简称，快速入驻阶段可取企业展示名称首字作为临时展示兜底，并在企业信息页提示完善简称。

## 2. 品牌色

1. 企业品牌色默认使用装得清品牌主色语义。
2. 默认值应引用平台唯一品牌 Token，不硬编码为互相漂移的多套颜色。
3. 默认品牌色不是企业自定义事实，不写入“已自定义品牌色”状态。
4. 后续允许企业替换品牌色时，另行确认可配置范围、对比度、打印和无障碍边界。

## 3. 投影规则

- 有真实 Logo：显示真实 Logo。
- 无真实 Logo：显示简称首字占位，可配置底色和文字对比度。
- 默认品牌色：当前端使用平台品牌语义主色。
- 自定义品牌色：仅在获批后使用，并保留来源与更新时间。

## 4. 展示边界

- Logo 占位必须可被识别为系统占位，不得伪造企业已上传品牌资产。
- Logo 占位和默认品牌色可保证业务连续，但不能替代法定企业身份、合同抬头或资质证明。
- 企业信息页需要展示“当前为默认品牌展示”并保留上传/自定义入口。

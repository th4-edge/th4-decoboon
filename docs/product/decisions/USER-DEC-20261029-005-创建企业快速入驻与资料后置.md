# USER-DEC-20261029-005 · 创建企业快速入驻与资料后置

- 决策日期：2026-10-29
- 决策人：用户
- 状态：`APPROVED`
- 关联：`USER-DEC-20261029-003`、`USER-DEC-20261029-004`、`enterprise-brand-profile`

## 1. 创建企业首屏

创建企业只要求：

1. 企业负责人姓名；
2. 企业展示名称。

负责人姓名优先使用微信昵称自动带入，用户可修改。企业名称用于首页、邀请和员工识别，最多 12 字。

## 2. 不在创建时录入

以下信息从创建企业首屏移除，入驻后通过“我的 → 企业信息”持续完善：

- 企业法定全称；
- 企业地址；
- 企业 Logo；
- 品牌色；
- 服务区域、客服/售后、资质、简介等对外服务资料。

## 3. 占位和法定身份

- 快速创建时企业展示名称可作为系统的临时企业标题，用于内部识别和当前页面展示。
- 它不代表已确认的企业法定全称。
- 在生成正式合同、税务/银行相关凭证或其他需要法定主体的文件前，必须补充并确认企业法定信息。
- 后续 `DocumentProfile` 只能使用 Company 法定信息的投影/快照，不得把临时展示名称当作法定名称静默输出。

## 4. 已有在建项目

- 创建企业首屏不再询问是否有在建项目。
- 创建成功后直接进入企业首页。
- 已有在建项目通过首页的业务承接入口后续处理，不阻塞企业创建。

## 5. 交互要求

- 不额外调用 `getUserProfile`；负责人姓名使用已有微信昵称或微信昵称输入能力。
- 创建成功后自动建立默认总店。
- 创建过程保持短表单、单主行动，不混入不一致的开关控件。

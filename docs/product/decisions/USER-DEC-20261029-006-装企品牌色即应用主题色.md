# USER-DEC-20261029-006 · 装企品牌色即应用主题色

- 决策日期：2026-10-29
- 决策人：用户
- 状态：`APPROVED`
- 关联：`USER-DEC-20261029-003`、`USER-DEC-20261029-004`、`enterprise-brand-profile`

## 1. 产品主体

- 装得清是软件提供者，负责 App、小程序、Web、权限、数据和记录存证能力。
- 装企是业务服务主体，员工与业主看到的品牌主体必须是装企。
- 不再向装企提供“对外展示主体: 装企/平台”或“记录存证署名开关”。该配置没有业务意义。
- 软件提供者身份采用固定、非配置化表达，不与装企品牌争夺叙事主体。

## 2. 品牌色即主题色

`Company.color` 是企业品牌色唯一主源，同时作为：

- 微信小程序/App 主题色输入；
- Web 主题色输入；
- 企业 Logo 占位与品牌强调色输入。

未配置时使用装得清默认品牌主色，不把默认值写回企业自定义事实。

## 3. 派生规则

装企只能选择或输入品牌基色，其他主题色由系统统一派生：

- 浅色背景、浅色边框、悬停态；
- 主操作色、深色强调、导航/页签选中态；
- 品牌渐变、阴影、焦点环；
- 品牌底色上的可读前景色。

成功、警告、危险、业务状态色不随品牌色改变，避免破坏业务语义。派生算法必须同时满足交互可读性和视觉一致性。

## 4. 投影与同步

- App/小程序：页面级主题变量覆盖主包与分包，导航、主按钮、选中态、页签、品牌卡片跟随企业色。
- Web：运行时覆盖品牌 Token 与 Element Plus 主色，侧边栏、按钮、选中态、链接与品牌工作面跟随企业色。
- 业主入口：按当前项目所属企业品牌色显示，不混用平台默认色。
- 同一企业修改品牌色后，重新进入或页面重新获得焦点时读取同一 Company 主档并更新主题。
- 历史合同/PDF/导出文件不因当前主题更新而回写；文件品牌快照仍单独治理。

## 5. 验收边界

- 自定义颜色不能只改一个 Logo 背景，必须改变应用主题色阶。
- 不允许出现品牌色导致白字不可读、选中态消失或业务状态色被覆盖。
- 不以“Token 已存在”替代真实页面换色；必须有 App 页面数据、Web CSS 变量和真实渲染证据。

## 6. 推荐色板

装得清自身产品默认色继续保持 `#16A394`，不因企业主题体系改版而替换。企业可选主题按站酷高赞 B 端的“浅中性画布 + 单一低饱和强调色”原则配置为：青瓷 `#5C7C6E`、松石墨绿 `#2F6E63`、岩蓝 `#4F708C`、赤陶 `#A65F46`、胡桃 `#7A5540`、黛紫 `#675D7B`、墨灰 `#3F4B53`。完整依据见 `docs/product/domains/enterprise-brand-profile/01f-brand-color-palette-v1.md`。

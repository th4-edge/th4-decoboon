## 4. 人工门禁

遇到以下情况必须停止该分支并写入决策包：

- 新业务对象、状态、角色或数据范围；
- 金额、成本、利润、权限、支付语义变化；
- DDL、迁移、生产数据删除；
- 正式小程序提审与发布；
- 密钥、生产配置、对外消息；
- 需要业务负责人拍板的范围取舍。

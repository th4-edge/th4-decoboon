# 装企信息与品牌投影 · 真实业务场景

## 场景 A：新装企入驻并第一次对业主露出

| 项 | 内容 |
| --- | --- |
| 使用人/角色 | BOSS、业主 |
| 触发事件 | 新装企完成企业开通，准备邀请员工、签约首个项目并向业主展示服务方 |
| 前置条件 | 企业主体已创建；BOSS 有企业资料维护权限 |
| 当前动作 | BOSS 在 App/Web 填写企业全称、简称、地址、服务区域、客服/售后、税号、资质、简介和品牌署名；上传企业 Logo 和品牌色（当前前端入口仍不完整） |
| 系统下一步 | 形成企业品牌主档；业主端、邀请卡片和单据使用同一投影；缺失字段明确提示 |
| 成功结果 | 业主看到正确的装企名称、Logo、服务区域、客服和服务地址；员工和财务使用同一企业信息 |
| 异常/恢复 | Logo 上传失败、地址无地图点位、企业资料不完整时显示“暂不可确认”和补齐入口，不展示平台 Logo 冒充装企 |
| 涉及对象 | Company、EnterpriseBrandAsset、ServiceLocation、CustomerJourney.Vendor、DocumentProfile |
| 状态变化 | 企业资料 Draft/Incomplete → Active/Complete；对外投影只读 |
| 金额/成本/权限 | 不涉及金额；仅 BOSS 修改企业主档 |
| 证据/来源 | USER-DECISION-20261014-002、BR-059、当前 App/Web 企业信息页 |

## 场景 B：企业换品牌后，历史合同和导出的边界

| 项 | 内容 |
| --- | --- |
| 使用人/角色 | BOSS、财务、业主 |
| 触发事件 | 装企更换企业名称、Logo、地址或客服电话 |
| 前置条件 | 已有历史合同、报价和凭证；当前主档可更新 |
| 当前动作 | BOSS 更新企业品牌信息；财务重新生成或打印历史单据；业主重新打开历史项目 |
| 系统下一步 | 当前页面采用新品牌；已签署合同、已生成单据和历史业主证据按原版本展示；需要重新出具时生成新版本或新快照 |
| 成功结果 | 新业务使用新品牌，历史合同不被改写，业主能理解品牌变更 |
| 异常/恢复 | 旧合同缺少品牌快照时显示来源时间和“按归档文件展示”，不得用当前 Logo 覆盖历史文件 |
| 涉及对象 | Company、BrandSnapshot、ProjectContract、DocumentRecord、CustomerJourney |
| 状态变化 | 当前品牌 Active → 新版本；历史快照 Immutable |
| 金额/成本/权限 | 不涉及金额；品牌变更仅 BOSS |
| 证据/来源 | BR-059、凭证模板设计、DocumentArchiveContext、当前 PDF 渲染代码 |

## 场景 C：多门店企业的服务地址与地图

| 项 | 内容 |
| --- | --- |
| 使用人/角色 | BOSS、StoreManager、业主 |
| 触发事件 | 企业有多个门店，业主需要知道由哪家门店服务、门店在哪里、联系谁 |
| 前置条件 | 多门店启用；客户/项目有门店归属；门店地址可用 |
| 当前动作 | BOSS/StoreManager 维护门店名称和服务地址；业主在“我的家”查看服务方与位置 |
| 系统下一步 | 显示“企业品牌 + 服务门店 + 地址/地图 + 统一客服”；项目施工地址单独展示 |
| 成功结果 | 业主不会把施工工地地址误认为装企门店地址，导航和联系路径清楚 |
| 异常/恢复 | 无门店地址或无地图点位时显示文字地址或“暂不可确认”，不借用总店地址 |
| 涉及对象 | Company、Store、Property、Project、ServiceLocation |
| 状态变化 | 门店地址当前版本更新；项目地址不受影响 |
| 金额/成本/权限 | 不涉及金额；门店维护权限待裁决 |
| 证据/来源 | Company/Store 当前模型、CustomerJourney、用户本次需求 |

## 反向场景

- 越权：店长修改企业 Logo、法定名称或银行账号应拒绝。
- 跨租户：业主或员工不得读取其他企业的 Logo、地址、资质和开户信息。
- 重复源：Company 与 DocumentProfile 同名同义字段不得各自静默修改。
- 历史回溯：更新 Logo/地址后，历史合同不得自动换成新品牌。
- 数据缺失：无 Logo、无地址、无地图点位、接口失败不得显示为平台默认品牌或空成功态。
- 状态不满足：未选择具体门店时，不得默认使用第一条门店地址。
- 敏感字段：业主端不得显示银行账号、成本、员工个人手机号和内部审计信息。

# 装企品牌主题色板 v1

> 状态：`candidate / 待用户视觉确认`  
> 依据：`USER-DEC-20261029-006`、站酷高赞 B 端研究 `zcool-research.md`、装得清 App/Web 主题派生规则。

## 1. 设计结论

站酷高赞 B 端作品的共同点不是高饱和“科技色”，而是：

- 大面积浅中性画布；
- 一个低饱和、可长期使用的品牌强调色；
- 状态色独立且克制；
- 品牌色通过层级、留白、边框和数据强调产生高级感。

家装装企的业务语境更接近空间、材料、生活方式和长期服务关系，因此推荐色采用自然材料与室内设计常见的松石、青瓷、岩蓝、赤陶、胡桃、黛紫和墨灰。

## 2. 推荐色板

| 色名 | 基色 | 白字对比度 | 使用建议 |
| --- | --- | ---: | --- |
| 装得清默认（平台产品色） | `#16A394` | 3.13 | 企业未自定义时保留装得清原有产品色，不作为企业推荐色 |
| 青瓷 | `#5C7C6E` | 4.60 | 自然、温和，适合设计/软装型装企 |
| 松石墨绿 | `#2F6E63` | 5.95 | 稳重、克制，适合大多数装企 |
| 岩蓝 | `#4F708C` | 5.21 | 理性、克制，适合工程管理型装企 |
| 赤陶 | `#A65F46` | 4.83 | 温暖、有辨识度，适合住宅整装品牌 |
| 胡桃 | `#7A5540` | 6.56 | 沉稳、质感，适合中高端定制品牌 |
| 黛紫 | `#675D7B` | 6.13 | 雅致、设计感，适合女性或设计驱动品牌 |
| 墨灰 | `#3F4B53` | 8.96 | 中性、专业，适合强调工程与交付的装企 |

企业推荐基色与白字对比度均达到正文 AA `4.5:1`。装得清产品默认色作为平台身份保留，不参与企业推荐色排序。系统继续派生浅色、深色、渐变、焦点和交互前景色。

## 3. 选择原则

- 装得清未配置企业品牌色时，App/小程序继续使用产品青绿 `#16A394`，Web 继续使用产品品牌绿 `#2F7D5A`。
- 企业在 App/Web 选择主题时，页面同时展示浅色、主色、深色和业务气质说明；企业只需选择基色，完整色阶由系统派生。
- 松石墨绿只是企业可选主题，不替换、不弱化装得清自身产品色和企业既有使用习惯。
- 不使用高饱和科技蓝、霓虹紫、橙色作为推荐品牌色。
- 品牌色只承担品牌识别、主操作、选中态和关键强调，不覆盖页面背景和警告/危险状态。
- 品牌色与业务状态色必须分离。
- 企业自定义颜色仍允许输入 `#RGB` / `#RRGGBB`，但系统必须实时派生可读色阶并验证对比度。

## 4. 页面应用

- 页面底色：装得清中性产品色 `#F4F7F8`。
- 企业 Hero：使用品牌色深色渐变。
- 登录页：品牌色只用于企业标识、焦点、主按钮和项目主线节点；页面继续保持浅中性画布。
- Logo：在品牌 Hero 使用白色承载面。
- 我的用户 Hero：品牌最浅色到白色。
- 图标底：品牌最浅色/浅色。
- TabBar：中性白底，边框/阴影使用品牌透明色。
- 财务 Hero：统一品牌渐变。

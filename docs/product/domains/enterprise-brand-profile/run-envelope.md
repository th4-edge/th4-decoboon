# 装企信息与品牌投影 · Run Envelope

> 当前授权仅覆盖概念梳理、只读代码/页面核对、缺口登记和业务咨询；不覆盖生产修改。

## 1. 目标

- Domain：`enterprise-brand-profile`
- North Star：装企主体、品牌、地址、联系方式和资质在 App、Web、合同、单据导出打印及业主端保持单一主源、清晰语义、冻结快照和可追溯投影。
- 目标角色：BOSS、StoreManager、Finance、Designer、Pm、Marketer、业主、平台运营。
- 本期范围：企业信息概念、主源、地址语义、Logo、地图、联系信息、单据投影、业主投影、快照和下游对账。
- 本期不做：代码修改、DDL、迁移、权限放宽、客户展示 UI 改造、营销发布。

## 3. 自主决策权限

- 可以决定盘点方法、文档结构、证据命名和只读核对方式。
- 可以在已确认事实范围内提出候选概念 ID 和候选模型。
- 不自行决定主源、字段是否上线、权限、页面行为、数据库结构或历史回溯规则。

## 4. 人工门禁

- 新业务对象、地址/地图字段、Logo 资产、快照对象。
- 权限和敏感信息展示。
- 合同、凭证、税务、银行信息。
- DDL、迁移、生产数据、对外展示和正式发版。

## 5. 质量门禁

- 每个结论有业务来源或明确标记为候选；
- 当前状态有代码/页面证据；
- 主源、投影、快照、缺失态和受众边界清楚；
- 任何人不能以字段存在替代业务闭环；
- 未裁决前不进入蓝图和编码。

## 6. 预算与止损

- 本批最多进行 1 次业务咨询；
- 业务未答复时继续只做只读映射和缺口整理；
- 不以新增更多推测替代业务裁决。

## 7. Return Packet

返回：概念图、当前状态、重复主源、缺失链路、T05 问题、建议切片和是否可进入 BIZ_ALIGNED。

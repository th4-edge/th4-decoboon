# 企业运营标准资产 · 业务域章程

- Domain：`enterprise-operations-standards`
- Owner：codex
- Created：2026-10-22
- North Star：五类企业运营标准资产具备与业务语义匹配的生命周期、版本或修订、平台基线边界、业务快照与历史保护，并在 App/Web 提供一致完整能力
- 关联问题：`PI-20261022-003`

## 1. 业务问题

- 当前场景：报价项目库、套餐模板、付款计划模板、施工计划模板、单据/凭证模板分别由 catalog、pack、plan、document 承载，生命周期与版本语义不统一。
- 谁遇到问题：企业负责人、店长、财务、设计师、业务员、项目经理；平台运营维护平台基线。
- 当前损失/风险：套餐修改覆盖历史来源；付款/施工模板版本号增加但旧内容不可还原；Web 缺少三类模板管理入口；同类资产命名和状态不一致。
- 希望达到的结果：按资产语义治理生命周期、版本/修订、平台基线、业务快照和历史保护；App/Web 使用同一后端语义。

## 2. 目标角色

| 角色 | 主要目标 | 关键动作 | 不负责什么 |
| --- | --- | --- | --- |
| 企业负责人 Boss | 管理企业标准资产与经营边界 | 维护五类资产；治理企业配置 | 不替代业主确认，不绕过版本/状态 |
| 店长 StoreManager | 维护影响全企业的业务标准 | 维护报价项目、套餐、付款/施工/凭证模板 | 不获得企业治理或跨店业务可见性 |
| 财务 Finance | 维护报价成本与凭证模板 | 维护报价项目库、凭证模板 | 不维护套餐/付款/施工模板 |
| 设计师 Designer | 使用标准资产完成设计报价 | 查看资产并生成业务快照 | 不维护模板或成本 |
| 项目经理 Pm | 使用合同计划执行履约 | 查看合同快照与计划 | 不回写模板历史 |
| 业主 Customer | 查看本人业务事实 | 查看合同、报价、凭证产物 | 不进入企业标准资产管理 |

## 3. 本期范围

- 必须做：五类资产的生命周期、版本/修订、来源、业务引用和实例快照契约；各资产业务切片；App/Web 能力一致。
- 暂时不做：套餐默认、平台行业套餐基线、平台行业报价项目基线（`GAP-063`）。
- 明确排除：设计模版方案库、供应商/材料主数据、经营目标、会计记账凭证。

## 4. 主链

```text
企业维护标准资产
→ 草稿/持续修订
→ 发布或启用
→ 业务实例引用并保存来源与快照
→ 资产升级/停用
→ 历史实例继续读取当时版本或快照
```

## 5. 关键不变量

1. 资产是否版本化由业务语义决定，不机械统一状态机。
2. 发布/启用版本不可原地覆盖；报价项目库至少保留 revision 和不可变变更审计。
3. 历史业务不得从当前资产或最新模板重算。
4. 平台基线不得自动改写企业副本。
5. 停用只阻止新业务，不改变历史实例。
6. 角色、权限、金额和成本口径不因本域实现而扩大或改变。
7. App/Web 必须同状态、同版本、同权限、同异常恢复语义。

## 6. 金额/成本/权限边界

- 金额：不改变销售价、合同金额、应收应付和凭证金额公式。
- 成本：标准成本、套餐成本和成本可见性沿用既有决策；缺少应计成本时不得用 0 冒充。
- 权限：报价项目库 BOSS/店长/财务维护；套餐/付款计划/施工计划 BOSS/店长维护；凭证模板 BOSS/店长/财务维护。
- 跨租户/数据范围：标准资产按 Company 隔离；店长企业级主数据写权限不扩大跨店业务可见性。

## 7. 成功指标

- 产品：五类资产生命周期和版本语义可在统一契约中查询。
- 数据质量：历史来源版本缺失可明确标记，不伪造回填。
- 业务结果：模板升级不回溯历史报价/合同/凭证。
- 安全：跨企业/越权/并发覆盖负向用例全部通过。

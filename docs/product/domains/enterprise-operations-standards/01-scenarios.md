# 企业运营标准资产 · 真实业务场景

## 场景 A：套餐模板升级不回溯历史报价

| 项 | 内容 |
| --- | --- |
| 使用人/角色 | 店长；企业负责人；设计师 |
| 触发事件 | 企业调整主推套餐的牌价、项目行和成本 |
| 前置条件 | 套餐 v1 已发布，已有客户报价绑定 v1 |
| 当前动作 | 店长创建 v2 草稿，核对项目行后发布 |
| 系统下一步 | v2 用于新报价；v1 保持可读；历史报价继续读取 v1 或当时完整快照 |
| 成功结果 | 新报价使用 v2，历史报价金额与成本不变 |
| 异常/恢复 | 并发发布冲突时提示刷新；失败时 v1 继续有效 |
| 涉及对象 | PackageTemplate、PackageVersion、Quote、QuoteLine |
| 状态变化 | v2 Draft → Published；v1 Published → 历史版本 |
| 金额/成本/权限 | 不改变公式；店长维护；历史成本不重算 |
| 证据/来源 | `DEC-083`、`BR-051`、`T12-BIZ-20261022-004` |

## 场景 B：施工计划模板升级与合同快照

| 项 | 内容 |
| --- | --- |
| 使用人/角色 | 企业负责人、店长、项目经理 |
| 触发事件 | 企业调整标准施工阶段和工期 |
| 前置条件 | 施工模板 v1 已启用，合同 A 已保存 v1 阶段快照 |
| 当前动作 | 店长基于 v1 创建 v2 草稿并启用 |
| 系统下一步 | 新合同可选择 v2；合同 A 继续读取 v1 阶段快照；平台基线升级仅提示 |
| 成功结果 | 历史合同基准工期、阶段和应收触发不被改写 |
| 异常/恢复 | 停止或升级失败时保留 v1；来源版本缺失显示不可确认 |
| 涉及对象 | CompanyConstructionPlan、ContractConstructionPlan、ContractConstructionStage |
| 状态变化 | v1 Enabled → 历史；v2 Draft → Enabled |
| 金额/成本/权限 | 不改变合同金额；总工期遵循 `DEC-048` |
| 证据/来源 | `DEC-048`、`DEC-083`、`GAP-062` |

## 反向场景

- 越权：财务写套餐/付款/施工模板；设计师、业务员、项目经理写任何模板。
- 重复提交/幂等：重复发布、重复停用、重复设默认返回同一有效结果。
- 跨租户/跨项目：跨企业 templateId/sourceId/code 返回 403/404。
- 数据缺失：历史来源版本不可确认时仍可读取既有快照，不猜测回填。
- 状态不满足：停用/草稿模板不得用于新业务。
- 金额/成本不完整：不得以 0 成本计算利润或毛利。

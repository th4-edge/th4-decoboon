## 北向目标

五类企业运营标准资产具备与业务语义匹配的生命周期、版本或修订、平台基线边界、业务快照与历史保护，并在 App/Web 提供一致完整能力。

## 依赖与顺序

```text

```

## 回滚

- EOP-V1 无 DDL、无数据写入；回退新增契约类、Provider 和测试即可。
- EOP-V2～V5 的 DDL、迁移、权限和跨租户变更必须备份、全量测试和回滚脚本。
- EOP-V6 前端页面独立回退，不改历史数据。

## 门禁

- EOP-V1 已通过独立验收，状态 `ACCEPTED`。
- EOP-V2、EOP-V3 已独立验收；EOP-V4 已完成定向测试、双端构建和迁移 128 演练，当前为 `DEV_VERIFIED`，等待独立验收。
- EOP-V4 的真实 App/Web 页面证据仍由 EOP-V6 统一完成；开发自测不得替代独立验收。

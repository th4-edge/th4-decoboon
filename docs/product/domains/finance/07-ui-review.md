## 3. 机器预检摘要

### 财务工作台

- 3 秒内难以确定先看什么、先做什么；
- 关键信息（现金余额、待收、待付、风险）没有形成单一结论和唯一主行动；
- 信息密度高，卡片、说明和快捷入口同时竞争；
- 卡片墙、药丸标签、英文 eyebrow 和说明性文案有 AI 味风险；
- 建议方向不是“增加个性”，而是减少竞争、收敛层级、强化对象与行动。

### 财务台账

- 表格和筛选可用，但页面缺少“当前核对结论”；
- 状态标签对比度、行高一致性和导航层级需复核；
- 行操作与高危动作的视觉层级需重新设计；
- 历史日期默认值不能作为当前业务规则证据。

## 4. 已有架构/体验问题

| 问题 | 证据 | 影响 | 目标修正 |
| --- | --- | --- | --- |
| 首页是功能集合 | `FinanceWorkbenchView.vue` 当前仍有指标、快捷入口、应收/应付表和最近流水 | 用户需要自己判断先做什么 | 结论带 + 风险队列 + 唯一主行动 |
| 财务菜单承载跨域能力 | 财务菜单含客户、报价、材料、薪酬 | 业务域与角色投影混用 | 跨域能力回主域，财务只做投影 |
| 同对象多入口 | 项目、材料、报价、薪酬在 `/finance` 有副本 | 状态/金额/动作不一致 | 一对象一主工作面 |
| 动作密度高 | 历史审计：一个页面可有大量按钮 | 主行动不突出，误操作风险 | 一状态一主行动，其余降级 |
| 高危动作与普通动作混排 | 台账删除/更正与普通行操作并列 | 安全风险 | 安全门 + 影响预览 + 二次确认 |
| 页面七态不统一 | 各页 skeleton/empty/error 实现不一致 | 失败/无权限/空数据混淆 | 共用 `EmptyErrorPanel`/`DataQualityBanner` |
| 汇总口径差异 | 历史审计首页待付 1,040 vs 应付页 1,140 | 用户不信任数字 | Provider 字段对账 + 同对象同口径 |
| 视觉 Token 与语法未统一 | 指标卡、表格、三栏、抽屉、设置表单混用 | 学习成本高 | 7 类页面母型 + 共享组件 |

## 1. 设计意图

页面不是三栏对象工作面，而是角色化客户卡片场景：

```text
角色统计
→ 门店范围与查询筛选
→ 负责人分组（适用角色）
→ 客户卡片
→ 客户详情
```

客户卡是业务桥接点，承担身份、协同人、经营事实和下一步。

## 2. 角色投影

### 企业负责人

- 全企业客户经营统计；
- 门店筛选；
- 负责人分组；
- 客户卡聚焦客户变化、风险、负责人、跟进、报价、签约和项目。

### 店长

- 本店客户经营统计；
- 本店负责人分组；
- 统计口径与企业负责人一致，范围锁定本店；
- 不显示跨店合计。

### 财务

- 同一客户卡片体系；
- 合同、项目、待收、逾期为卡片主摘要；
- 保留量房、设计、报价、合同状态；
- 当前下一步围绕财务动作；
- 不复制财务台账和专业工作台。

## 3. 真实与预览

- 真实模式消费现有客户、项目、设计、报价、应收 Provider；
- `?preview=1` 使用示例数据，供登录后感受页面结构；
- 预览模式在页面顶部明确标注“示例数据”。

## 4. Token 与组件复用

- 使用 Web `tokens.scss`；
- 复用 `StoreScopePicker`、`StatusTag`、`SkeletonBlock`、`EmptyState`、`NavIcon`、客户编辑/新增/跟进/流失组件；
- 不新增设计语言；
- 不引入 2.5D/3D。

## 5. 七态

- 正常：真实数据/预览数据；
- 加载：客户卡骨架；
- 空：真实无客户或筛选无结果；
- 失败：Provider 失败提示；
- 无权限：由现有角色路由与服务端兜底；
- 长内容：卡片文本截断与详情展开；
- 极端值：金额等宽显示、缺值暂不可确认。

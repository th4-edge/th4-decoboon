## 1. 本轮修正

用户评审指出 v1 存在四个问题：

1. 页面过度偏财务，合同、项目、待收、逾期占据客户卡主体；
2. 客户卡没有像小程序一样表达“客户现在是什么样”；
3. 存在“财务关注优先 / 风险优先 / 金额优先”等排序项；
4. 财务角色没有左侧负责人分组，空客户时分组区消失。

v2 将页面重新收敛为**客户中心卡片场景**，财务信息只作为客户卡底部的低权重业务上下文，不再主导客户首屏。

## 2. 冻结结构

```text
角色统计
→ 门店范围 / 搜索 / 客户状态筛选
→ 左侧负责人分组查询（所有内部角色常驻）
→ 客户卡片
→ 客户详情抽屉
```

- 不显示排序选择，不按金额、风险、财务关注度由前端重排；
- 客户列表顺序沿用 Provider 返回值；
- 左侧分组始终存在，至少显示“全部客户”；
- 当前范围无负责人时显示“当前范围暂无负责人分组”，不得隐藏分组区；
- 分组计数来自当前列表或企业负责人既有聚合，不伪造全量数字。

## 3. 客户卡信息顺序

客户卡参考小程序客户 Tab，按客户本身表达：

1. 客户身份：姓名、阶段、等级、风险、负责人、电话；
2. 下次跟进提醒；
3. 房屋：小区、面积、预算；
4. 协同人：顾问、设计师、项目；
5. 客户行为：微信、到店、量房、设计、已转项目；
6. 客户经营时钟：上次跟进、停留天数、下次跟进；
7. 客户当前业务：报价或签约金额、项目/风险说明；
8. 财务角色附加的合同、项目、待收、逾期上下文（低权重一行）；
9. 唯一卡片动作：查看客户。

## 4. 角色投影

### 企业负责人

- 全公司客户统计；
- 门店选择；
- 负责人分组；
- 客户卡显示负责人、经营时钟和当前业务结果。

### 店长

- 本店客户统计；
- 本店负责人分组；
- 门店范围锁定本店；
- 客户卡结构与负责人一致，不新增第二套门店卡片。

### 财务

- 使用同一客户卡；
- 首屏先看客户当前状态、房屋、责任人和下一步；
- 合同、项目、待收、逾期只在卡片底部作为补充上下文；
- 专业财务动作进入客户详情承接，不复制财务工作台。

## 5. 按钮图标门禁

本页及从本页打开的客户/房屋组件执行“功能按钮 = 图标 + 文字”：

- 新增、刷新、清除筛选、查看客户；
- 负责人分组、客户状态筛选；
- 编辑客户、写跟进、标记流失、转交负责人、指派设计师；
- 新增房屋、维护当前房屋、弹窗取消/确认；
- 关闭按钮使用带可读名称的图标按钮。

浏览器 DOM 审计结果：当前页可见按钮缺失图标数为 `0`。

# 材料履约与材料业务助手 · 真实业务场景

## 场景 A：财务从待下单到形成暂估应付

| 项 | 内容 |
| --- | --- |
| 使用人/角色 | 财务、Boss、设计师、项目经理 |
| 触发事件 | 设计师已选材并提交请购，财务打开材料下单工作台 |
| 前置条件 | 项目已立项、合同材料行生成 MaterialPlan、选材完成、作业单提交 |
| 当前动作 | 财务选择供应商，确认本次数量；单价可以留空；系统生成采购单 |
| 系统下一步 | 有价形成应付；无价形成暂估应付；作业单进入已下单/部分下单；计划状态派生 |
| 成功结果 | 采购单、应付、作业单/计划状态一致，可追溯到来源计划 |
| 异常/恢复 | 无供应商阻断；超量阻断；一张作业单可拆多供应商；无价不阻断履约但成本不完整 |
| 涉及对象 | MaterialPlan、MaterialOrderSheet、PurchaseOrder、Payable、Partner |
| 状态变化 | Sheet Submitted → Ordered/PartiallyOrdered；Plan ReadyToOrder → Ordered/PartiallyOrdered |
| 金额/成本/权限 | 财务/Boss/店长可下单；P2 采购价；无价 estimated=true；设计师/PM 不可决定供应商价格 |
| 证据/来源 | SCN-021、BR-045、DEC-072、DEC-073 |

## 场景 B：PM 现场测量、到场确认与成本收敛

| 项 | 内容 |
| --- | --- |
| 使用人/角色 | Designer、PM、Finance |
| 触发事件 | 设计选材完成，作业单已建；供应商送货到工地/仓库 |
| 前置条件 | 合同生效、作业单行来自已选材计划、采购单已下单 |
| 当前动作 | PM 记录测量/配送/安装日期；到货时确认实到数量、到场日期、照片和异常说明 |
| 系统下一步 | 生成 GoodsReceipt；回退/累计采购到场；回填应付账期；累计实际成本；推进计划和作业单状态 |
| 成功结果 | 到场量、库存、应付账期和实际成本一致；异常可追溯 |
| 异常/恢复 | 部分到场、破损/色差、超量拦截、多明细采购单必须指定明细、无价不阻断到场 |
| 涉及对象 | MaterialOrderSheet、GoodsReceipt、PurchaseOrder、InventoryStock、Payable、ProjectCostContext |
| 状态变化 | Sheet Ordered → PartiallyArrived/Arrived；Plan Ordered → PartiallyArrived/Arrived |
| 金额/成本/权限 | 到场不新增应付；回填账期起算/到期；P2 暂估或 P3 结算价进入实际成本；PM/设计师确认，Boss/店长/财务兜底 |
| 证据/来源 | SCN-005、SCN-021、DEC-MP-01、DEC-MP-07、BR-045 |

## 场景 C：减项发生在已下单/已到货之后

| 项 | 内容 |
| --- | --- |
| 使用人/角色 | Boss/店长、设计师、PM、财务 |
| 触发事件 | 合同变更减项通过，减少某材料需求 |
| 前置条件 | 变更审批通过；材料计划、采购、到场状态可查 |
| 当前动作 | 系统按材料当前状态处理：未下单冲计划，已下单未到调整采购，已到货生成退货 |
| 系统下一步 | 先冲损耗再冲净用量；采购明细/应付差额调整；退货冲减成本/应付/库存；余额转供应商往来 |
| 成功结果 | 合同、材料计划、采购、应付、成本、库存可追溯一致 |
| 异常/恢复 | 本单应付不足时冲其他应付；仍有余额转 PartnerCredit；已付款转待协商 |
| 涉及对象 | ContractChange、MaterialPlan、PurchaseOrder、MaterialReturn、Payable、PartnerCredit、Inventory |
| 状态变化 | 计划/采购状态重算；退货状态 Confirmed/Pending；变更生效 |
| 金额/成本/权限 | 不得直接改应付无留痕；退货按 P2/P3 口径冲减；金额权限按财务域 |
| 证据/来源 | DEC-MP-02、DEC-073、DEC-074、ContractChangeFulfillmentContext |

## 反向场景

- 未选材直接建作业单/下单：拒绝，提示完成主材选材；
- 下单量超过净用量 + 损耗：拒绝；
- 跨企业/跨项目/非项目参与人访问：统一拒绝或 404；
- 重复提交/重复下单/重复结算：幂等或唯一约束拦截；
- 无价下单：允许履约，但不得展示 0 成本利润；
- 结算重复：同一采购明细只能被一种结算方式计入一次；
- 已下单后直接取消作业单：必须走采购调整或退货，不得直接删除事实；
- 业务助手越权读取其他企业/项目：工具层拒绝并返回无权限。

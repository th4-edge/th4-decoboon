# 材料履约与材料业务助手 · Run Envelope（自主运行授权包）

> 用户离开前的运行授权。监督任务只能在本文件授权范围内自主推进；命中人工门禁时停止该分支并写入决策包。

## 1. 目标

- Domain：`material`
- North Star：材料计划、选材、作业单、采购、到场与结算形成可追溯闭环，并提供可解释、可校核的业务助手。
- 目标角色：Boss/StoreManager、Finance、Designer、PM、Supplier/Dealer、Customer（只读）、System。
- 本期范围：
  - 材料主链的结构化蓝图、字段字典、状态机、业务体检；
  - App/Web 的模块级/页面级/对象级说明；
  - 只读材料业务助手：解释、数据校核、异常诊断、下一步引导；
  - 真实页面/真机证据、独立验证和设计—蓝图—实现—验收对账。
- 本期不做：
  - 新业务规则或金额/成本口径；
  - 自动审批、自动付款、自动删除、自动改权限；
  - 测量字段全品类必填、作业单独立取消 Provider（除非另有业务裁决）；
  - 正式小程序提审和发布；
  - 全品类一次性铺开。

## 3. 自主决策权限

监督/执行任务可以自行决定：

- 技术实现方式、组件拆分、API 拆分；
- 页面布局、信息层级、交互细节（遵守现有设计系统）；
- 测试补充、测试数据准备、构建/类型检查/必要的 dev/test 冒烟；
- 已裁决规则内的字段映射、序列化白名单、错误文案；
- 本地/开发/测试环境的重启和验证；
- 在 `DEV_VERIFIED` + `RECONCILED` 后，对**无 DDL、无权限/金额/成本语义变化**的可回滚后端/Web 变更执行灰度/生产发布和冒烟；
- 小程序开发版上传、体验版发布与验证（正式版不碰）。

## 4. 人工门禁（必须停）

遇到以下情况，停止相关分支并写入决策包：

- 新业务对象、状态、角色、数据范围或审批链；
- 金额、成本、利润、支付、结算语义变化；
- DDL、迁移、生产数据删除或不可逆数据修复；
- 正式小程序提审与发布；
- 密钥、生产配置、对外消息、真实客户通知；
- 需要业务负责人拍板的范围取舍；
- 连续失败或证据不足导致无法判断“完成”。

## 5. 质量门禁

- 业务事实有 `OBJ/SCN/BR/DEC/MET/EV` 引用；
- 定向测试 + 编译/构建通过；
- 真实浏览器/真机截图与交互证据；
- 无 `UNMAPPED`/`STALE`；
- 独立验证 PASS；
- 成本完整性/权限/跨租户/幂等/边界用例覆盖；
- 回滚路径明确。

## 6. 预算与止损

- 每个缺陷最多修复轮次：3；
- 每批 UI 审查最多轮次：2；
- 同一指标连续无改善：2 次后停止该类优化并重新测量；
- 单次监督循环最多推进：1 个批次；
- 最大自主批次：B1–B6；
- 无进展/证据不足：标记 `BLOCKED`，写决策包，停止该分支。

## 7. Return Packet

监督任务完成或停止时必须提供：

- 已完成批次与证据路径；
- 未完成项与原因；
- 自主假设/临时决策；
- 需要用户决策的事项；
- 下一轮提示词；
- 是否可进入 `ACCEPTED` / `RELEASED`；
- 回滚/恢复方式。

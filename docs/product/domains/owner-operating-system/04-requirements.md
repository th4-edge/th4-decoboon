## 非功能要求

- 性能：原型单文件本地打开，不访问外部 API；生产方案后续按性能门禁执行。
- 可访问性：键盘可操作，焦点可见，状态同时使用文字/颜色/图标，正文不小于 13px。
- 异常恢复：加载失败、权限失败、数据缺失、成本不完整均有独立表达。
- 审计/幂等：原型中的审批、指派、确认均只演示状态和回读，不伪造真实写操作。
- 跨端一致性：同一示例对象在 Web、App、小程序使用同一对象 ID、状态、金额和责任人。
- 视觉：采用装得清 Web Token 中的青绿色品牌、12px 圆角、13px 最小正文和状态语义色。

## 明确不做

- 不接真实 API、不登录、不写入任何生产数据。
- 不定义新角色、新状态、新金额公式、新审批流。
- 不实现真实审批、支付、删除、权限变更。
- 不将高保真原型视为生产页面或 UI 验收通过。
- 不发布微信小程序正式版。

## 概念原型内容

1. Web：经营总览、业务推进、企业经营、运营工具、组织管理五页。
2. App：负责人总览、业务推进、企业经营、运营工具、组织管理五页，移动壳层内切换。
3. 微信小程序：轻量经营简报、业务推进、企业经营、运营工具、组织入口，独立产品边界标为 `GAP-BOS-001`。
4. 业务推进：八个阶段、阶段进入/退出语义、负责人观测点、责任人、阻断与下一步。
5. 对象处置：风险抽屉包含对象事实、负责人判断、处置后回读和事实边界。
6. 一人装企：岗位视角切换，但明确身份、数据范围和审计主体不变。
7. 企业经营：成本不完整显示为空，经营利润草案显示“口径待确认”。

# 装得清负责人工作台 · UI Baseline V1

> 状态：概念基线可评审  
> 原型：`docs/product/prototypes/owner-operating-system/index-v3.html`  
> 范围：经营总览、业务推进、项目对象三个样板页，以及对应移动端壳层  
> 性质：UI/交互基线，不是生产页面，不是独立验收

## 1. 设计方向

```text
工程蓝图
+ 经营账本
+ 企业工作台
```

目标不是做成作品集里的概念后台，而是形成装得清自己的商业级产品语言：

- 有工程企业的秩序、结构和可信感；
- 有经营账本的数字密度和阅读性；
- 有企业 SaaS 的克制、清晰和高效率；
- 不使用玻璃拟态、霓虹渐变、无意义大图和过多装饰。

## 2. 视觉 Token

| 类别 | 冻结值 |
| --- | --- |
| Canvas | `#f1f0e9` |
| Paper | `#f8f7f2` |
| Card | `#ffffff` |
| Ink | `#17201b` |
| Secondary text | `#5f665f` |
| Tertiary text | `#666d66` |
| Brand deep | `#102d21` / `#173d2d` |
| Brand primary | `#2f7d5a` |
| Accent | `#d7f56a`，只用于关键主行动或经营结论 |
| Success | `#23845e` |
| Warning | `#906018` |
| Danger | `#be3e45` |
| Info | `#366fae` |

规则：

- 品牌色只保留一个色系，Web 使用较深层级，移动端使用较亮层级。
- 状态色只表达业务语义，不作为装饰。
- 页面不得直接新增裸色值，必须进入 Semantics Token。
- 正文最小 14px，辅助信息最小 12px；不允许 9–11px 业务文本。

## 3. 字体与数字

```text
页面标题：27px / 700
对象标题：25px / 700
模块标题：14–18px / 650–700
正文：14px / 400
辅助：12px / 400
KPI：21–24px / 700
```

规则：

- 金额、比例、日期、编号使用等宽数字或 `tabular-nums`。
- 金额默认右对齐。
- 标题靠字号和字重建立层级，不依赖颜色。
- 中文页面不堆叠英文大写小标题，仅保留轻量索引和系统标签。

## 4. 间距、栅格与形状

- 8px 基础间距网格。
- 桌面内容区使用 12 列思维，常见布局为 `1.45fr + .55fr` 或 `1fr + 1fr`。
- 页面内边距 21–24px。
- 卡片圆角 11px；大型对象区 15px；抽屉 0 侧边圆角。
- 默认只有 1px 边框与极轻阴影，不为每个区块加阴影。
- 卡片只包裹独立业务对象，不用卡片切割所有段落。

## 5. 页面模板

### 5.1 经营总览

```text
页面标题
→ 一句经营判断
→ 3 个经营决策
→ 4 个核心指标
→ 经营决策队列
→ 业务停留点
→ 目标 / 现金流等辅助信息
```

要求：

- 只保留一个深色 Hero；
- 最多一个主行动；
- 首屏回答“今天先做什么”；
- 不解释产品信息架构。

### 5.2 业务推进

```text
阶段轨道
→ 当前阶段观测表
→ 当前停留对象
→ 当前能力入口
→ 亲自处理
```

阶段只作为定位器，不要求负责人先理解所有岗位。

### 5.3 项目对象

```text
对象身份条
→ 当前事实与风险
→ 唯一主行动
→ 今日任务
→ 对象关系
→ 负责人观测
→ 最近动作
```

对象身份条必须包含：

- 项目名称与编号；
- 当前状态；
- 项目经理；
- 客户；
- 合同金额；
- 回款；
- 成本；
- 风险。

## 6. 组件基线

| 组件 | 规则 |
| --- | --- |
| PageHeader | 页面索引、标题、范围、描述、右侧动作 |
| ObjectHero | 身份、状态、负责人、金额、风险、主行动 |
| MetricSignal | 标题、值、单位、次要事实、缺失态 |
| Risk/Decision Card | 原因、对象、责任人、时效、下一步 |
| StageRail | 阶段、状态点、停留计数、选中态 |
| DataTable | 12px+ 字体、数字右对齐、行内动作收敛 |
| StatusTag | 文字 + 颜色 + 点，不单独靠颜色 |
| DetailDrawer | 对象上下文不丢失，Esc 可关闭，焦点回到触发点 |
| ActionBar | 一个主行动，其他动作降级 |
| AsyncState | loading / empty / error / unauthorized / stale / partial |

## 7. “亲自处理”基线

- 岗位切换只在对象或阶段执行上下文中出现。
- 选择岗位不会改变 BOSS 身份、Company 范围或审计主体。
- 选择岗位后显示当前对象可用动作。
- 动作完成必须回读状态、金额、待办和时间线。
- 一级导航不出现业务员、设计师、项目经理、财务等岗位菜单。

## 8. 两轮渲染评审

### 第一轮

发现问题：

- 多个辅助文字低于 12px；
- Tertiary text 对浅色背景对比不足；
- 需要确认页面级横向溢出。

修正：

- 所有业务文本抬升至 12px 以上；
- Tertiary text 加深；
- 移动端风险卡和阶段卡增加 44px 最小触达高度。

### 第二轮

通过：

- 1440×1000：三个 Web 样板页无横向溢出。
- 1024×900：三页无横向溢出，侧栏折叠。
- 390×844：移动端完整容纳，内容在手机内部滚动。
- 控制台：0 error / 0 warning。
- 可见文字：无小于 12px 的文本。
- 能力抽屉、亲自处理、角色动作、UI 基线抽屉均可交互。

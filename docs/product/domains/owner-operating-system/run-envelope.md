# 装企负责人经营管理体系 · Run Envelope（自主运行授权包）

## 1. 目标

- Domain：`owner-operating-system`
- North Star：以负责人视角统一多端能力，沿客户经营主链看清业务推进、经营结果、运营标准和组织效能，并能从观测点直接进入处置
- 目标角色：企业负责人 BOSS；一人装企 BOSS；多门店 BOSS
- 本期范围：四维能力盘点、业务推进图、负责人观测点、App/微信小程序/Web 职责映射、高保真概念原型
- 本期不做：生产代码、Provider、DDL、权限变更、金额口径变更、正式小程序发布

## 3. 自主决策权限

监督/执行任务可以自行决定：

- 高保真原型的页面布局、交互细节和视觉表达；
- 在已批准业务卡片内组织信息层级；
- 本地静态 HTML 的技术选择；
- 本地浏览器渲染、截图和可访问性检查；
- 对未确认口径增加“待确认”表达，而不自行补全。

## 4. 人工门禁

遇到以下情况必须停止该分支并写入决策包：

- 新增业务对象、状态、角色或数据范围；
- 金额、成本、利润、权限、支付语义变化；
- DDL、迁移、生产数据删除；
- 正式小程序提审与发布；
- 密钥、生产配置、对外消息；
- 需要业务负责人拍板的产品一级名称或三端产品边界；
- 用户要求把概念原型直接转成生产实现。

## 5. 质量门禁

- 业务裁决已引用；
- 原型不展示伪利润和默认事实；
- 真实浏览器至少渲染两轮并保存截图；
- 桌面、平板、移动三档检查；
- 无未解释的 UNMAPPED/STALE；
- 概念原型不得宣称生产验收 PASS；
- 后续真实实现必须使用同一 Provider 并通过独立验收。

## 6. 预算与止损

- 每个缺陷最多修复轮次：2
- UI 审查最多轮次：2
- 同指标连续无改善停止次数：2
- 最大自主批次：1（BOS-P0）
- 无进展时处理：记录阻断和下一决策点，停止扩展

## 7. Return Packet

回来后必须提供：

- 已完成批次与证据；
- 未完成项与原因；
- 自主假设；
- 需要用户决策的事项；
- 下一批提示词；
- 是否可进入真实数据切片。

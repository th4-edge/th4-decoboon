# B3A · 工资单现有执行链跨端对齐研发任务

## 状态

- 批次：`B3A`
- 变更级别：L3（最终确认、删除、金额展示）
- 前置：H1、B2（均已获用户承接）
- 编码授权：用户 2026-10-23 指令“下一步”
- 当前状态：`USER_ACCEPTED_NON_INDEPENDENT / BLACK_BOX_PASS`
- DDL/迁移：无

## 目标

在不引入复核/作废新流程的前提下，让 Web 工资单执行链达到 App 已有水平。

## 范围

1. Web 接入 `payroll/sheet/info`；
2. 工资项详情补齐基本工资、提成、奖金、补贴、考勤扣款、社保、个税、其他扣款、应发、扣款、实发、工资项状态与归属；
3. BOSS 删除 Draft 工资单，二次确认；
4. 确认前二次确认并说明生成应付、计成本、工资条发放后可见；
5. 确认按钮严格使用 `confirm:payroll`；
6. 历史工资单跳考勤使用工资单月份；
7. 确认后重新读取工资单和工资项。

## 不做

不实现 `Draft -> Pending` 复核；不实现作废、退回重算；不修改员工发放；不修改提成解耦；不做 DDL；不扩大店长确认权。

## 验证

- BOSS 生成、查看、确认、删除草稿；
- Finance 生成和查看，不显示最终确认；
- StoreManager 本店只读，不显示生成/确认/删除；
- 金额展示与接口一致；
- 确认后应付只生成一次；
- 删除只允许无事实 Draft。

# B3B1 · 薪酬复核与员工发放权限闭环研发任务

## 状态

- 批次：`B3B1`
- 变更级别：L3（权限、薪酬动作）
- 业务裁决：`DEC-093`、`T12-BIZ-20261023-002`
- 编码授权：用户 2026-10-23 明确启动
- DDL/迁移：无
- 当前状态：`RECONCILED / BLACK_BOX_PASS_PENDING_USER_ACCEPTANCE`
- 不包含：工资单作废/反向应付/成本；批量/部分发放

## 目标

在不引入作废和反向财务事实的前提下，完成薪酬可选复核、Pending 展示/退回，以及店长员工发放入口的权限闭环。

## 范围

1. Finance/BOSS 可将 Draft 工资单提交为 Pending；
2. BOSS 可将 Pending 退回 Draft，原因必填并留痕；
3. BOSS 可直接确认 Draft 或 Pending；
4. Web/App 正确显示 Pending、退回原因和可执行动作；
5. 店长不显示员工工资/提成发放入口；
6. 店长直接调用员工发放接口返回 403；
7. Finance/店长最终确认、草稿删除继续 403；
8. BOSS 确认/删除能力回归，不得重新下放财务/店长；
9. App/Web 能力键与后端角色矩阵一致。

## 不做

- 不实现工资单作废；
- 不反向应付、成本、工资条或台账；
- 不增加 `Void` 版本模型或迁移；
- 不实现批量/部分发放；
- 不修改提成释放、工资公式和历史工资；
- 不发布生产。

## 验证

- 正向：Finance 提交复核；BOSS 从 Draft/Pending 确认；BOSS 退回 Pending；BOSS/Finance 发放。
- 反向：Finance/店长确认 403；Finance/店长删除 403；店长发放按钮不可见且接口 403；跨店 404/403。
- 幂等：重复提交复核、重复退回、重复确认不产生重复应付/成本/工资条。
- 跨端：App/Web 状态、按钮、错误文案与 API 结果一致。
- 回归：B3A 工资单详情、确认、草稿删除、金额展示和门店范围继续通过。

# B7 · 店长薪酬敏感字段边界决策包

## 当前事实

- 业务规则：`DEC-017` / `EV-064` 冻结“店长可看应发/扣款/实发构成，不可看银行卡、身份证、个税明细”。
- 数据事实：`PayrollItem` 只有 `taxAmount`（个税扣减汇总）和 `socialInsuranceAmount`（社保个人扣减汇总），没有税率、应纳税所得额、专项扣除等详细个税字段。
- 接口事实：`payroll/store-payroll/info` 和 `payroll/item/page` 当前把两项汇总返回给店长；App `sheet-detail` 和 Web 员工工资详情展示两项；`payroll/store-payroll/page` 只返回应发、扣款合计和实发。
- 业务缺口：`GAP-074`，咨询单 `REQ-BIZ-20261030-001`。

## 待裁决选项

| 选项 | 店长可见社保汇总 | 店长可见个税汇总 | 店长可见扣款合计/实发 | 影响 |
| --- | --- | --- | --- | --- |
| A 可见扣款汇总 | 是 | 是 | 是 | 维持现行扣款构成展示；个税只到汇总，不展示计算明细 |
| B 隐藏两项 | 否 | 否 | 是 | 后端按店长裁剪，App/Web 显示“部分扣款按权限不展示” |
| C 仅隐藏个税 | 是 | 否 | 是 | 需要单独裁剪 `taxAmount`，保留社保汇总 |

## 研发门禁

- 未裁决前不修改 Provider 字段、不修改 `@Properties`、不修改 `PayrollAccessContext`、不改 App/Web 展示。
- 裁决后必须先做字段可见性矩阵，再做 Provider 定向测试和真实 Twin 门店验收。
- 不得只在前端隐藏；服务端响应必须独立裁剪。
- 不得用 0 表示“不可见”，应返回字段缺失或 `null`，前端显示“按权限不展示/暂不可确认”，具体响应契约按裁决结果冻结。

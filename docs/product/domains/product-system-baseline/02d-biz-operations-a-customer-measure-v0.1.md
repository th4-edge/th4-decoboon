## 一、业务链

```text
内容素材/内容任务/发布
→ 内容线索触点
→ 客户登记
→ 客户跟进/画像/标签
→ 房屋建档
→ 预约量房
→ 量房记录
→ 原始区域/实测值
→ 设计方案
```

关键区别：

- `LeadTouch` 是租户内容获客触点，不是平台销售线索；
- `Customer` 是装企客户经营主体；
- `Property` 是客户名下具体装修标的；
- `Measure` 是房屋的一次量房事实；
- `MeasureRegion` 是房屋的原始区域实测档案；
- 设计方案、报价、合同和项目必须绑定明确房屋，不能用客户地址或列表第一条房屋代替。

- `LeadTouch` 不创建客户，只记录客户与内容之间的归因关系；
- 归因方式、置信度、主归因和证据需要保留。

### App/Web

- 按用户“App/Web 强制能力一致且完整”裁决，内容获客存在跨端缺口。

## 四、BIZ-03 房屋与量房

### 当前对象

| 对象 | 当前定位 |
| --- | --- |
| Property | 客户名下具体装修房屋，设计/报价/合同/项目的唯一业务根 |
| Measure | 一次量房记录 |
| MeasureRegion | 原始区域和实测档案 |

### Property

关键字段：

- `propertyNo`、community、building、roomNo、address；
- area、layout、status；
- customer；
- owner、salesman、designer；
- latestMeasureAt；
- store/team。

规则：

- 一个客户可有多套房屋；
- 设计、报价、合同、项目必须明确 `propertyId`；
- 不允许取客户第一条房屋兜底；
- 项目、报价、合同和财务事实都保留房屋归属快照。

### Measure

关键字段：

- customer、property；
- designer（量房设计师）；
- executor（实际执行人）；
- scheduledAt、completedAt、measureTime；
- status；
- sitePhotos、structureImages、attachments；
- originalStructure、dimensions；
- customerRequirements、designerConclusion。

规则：

- 量房是房屋事实，不是客户地址的附属信息；
- 设计师和实际执行人可以不同，实际执行人必须单独记录；
- 量房计划、执行、完成和结论应可区分；
- 量房记录必须能被设计/方案追溯。

### MeasureRegion

关键字段：

- measure、property；
- roomKey、roomType、name；
- length、width、height；
- area、perimeter；
- areaSource；
- measuredBy、measuredAt；
- sort、remark。

规则：

- 区域面积/周长是设计师实测量房后录入的实测事实；
- `AreaSource=Measured` 才可进入设计/报价工程量；
- 模板参考值和历史估算值不能冒充本房屋实测事实；
- 长/宽是量房快照，不得由系统推算面积/周长；
- 历史估算区域必须标记并等待复核。

### App/Web

- App 有量房经营工作台、预约量房、量房记录、房屋编辑和原始区域录入；
- Web 有量房任务工作台、客户跟进和量房相关预约；
- Web 当前有量房任务和房屋接口，完整原始区域录入闭环需继续核对；
- App/Web 必须共享同一量房与原始区域事实，不得各自维护区域数据。

## 六、当前结构问题

### BIZ-X01：内容获客跨端不完整

App 有完整内容模块，Web 暂无内容工作台。按跨端裁决，应补 Web 或明确形成例外。

### BIZ-X02：平台线索与内容线索边界容易被混淆

`LeadTouch` 是租户内容归因，不是平台官网/抖音销售线索。页面和指标必须明确来源层级。

### BIZ-X03：客户生命周期状态与销售阶段展示可能分叉

`CustStatus` 是唯一生命周期状态；前端“客户阶段”必须由同一状态或正式派生规则生成，不能本地维护另一套客户阶段。

### BIZ-X04：客户、房屋、量房仍未形成统一事实链

`customer/customer/info` 返回客户、标签、画像、分级和部分量房事实；`property/property/info`、`property/measure/info` 分别独立。用户从客户视图难以完整追踪“客户 → 多房屋 → 量房 → 区域实测”。

### BIZ-X05：房屋详情只返回最近量房时间

`property/property/info` 只有 `latestMeasureAt`，没有量房状态、原始区域数量和实测完整度摘要。房屋视图需要事实追踪投影。

### BIZ-X06：量房设计师与实际执行人

量房记录同时有 designer 和 executor，页面和指标需明确区分“指派设计师”和“实际执行人”，不能混用。

### BIZ-X07：原始区域实测是后续设计/报价的事实源

如果客户/房屋/量房页面展示面积，必须明确是房屋面积、量房记录尺寸、区域实测面积还是模板参考值，不能只显示一个“面积”。

# 装得清产品体系基线 · 垂直切片计划

## 北向目标

以角色、业务域、功能、对象概念和跨端展示的同源基线，支撑产品持续扩展、变更影响识别与规则一致性。

## 推进原则

1. 先业务事实，后产品矩阵，再页面和代码。
2. 一次只做一个垂直切片，不把角色、业务、功能、概念和跨端修复混成一个大批次。
3. 每个批次都必须有输入、业务裁决、产物、对账和退出条件。
4. 未完成 `BIZ_ALIGNED` 前，不进入编码、权限或状态机变更。
5. 页面证据只能是“当前实现事实”，不自动升级为“正式业务规则”。

- 本域 B0 仅新增产品文档，回滚方式为删除本域包和 T05 文件。

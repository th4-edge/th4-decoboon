# 统一对象视图一期实施计划 v0.1

> 日期：2026-10-22
> 状态：用户已授权按照统一方案处理报价、合同等相关业务概念。
> 实施原则：一次一个垂直切片，先报价、再合同、再项目，不进行全域同时重构。

## 一、一期目标

建立可复用的业务对象统一视图基础，并先落地：

```text
报价统一视图
→ 合同事实追踪复用
→ 项目事实追踪复用
```

后续对象沿用同一契约。

## 二、范围

### 一期必须完成

1. 报价统一视图契约和场景适配；
2. 报价按区域、按类型两种服务端分组；
3. 类型视图服务端合并跨区域相同项并保留来源；
4. 报价在 App、Web、业主端、项目、合同和 PDF 的场景适配；
5. 合同事实追踪：上游量房、设计、报价，当前合同，下游项目/变更/材料/验收/财务摘要；
6. 项目事实追踪：复用统一事实节点和统一对象视图跳转；
7. 契约测试、定向回归、构建和真实页面证据；
8. 独立验收门禁。

### 一期不做

- 不重构所有业务对象；
- 不新增报价/合同/项目 DTO 或前端第二套模型；
- 不改变既有报价、合同、金额、成本、权限业务口径；
- 不进行大规模数据库迁移，除非专项 T06/T12 明确要求并单独审批；
- 不把全部对象详情嵌入项目/合同页面；
- 不正式发布小程序正式版。

## 四、共享领域契约

### 4.1 对象身份

```text
objectType + objectId + version
```

### 4.2 场景

```text
EDIT | READ | OWNER | PROJECT | CONTRACT | SUMMARY | PRINT
```

### 4.3 分组

```text
REGION | TYPE | PHASE | CATEGORY
```

### 4.4 事实节点

```text
nodeId
objectType
objectId
version
status
businessTime
recordedAt
actor
summary
relations
visibility
navigation
```

### 4.5 权限

- 场景只改变字段、动作和密度；
- 服务端负责裁剪；
- 业主字段白名单独立；
- 成本、内部公式、供应商执行价不得进入业主投影。

## 五、报价一期规则

- 同一 `quoteId + version` 只能有一套核心投影；
- REGION 保留原始区域行；
- TYPE 按 ItemType → Category 分组；
- TYPE 合并跨区域相同项必须服务端完成；
- 合并保留 `sourceLineIds`、`sourceRegionIds`、`sourceRegionNames`、`sourceCount`；
- 项目默认 REGION；
- 合同报价详情跳转统一报价视图；
- 业主支持 REGION/TYPE；
- PDF 允许选择 REGION/TYPE。

## 六、合同一期规则

- 合同绑定明确 quoteId/version；
- 报价绑定明确 designId/version（若有）；
- 设计追溯到量房/区域快照；
- 合同展示上游摘要和下游影响摘要；
- 直接签约补录、项目承接必须显示来源异常状态；
- 合同变更不回溯改写签约报价/设计快照。

## 七、项目一期规则

- 项目是事实索引根；
- 事实节点显示来源、版本、状态、时间、责任人和统一对象跳转；
- 不复制完整明细；
- 默认阶段视图，支持时间线/关系链/异常视图；
- 历史、当前、失效状态明确。

## 八、验证与门禁

1. 后端定向契约测试；
2. 相关全量回归（金额/权限/跨端影响）；
3. App type-check/build；
4. Web type-check/build；
5. 真实登录、真实数据、真实页面截图；
6. 跨租户/跨店/越权负向；
7. 历史版本与 PDF 回读；
8. 独立验收 PASS；
9. 无 DDL 变更时记录无迁移；如有 DDL，走备份/回滚/用户确认。

## 九、回滚

- 先通过新增统一投影和服务适配实现，不删除旧结构；
- 页面切换失败可回退到旧读取路径；
- 契约测试失败阻断发布；
- 如涉及 DDL，必须单独审批并保留回滚脚本；
- 不允许以“旧页面还能用”掩盖口径分裂。

## 问题摘要

同一项目 `242297299361857536`、同一财务角色、同一业务状态：

- 项目状态 `Preparing`；
- 成本 `costComplete=false`；
- 缺失成本 `1` 项；
- 利润和毛利率均为 `null`；
- 结算状态 `Draft`。

Web 正确显示“成本未完整”，并禁用“确认结算”；小程序页面数据虽然正确，但存在：

1. 小程序“确认结算”按钮未禁用，形成错误可操作预期；
2. 小程序金额文字取整到元，Web 精确到分。

## 业务影响

- 用户可能在成本不完整、项目未达到结算条件时尝试确认结算。
- Web 与 App 对同一高风险资金动作的门禁表达不一致。
- 财务用户在不同端看到的金额精度不同，影响跨端对账信任。
- 虽然页面数据、API、DB 的业务金额一致，且后端仍有拒绝门禁，但不能以“后端会拦截”替代正确的端侧引导。

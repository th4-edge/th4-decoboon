## 1. 业务目标

建立预计、动态、最终三态成本与毛利的只读投影契约，明确旧字段兼容规则，并用契约测试固定 P1/P2/P3、完整性、空值和阶段映射。D1 不替换生产公式，不接页面，不做 DDL。

## 2. 冻结范围

- 对象：`ProjectCostProjection`、`ProjectCostContext` 读取契约、`FinanceReportContext` 消费边界。
- 状态：`Estimated`、`Dynamic`、`Final`；结算 Draft/Confirmed/Closed 仅作为投影可读条件。
- 角色与数据范围：BOSS/总部财务 Company；店长/门店财务 Store；PM/设计师项目参与范围；普通员工/业主不可见内部成本与毛利。
- 金额/成本：
  - P1 只进 `estimatedCost`；
  - P2 只可作动态暂估；
  - P3 是最终材料成本唯一来源；
  - 分类成本按材料、工人/班组、员工工资、员工提成、项目费用、其他项目应计；
  - 无采购/未到货/未定价/未结算或缺失分类时，对应完整标志 false、利润/毛利率 null。
- 后端：新增/固化三态投影字段、阶段枚举、兼容别名和只读测试。
- App：D1 不改页面；验证现有字段暂不因契约新增而破坏读取。
- Web：同 App。
- 明确不做：不改生产利润公式、不删旧字段、不改结算门禁、不做 DDL/迁移、不接 Expense 新对象、不上线企业/门店经营利润。

- 审计/幂等：纯读取，无写操作；同一项目同一阶段同一数据版本结果稳定。

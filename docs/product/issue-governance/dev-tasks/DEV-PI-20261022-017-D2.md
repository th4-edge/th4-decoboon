## 1. 范围

- `ProjectCostContext` 产出 `ProjectCostProjection`（唯一生产公式），不再把 P1 作为实际/最终成本。
- 分类成本：
  - `materialCost`：已结算到场 P3；已到货未结算且已定价的 P2 仅用于 Dynamic。
  - `workerLaborCost`：已确认工人/班组应付。
  - `employeeSalaryCost`：项目归属且已确认员工工资应付。
  - `employeeCommissionCost`：项目归属且已计提/确认员工提成应付。
  - `projectExpenseCost`：已批准项目 Expense 或有效手工项目零星成本，二选一。
  - `otherProjectAccruedCost`：来源明确且已确认的其他项目应计成本。
- `FinanceReportContext` / `FinanceProjectLedgerContext` 只聚合投影，不得再用 `max(actualCost,payableCost)`。
- 企业费用不进入项目成本；`Payable(Material/Supplier/Other)` 和 `Payment` 不直接充当成本。
- 承接成本 = 接管前确认快照 + 接管后发生额。

## 2. 不做什么

- 不新增 DDL；如最终快照需持久化版本字段，另提单。
- 不改结算确认/关闭门禁（归 COST-D3）。
- 不改 D5 公司/门店经营利润。
- 不迁移历史数据，不批量回填 P1/P2/P3。

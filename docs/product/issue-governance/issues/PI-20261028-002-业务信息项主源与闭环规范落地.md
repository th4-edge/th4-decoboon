## 一、问题摘要

装得清当前信息问题不是孤立字段缺失，而是缺少统一的信息架构：

- 同一信息在多个对象中形成可编辑主源；
- 上游录入的信息没有明确下游消费者；
- 只进入页面、导出或 AI Prompt 被误认为业务闭环；
- 快照、投影、派生和证据没有显式区分；
- 信息变更没有影响分析；
- 新增字段没有注册和验收门禁。

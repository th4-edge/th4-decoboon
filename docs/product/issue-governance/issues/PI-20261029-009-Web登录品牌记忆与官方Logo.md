## 根因

1. Web 只持久化登录 token，没有保存上次登录企业与手机号，退出后登录页无法提前恢复装企品牌。
2. Web 登录页、角色壳层和财务/设计/项目经理壳层使用“装”字方块代替装得清官方 Logo。
3. Web favicon 也是文字生成图形，不是统一 logo-export 资产。
4. 旧 `/favicon.svg` 被开发服务器回退为 HTML，`/favicon.ico` 为 404，浏览器标签页可能继续显示旧图标或空白。

## 处理

- 新增本地 `zdq.web.last-login.v1`，只保存手机号、员工姓名、企业公开品牌信息和保存时间。
- 不保存密码、token、权限、金额或内部业务数据。
- 登录页打开时预填手机号，并应用上次企业品牌色。
- 登录页左侧主品牌直接切换为上次企业 Logo 与名称；无企业 Logo 时使用企业名称首字占位。
- 右侧标题改为“登录{装企名称}工作台”，不再显示独立的“上次登录企业”卡片。
- Web 登录页和所有角色壳层改用 `logo-export` 官方 Logo；favicon 改用官方彩色 Mark。
- 补齐官方 `favicon.ico`（16/32/48/64）、SVG favicon、32px PNG 和 180px Apple Touch Icon，并加版本参数刷新浏览器缓存。
- favicon 在有装企信息时同步为企业 Logo；无企业 Logo 时使用企业首字和企业品牌色生成。
- 登录后工作台侧栏显示企业 Logo/名称，浏览器标题使用企业名称，首页正文不出现装得清产品文案。

## 验证

- 企业 Logo 缓存地址实际加载，`naturalWidth=256`。
- 企业品牌色 `#2563EB` 在退出后的登录页根 Token 中恢复。
- 手机号 `18660219918` 自动预填。
- 本地记忆对象无 `password`、无 `token`。
- 登录页平台 Logo 为 `/brand/logo-mark-white.png`，实际加载 `naturalWidth=256`。
- 工作台侧栏 Logo 为同一官方白色 Mark。
- 无缓存首访仍使用官方装得清 Logo 和默认品牌色。
- 登录页包含克制的户型线稿与家装业务路径元素。
- 官方 Logo SHA-256 与 `rules.md` §12 一致。

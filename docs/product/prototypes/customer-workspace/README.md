# Web 客户概念工作台 · 交互原型

打开：`index.html`

## 定位

这是一个用于验证客户页面业务规则的高保真 Web 交互原型。设计规则通过后，已同步落地到 Web `/workbench/customers`；生产页支持真实 Provider，并提供 `?preview=1` 示例预览。本原型仅作设计参考，不是生产页面。

## 当前冻结方向

- 客户页面以客户卡片为主工作单元；
- 采用“角色统计 → 查询/筛选 → 负责人分组 → 客户卡片 → 客户详情”的阅读顺序；
- 不使用左中右三栏对象工作面；
- 企业负责人：全企业客户经营统计、门店筛选、负责人分组；
- 店长：本店同口径统计、本店负责人分组；
- 财务：同一客户卡片体系，卡片重点转为合同、项目、应收、财务下一步，并保留量房、设计、报价信息；
- 客户卡点击后打开详情抽屉，查看多房屋、业务链、跟进和当前主行动。

## 评审交互

顶部评审控制条可切换：

- 企业负责人 / 店长 / 财务；
- 正常 / 加载 / 空 / 失败 / 无权限 / 长内容 / 极端值。

评审控制条不是产品界面的一部分；截图评审可使用 `?review=0&role=finance` 等参数隐藏。

## 视觉边界

- 颜色、字号、圆角和阴影镜像 Web `src/styles/tokens.scss`；
- 不新增第二套设计语言；
- 不使用 AI 味英文 eyebrow、无意义装饰、2.5D/3D；
- 页面核心信息为真实业务结构，不把示例数据作为生产事实。

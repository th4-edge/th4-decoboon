## 8. 闭环门禁

- [ ] 已在业务信息项注册表登记
- [ ] 有唯一主概念和唯一主源
- [ ] 有明确维护角色与生命周期
- [ ] 至少一个真实业务场景消费
- [ ] 消费后产生可核验动作或结果
- [ ] 快照/投影/派生/证据语义明确
- [ ] 权限与数据范围明确
- [ ] 缺失和失败不使用默认值伪装
- [ ] App/Web/业主端同源（如适用）
- [ ] 有正向、反向、缺失、权限和历史快照测试

## 使用顺序

```text
财务启动会（04）
-> 账本摸底（templates/01）
-> 在建项目承接（templates/02）
-> 账务承接对照（templates/03）
-> 期初资金账户（templates/05）
-> 首月双轨对账（templates/04）
```

## 三条红线（任何角色都不得突破）

1. 期初资金余额不是收入/支出，不进入利润。
2. 剩余收付款计划是期初应收/应付的时间分解，不是新增应收应付。
3. 历史已结清数据只做档案，不进入装得清经营指标。

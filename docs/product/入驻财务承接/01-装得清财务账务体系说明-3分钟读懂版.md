# 装得清财务账务体系说明（3 分钟读懂版）

> 读者：装企 BOSS、财务、销售、实施
> 目的：统一“装得清是什么账、不是什么账、和原账本怎么相处”的口径

## 1. 一句话定位

装得清做的是**项目经营账 + 资金台账 + 经营核算**，不是法定会计总账。

我们帮你把“每个项目还欠多少、还欠谁多少、账户还有多少、这个项目赚不赚钱”看清楚；你的会计账、总账、税务申报继续留在原系统。

## 2. 装得清是什么、不是什么

| 装得清是 | 装得清不是 |
| --- | --- |
| 项目维度的收入、成本、毛利 | 会计科目、借贷分录、法定总账 |
| 应收应付、收付款、资金流水 | 税务申报、审计报告、发票系统 |
| 项目成本完整性与动态利润 | 客户原账本的逐笔还原 |
| 老板能看懂的项目经营结果 | 财务人员的记账软件替代品 |

## 3. 三本账

| 账本 | 归属 | 装得清是否承载 |
| --- | --- | --- |
| 历史档案账 | 你的原账本、Excel、纸质资料 | 只做附件/摘要，不还原明细 |
| 接管基线账 | 装得清 | 期初应收、期初应付、期初资金、成本快照 |
| 接管后经营账 | 装得清 | 新业务按标准闭环自动形成 |

## 4. 三个不丢

入驻承接只承诺三个结果：

1. **项目不丢**：在跑项目进入工地和财务工作台；
2. **往来不丢**：当前未收、未付进入期初应收应付；
3. **现金不断**：期初资金余额进入资金台账，现金流从接管日连续。

不承诺：历史逐笔还原、科目一一对应、已结清历史参与经营指标。

## 5. 你的账本怎么对应装得清

不做“科目对照表”，做“业务事实对照表”：

| 你的账务事实 | 装得清承载 | 承接方式 |
| --- | --- | --- |
| 客户工程款、预收、应收 | 项目合同 + 期初应收 + 收款 | 接管日未收余额转期初应收，后续收款走应收/收款 |
| 材料款、人工、项目款、供应商应付 | 应付账款 + 付款 | 接管日未付余额转期初应付，后续付款走应付/付款 |
| 已发生项目成本 | 成本快照 + 完整性 | 只填总额与完整性，不还原明细 |
| 房租、税费、借款、押金、备用金等 | 手工记账（其他账务） | 文本分类 + 账务用途；工程款/材料款/工资/项目款禁止手工登记 |
| 会计科目、总账、税务 | 你的原系统 | 不迁移 |

## 6. 两个关键数字

```text
项目毛利 = 项目收入 - 项目成本
        项目收入：合同当前金额 + 关联项目的其他收入
        项目成本：材料实际成本 + 人工/项目应付 + 项目零星成本 + 其他应计成本
        成本不完整时，项目毛利显示为空，并提示“成本未完整”

资金现金流 = 全部资金流水收入 - 支出
        包含自动收款、自动付款、手工记账、调整冲销
        现金流 ≠ 利润
```

装得清本期**不提供公司经营利润/净利润**；房租、推广、税费等企业费用只进入资金现金流，不进入项目毛利，也不汇总为公司利润。

## 7. 为什么和你的原账本数字不完全一样

因为两套账回答的问题不同：

| 你的原账本 | 装得清 |
| --- | --- |
| 按会计科目、期间、凭证组织 | 按项目、业务事实、资金流组织 |
| 关注对外报表、税务、审计 | 关注项目赚不赚钱、欠多少、现金够不够 |
| 已结清历史也在账上 | 只承接还要继续经营的未结事实 |

**不一致是正常的，关键是把差异分类说清楚，而不是静默调平。**

## 8. 一句话总结

> 装得清不替代你的会计账，只接管你“还要继续经营的项目事实”。期初把未收、未付、账户余额、成本完整性接进来，之后所有新业务按装得清标准闭环运行。

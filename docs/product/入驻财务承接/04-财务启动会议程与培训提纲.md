# 财务启动会议程与培训提纲

> 适用：麦鸿等存量装企入驻首次财务启动会
> 时长：90 分钟（会议 60 + 答疑 30）
> 参会：装企 BOSS、财务、项目经理代表；装得清实施/客户成功
> 目标：统一账务口径、明确承接范围、确定首月双轨计划

## 1. 会前准备（实施提前 1-2 天）

- 发送《装得清财务账务体系说明（3 分钟读懂版）》；
- 发送并回收 `templates/01-账本摸底表模板.csv`；
- 收集在建项目清单、原账期末余额、资金账户清单；
- 确认参会人、接管日候选、是否有内账/外账。

## 2. 会议议程（60 分钟）

| 时间 | 议题 | 负责人 | 产出 |
| --- | --- | --- | --- |
| 0-10 min | 装得清是什么账、不是什么账 | 实施 | 统一口径 |
| 10-20 min | 三本账与三个不丢 | 实施 | 客户理解“不搬账本” |
| 20-35 min | 六步承接流程与完成标准 | 实施 + 财务 | 明确操作路径 |
| 35-45 min | 麦鸿账本摸底结果与差异预判 | 财务 | 差异清单初稿 |
| 45-55 min | 接管日、项目范围、责任人确认 | BOSS | 范围与接管日冻结 |
| 55-60 min | 首月双轨计划与分工 | 双方 | 周节奏与责任人 |

## 3. 四个必须当场确认的事项

1. 接管日期；
2. 本次承接的在跑项目范围；
3. 项目负责人/门店/团队归属；
4. 首月双轨对账的双方责任人。

## 4. 分角色培训提纲

### 4.1 BOSS（30 分钟）

- 你以后看什么：项目毛利、应收应付、资金现金流、风险；
- 为什么没有公司净利润；
- 为什么成本不完整时不显示利润；
- 接管后你还需要做什么：确认范围、处理差异、看经营对账。

### 4.2 财务（60 分钟）

- 六步承接操作演示；
- 期初应收/应付录入与核销规则；
- 期初资金余额与剩余收付款计划；
- 双轨对账表填写与差异分类；
- 手工记账：什么能记、什么不能记、工程款/材料款/工资/项目款怎么引导；
- 首笔业务锁定与冲正规则。

### 4.3 项目经理（30 分钟）

- 项目当前状态、阶段、剩余施工怎么承接；
- 接管后工地任务和验收怎么走；
- 项目零星成本怎么发起/配合财务。

## 5. 会后行动清单

| 动作 | 负责人 | 截止 |
| --- | --- | --- |
| 回收账本摸底表 | 实施 | D+1 |
| 完成在建项目承接表 | 财务 | D+3 |
| 完成账务承接对照表 | 财务 + 实施 | D+5 |
| 完成期初资金账户表 | 财务 | D+5 |
| 录入期初应收应付与计划 | 财务 | D+7 |
| 完成成本完整性确认 | 财务 + PM | D+7 |
| 开始首月双轨运行 | 双方 | D+7 |
| 首月经营对账会 | 双方 | D+30 |

## 6. 启动会关键话术

> 我们今天不是来搬你们的账本，而是来接管你们还要继续经营的项目事实：未收、未付、账户余额、成本完整性和剩余收付款计划。你的会计账继续保留，装得清负责项目经营账，双方首月用双轨对账把差异说清楚。

## 7. 成功标准

- 客户能用自己的话说出“装得清是项目经营账，不是会计总账”；
- 接管日、项目范围、责任人当场确认；
- 财务知道六步怎么做、哪些不能做；
- 首月双轨对账的双方责任人明确。

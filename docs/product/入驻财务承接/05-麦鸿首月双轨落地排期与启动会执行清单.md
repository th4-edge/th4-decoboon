# 麦鸿首月双轨落地排期与启动会执行清单

> 版本：v1.0（2026-10-06）
> 适用：麦鸿（存量装企）首月双轨对账落地
> 关联方案：`docs/product/2026-10-06-首月双轨对账设计方案与运营手册.md`
> 关联资料包：`docs/product/入驻财务承接/00-README.md`

## 1. 目标

用一个月完成麦鸿从原账本到装得清的账务切换：

1. 在跑项目、期初应收、期初应付、期初资金、成本完整性全部承接；
2. 四个主题（项目未收、项目未付、资金余额、项目成本）完成首月双轨对账；
3. 差异分类、处理、收敛；
4. 新业务 100% 走装得清；
5. BOSS 确认关闭首月双轨，原账本只保留法定会计用途。

## 2. 关键角色

| 角色 | 麦鸿侧 | 装得清侧 | 职责 |
| --- | --- | --- | --- |
| 项目负责人 | 企业负责人 | 实施负责人 | 决策、确认口径、最终关闭 |
| 财务负责人 | 财务 | 实施/客户成功 | 原账录入、差异处理、日常记账 |
| 项目经理 | PM | 实施/客户成功 | 提供项目状态与成本事实 |
| 数据责任人 | 财务/文员 | 实施 | 账本摸底、附件、对照表 |

> 具体人名在启动会确认，填入执行清单责任人列。

| 时间 | 议题 | 产出 |

## 8. 退出判断

满足以下条件可关闭首月双轨：

```text
四个主题全部完成对账
未分类/未处理差异为 0，或全部差异已分类确认接受
新业务 100% 走装得清
原账本只保留法定会计/税务用途
BOSS 确认关闭
```

未满足时：

- 进入延长对账期；
- 保留首月快照；
- 不强行关闭；
- 新差异单独记录，不修改历史对账结果。

## 9. 风险与升级

| 风险 | 处理 | 升级 |
| --- | --- | --- |
| 原账金额无法确认 | 标记待确认，不猜 | 财务负责人 + BOSS |
| 差异无法解释 | 分类记录，不静默调平 | BOSS 决策 |
| 成本不完整 | 利润置空，提示成本未完整 | 财务 + PM |
| 私户/个人垫付 | 主体差异，逐步规范新业务 | BOSS |
| 差异长期不收敛 | 延长对账期，增加对账频次 | BOSS + 实施 |
| 新业务仍走原账 | 每周统计覆盖率，专项跟进 | BOSS |

## 11. 成功标准

1. 四个主题 100% 完成对账；
2. 期初准确率 ≥ 95%；
3. 未分类/未处理差异为 0 或已确认接受；
4. 新业务 100% 走装得清；
5. BOSS 确认关闭首月双轨；
6. 原账本只保留法定会计/税务用途。

## 12. 一句话执行口径

> 先接管事实，再对齐差异，最后退出双轨；不搬科目、不建总账、不静默调平、不让历史污染指标。

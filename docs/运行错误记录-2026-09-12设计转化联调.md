## 1. 已修复问题

| 编号 | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| E-01 | 导入脚本请求 Provider 报 `tokenIsUndefined` | Python `urllib` 对自定义 `token` Header 的发送行为与框架鉴权不一致 | 导入脚本改用 `requests`，同时登录令牌只通过 Header 传递 |
| E-02 | `design/scheme/update` 报 `Design.name` 非空异常 | 自定义 Provider 的普通实体参数不会自动完成所有字段注入 | 按框架规范改为 `@AutoInject` 字段注入 |
| E-03 | `design/space/save` 报 `Space.name` 非空异常 | 同上，区域字段没有注入到实体 | 区域保存改为 `@AutoInject` 注入名称、类型、长宽高、排序和备注 |
| E-04 | `design/item/save` 报 `分项单位不能为空` | 分项字段未注入，且脚本把中文单位直接传给枚举字段 | Provider 改为 `@AutoInject`；导入脚本增加中文单位到 `Area/Count/Set/...` 的映射 |
| E-05 | 谈单生成报 `Found shared references to a collection: TalkSection.images` | 多个 TalkSection 复用了同一个 Hibernate 集合实例 | 每一页创建独立的 `ArrayList` |
| E-06 | `quote/save` 返回体过大，客户端解析失败 | 报价响应没有限制嵌套的 Design/Customer/QuoteItem 字段 | 为报价保存 Provider 增加严格 `@Properties` 白名单 |
| E-07 | 谈单生成响应递归膨胀 | `Talk.sections` 序列化 TalkSection 后又反向序列化 Talk | 给 TalkSection 增加字段白名单 |
| E-08 | 重试导入产生重复诉求、方案和谈单页 | 导入脚本每次无条件新增 | 诉求按标题去重；方案按名称复用；区域和分项按业务键更新 |
| E-09 | 空方案和重复“客餐厅更新”污染报价 | 首次联调测试数据未清理 | 增加区域/分项删除 Provider，清理测试记录，归档空方案 |
| E-10 | 设计师客户详情没有“设计转化”入口 | 入口放在仅营销角色可见区域 | 提升为客户详情独立卡片，设计师可直接进入 |
| E-11 | PPT 下载地址返回前端 HTML | Nginx 对 `/upload/**` 未转发，且框架 API 路由拦截了静态资源 | 增加 `/upload/**` Nginx 转发和受控的 PPT 下载控制器 |
| E-12 | 金额显示为 `¥¥` | 模板手写 `¥`，同时 `money()` 也返回 `¥` | 删除模板中的重复货币符号 |
| E-13 | 删除已进入报价快照的设计分项触发数据库外键异常 | 删除前未校验 QuoteItem 快照引用 | 增加报价快照引用校验，返回明确业务提示 |
| E-14 | 报价设计页面信息密度高、按钮分散、字号层级不一致 | 每个页面单独实现布局和底部操作，缺少统一工作台规范 | 增加全局工作台样式；统一操作栏、分段导航、指标块、表单卡和按钮尺寸 |
| E-15 | 谈单页 25 页全部展开，内容过长难定位 | 缺少分页导航和折叠展示 | 增加页目录快速跳转、每页内容折叠与展开 |
| E-16 | 后端长文本导致移动端卡片、报价明细和谈单页变形 | Flex 子项缺少 `min-width:0`，长名称/规格/公式没有换行或限行 | 增加全局长文本工具类，列表单/双行截断，详情安全换行，价格与状态保持不压缩 |
| E-17 | 首次联调统一材料库时 `catalog/item/tree` 提示登录状态失效 | 旧令牌在当前后端实例中已失效 | 使用指定账号重新登录后验证通过 |
| E-18 | 材料库树首次迁移报 `Found shared references to a collection: CatalogItem.images` | 多条迁移记录复用了同一个 Hibernate 集合实例 | 每条 `CatalogItem` 创建独立 `ArrayList` 保存图片地址 |
| E-19 | 设计师可绕开统一导航守卫，直接输入 URL 打开材料库维护页 | H5 地址直连不经过小程序 `navigateTo` 拦截器，页面自身未再次校验角色 | 维护页 `onLoad` 增加 `edit:catalog` 校验，未授权立即回首页；服务端仍返回 403 |
| E-20 | 主材分页列表返回未展示的图片集合，形成逐项懒加载 SQL | `catalog/item/page` 响应白名单包含 `images`，页面每次加载 30 项会触发大量附加查询 | 分页响应移除 `images`；分类树改为只查询分类/品牌/规格维度 |

## 2. 已完成重构

### 2.1 catalog

- 新包：`com.th4.edge.decoboon.catalog`
- 统一根实体：`CatalogItem`
- 六类明细：施工、主材、软装、定制、电器、综合
- 统一枚举：`ItemType`、`PricingMethod`
- 真实数据：施工 160、主材 254、全屋定制 108、综合 15
- 已补齐类型明细：施工 160、主材 254、全屋定制 108、综合 15

### 2.2 pack

- 新包：`com.th4.edge.decoboon.pack`
- `PackageTemplate / PackageSection / PackageLine`
- 套餐行直接关联 `CatalogItem`
- 套餐成本由服务端根据目录成本和套餐数量重新计算
- Provider 路由：`pack/template/*`、`pack/section/page`、`pack/line/page`

### 2.3 quote

- 新包：`com.th4.edge.decoboon.quote`
- `Quote / QuoteLine / QuoteComponent / QuoteGroup`
- `QuoteMode = Package / Custom / Hybrid`
- `QuoteLineRole = Base / Option / Upgrade / Add / Deduct / Replace / Gift`
- 价格组件区分材料、人工、成本和其他
- Provider 路由：`quote/page`、`quote/info`、`quote/save`、`quote/update`、`quote/line/page`

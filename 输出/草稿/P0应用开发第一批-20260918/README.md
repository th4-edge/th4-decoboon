## 当前证据结论

- 跨租户项目详情负向验证：返回 `404 项目不存在或无权访问`。
- 同企业跨数据范围未通过：业务员可调用 `project/project/save` 读取老板负责项目；临时将报价置为待签状态后，也可通过 `project/contract/save` 读取老板合同。
- 新客户无跟进、仅存在地址时可以成功约定量房，并自动创建房屋档案，违反“客户地址不等于房屋、量房必须先建立房屋”的口径。
- 报价确认后客户状态立即变为“已签约”，早于合同签约。
- 合同签约价直接复制报价金额，没有签约价调整、原因和快照入口；直接签约基线报价也不存在。
- 报价分项只能读取项目库价格，代码明确覆盖前端价格，当前不支持“自定义销售价必须标记”。
- App 客户来源把 `WalkIn` 写成 `Walkin`、把 `OldCustomer` 写成 `Old`，实测后端静默落为 `Other`。
- 财务总览仍显示 `¥1,600` 材料应付、估算/实际成本为 0、累计利润 `¥48,400`、毛利率 97%，复现 `GAP-003` 的伪利润风险。

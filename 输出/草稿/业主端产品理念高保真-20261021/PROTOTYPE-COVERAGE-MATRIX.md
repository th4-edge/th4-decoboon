## 五类业务详情页覆盖

| 业务详情 | 实现在线页 | 必须保留的业务事实 | 线下确认/记录口径 | 真实空态 |
| --- | --- | --- | --- | --- |
| 报价详情 | `#quote` | 版本、空间构成、逐项金额、版本差异、附件 | 客户线下确认，设计师/员工登记；不是业主在线确认 | 1 版汇总 + 明细未同步 |
| 合同详情 | `#contract` | 主体、金额、范围、工期、付款节点、附件 | 客户线下签约，员工登记生效 | 合同事实 + 正文/材料未同步 |
| 选材详情 | `#selection` | 品牌、系列、花色、规格、空间、版本 | 客户线下确认，设计师登记 | 0 版本 + 完整形成规则 |
| 材料计划 | `#material-plan` | 下单、运输、预计到场、现场记录 | 不需要业主确认；到场 ≠ 质量验收 | 0 项 + 完整形成规则 |
| 增减项 | `#change` | 原因、明细、金额、状态、发起与生效时间 | 企业审批生效后业主只读同频；不建模业主在线确认 | 0 项 + 合同金额未变化 |

详情页共同交互：

- 支持 URL 深链和返回原来源页。
- 顶部详情导航避开微信胶囊与状态栏。
- 附件和业务原件可通过文档预览层打开。
- 报价构成使用可展开空间分组，避免首屏一次堆满全部明细。
- 详情页正文、金额、状态和留痕均使用可读字号，状态同时具备文字、颜色和位置。
- 真实数据态不借用丰富内容态的明细、附件、照片或金额。

## 全局视觉与排版门禁

| 项目 | 统一规则 | 验收方式 |
| --- | --- | --- |
| 内容轨 | 标准区块左右 16px，宽度 358px | DOM 边界检查 |
| 章节对齐 | 标题、说明、子卡片同宽 | section-head 与子卡边界比较 |
| 正文字号 | 12.5–13px | 计算样式检查 |
| 辅助字号 | 不低于 11px，图标字形除外 | 计算样式检查 |
| 主要卡片 | 20px 圆角 | 样式检查 |
| 点击区域 | 主按钮不低于 44px | 尺寸检查 |

| 横向溢出 | 0px | 390×844 渲染 |
| 导航避让 | 详情导航不触碰微信胶囊 | BoundingBox 检查 |

## 暂缓项与原因

| 项目 | 原因 |
| --- | --- |
| 同小区/同户型匿名避坑榜 | 涉及其他业主隐私、数据授权、评价责任和平台边界，必须先裁决 |
| 自动生成法律整改函 | 涉及法律责任与模板审核，不能用原型虚构 |
| 延期赔偿自动计算 | 依赖合同条款与责任认定，必须业务裁决 |
| 企业完整案例页与预约 | 需要案例授权、脱敏和装企资料生产机制 |
| 真实 360° 查看器 | 需要真实全景素材和拍摄规范 |
| 自动环境音乐播放 | 小程序音频策略、版权和用户打扰需另行验证 |

## 结论

新版不得再用“视觉升级”替代“内容覆盖”。每次改版后都应更新本矩阵，并逐项确认原稿中的业主价值是否被保留、增强，或明确说明暂缓原因。

## 灵动细节

- 中央装修历程按钮在激活时有呼吸光环。
- 首页实时状态点有轻微脉冲，避免页面像静态海报。
- 当前施工阶段节点有脉冲聚焦。
- 装修历程进入时数字从 0 滚动到真实统计。
- 时间线按滚动逐条出现，照片从轻微放大的状态缓慢回到自然比例。
- 装修历程拥有顶部滚动进度和真实环境音乐开关。
- 主材与空间支持前后对比滑杆。
- 图片、视频、验收、增减项、漏项等关键内容均可点击进入细节层。
- 支持 `prefers-reduced-motion`，用户选择减少动效时不强行播放动画。

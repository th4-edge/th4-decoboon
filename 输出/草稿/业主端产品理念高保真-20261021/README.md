# 装得清 · 业主端产品理念高保真

- 日期：2026-10-21
- 形态：单文件可交互 HTML
- 对照版本：`index.html` 丰富内容态 / `index-real-data.html` 真实数据态
- 目标：先确认业主端的产品目标、叙事方式与交互气质，再进入小程序实现
- 数据：全部为虚构演示数据，不代表真实项目、金额或承诺

## 核心命题

> 业主端不是装企 ERP 的移动投影，而是站在业主这一侧的掌控感、安全感和装修记忆。

业务能力与价值能力必须分开：

- 业务能力：我的家、进度、我的钱、家档案，负责事实、责任、证据和服务。
- 价值能力：中央装修历程，负责画面、记忆、感受、音乐和分享。

分享不是因为装企需要获客，而是因为业主觉得这一段过程值得被家人看见、值得被记住。

## 五个核心界面

| 界面 | 业主问题 | 产品表达 |
| --- | --- | --- |
| 我的家 | 今天家里怎么样，需要我做什么 | 一句话现状、唯一待确认事项、未来 7 天、现场、服务的人、家庭分享 |
| 进度 | 家里是否在正常推进 | 阶段时间线、谁在做、是否需到场、计划与实际 |
| 我的钱 | 下一笔为什么付，为什么金额变了，我是否安全 | 付款进度、报价版本差异、开工前漏项、增减项与下一节点 |
| 家档案 | 装修结束后我留下什么 | 隐蔽工程、材料档案、质保售后、家的相册、服务关系 |
| 装修历程 | 这段经历值得记住吗 | 深色沉浸层、关键画面、人物承诺、家庭故事、可控制分享 |

本轮在内容厚度上进一步补强：

- 首页增加施工现场视频、照片流、主材护照与自然光细节。
- 进度页增加项目经理现场巡检视频和多图证据条。
- 家档案增加“家的影像”视频档案。
- 装修历程增加现场视频、材料组合、同一空间前后对比滑杆和完整人物承诺。
- 明确要求装企按里程碑持续准备照片、短视频、材料自然光图、验收证据和人物服务说明。

进度页同时保留了 10-14 原型中真正有价值的业主表达：

- 已完成 / 进行中 / 等你确认 / 未开始的状态图例。
- 每个阶段“做了什么、谁负责、和计划相比如何”。
- “进度按已完成阶段计算，不是按天数；需要业主确认的节点由业主本人完成”。
- 每日一张现场全景，保留日期、拍摄人和阶段。
- 现场记录照片带日期、阶段与拍摄人出处。
- 整改事项展示责任人、承诺日期、返工说明和业主复验入口。

“我的钱”已从单一付款页恢复为完整业主资金视图：

- 当前待付、应付总额、已付与下一笔付款。
- V3 报价相对 V2 的逐项金额变化，以及客户签认来源。
- 开工前 26 项漏项自查与 3 项不确定记录。
- 审批中与已生效增减项分开展示，只有审批生效才计入付款计划。
- 不展示企业成本、利润与供应商价。

## 全局排版收敛（第三轮）

本轮不是继续加内容，而是统一整套界面的视觉秩序：

- 标准内容轨统一为左右 16px，即 `16 / 374 / 358`。
- 章节标题、章节说明与章节内卡片同宽，清除双重 16px 内缩。
- 正文提升至 12.5–13px，辅助信息不低于 11px；按钮最小高度 44px。
- 主要卡片统一 20px 圆角；金额、状态、时间与登记来源使用一致层级。
- 详情页改为浅色纸质单据风格。
- 深色主题只保留在“装修历程”，并使用暖深绿与高对比米白，不再用近黑科技色。
- 首页选材任务、我的钱增减项均可直接进入对应详情页。

## 五类业务详情页

本轮把报价、合同、选材、材料计划、增减项从摘要卡补齐为独立详情页，支持深链和返回来源：

- `#quote`：版本记录、空间构成、逐项金额、版本差异、线下确认登记、报价与确认材料。
- `#contract`：合同主体、当前金额构成、施工范围、付款节点、线下签署登记、合同附件。
- `#selection`：品牌、系列、花色、规格、空间、版本、线下确认登记，并明确“选材确认 ≠ 材料到场”。
- `#material-plan`：下单、运输、到场时间线、自然光与包装记录、材料员留痕，并明确“到场不需要业主确认，也不等于质量验收”。
- `#change`：审批中与已生效分开展示；审批中不显示金额，只有生效金额进入合同与付款；业主端只读同频，不建模业主在线确认。

统一的详情页规则：

1. 谁登记、何时登记、来源是什么，必须可见。
2. 客户线下完成、员工登记的事实，不能伪装成业主在小程序点击确认。
3. 真实为空时保留完整结构，但明确“尚未形成/未同步”，不补造明细、附件或照片。
4. 企业成本、利润、供应商价格和内部审批意见不进入业主端。
5. 详情页只设一个视觉主行动，疑问反馈降级为次行动。

## 三个关键交互层

1. **水电验收**：6 项验收点、现场证据、业主本人确认或提出疑问。
2. **为你家负责的人**：明确谁负责什么、出现哪类问题找谁、换人可追溯。
3. **给家人的一扇窗**：分享卡片预览、房号/金额/照片范围控制、装企身份随内容自然出现。

原型中的“现场视频”为本地生成的演示蒙太奇；正式产品必须由装企在真实施工节点拍摄并授权使用。素材要求见左侧栏“装企实施素材要求”。

## 三端角色价值

- 业主：被保护、被理解、能看懂、能掌控、值得分享。
- 装企：服务被看见，责任被留证，口碑由真实过程自然发生。
- 装得清：提供可信的记录与保管，不抢装企服务主体，不把业主素材变成平台广告。

## 预览方式

直接打开 `index.html`，点击左侧页面列表或手机底部导航。

- 中央凸起按钮进入装修历程。
- 首页点击“去验收”打开验收层。
- 点击服务团队打开责任关系层。
- 点击家庭分享卡片或历程底部按钮打开分享预览。

本地预览若浏览器限制 `file://`，可在本目录执行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765/index.html`。

详情页深链：`#quote`、`#contract`、`#selection`、`#material-plan`、`#change`。

真实数据对照：

- 丰富内容态：`http://127.0.0.1:8765/index.html`
- 真实数据态：`http://127.0.0.1:8765/index-real-data.html`

真实数据态以现有验收 JSON 的真实项目为输入：祥泰园 2-1102、施工中 30%、水电阶段、0 张现场照片、0 段视频、1 版报价 ¥32,600、合同已生效、6 个付款节点、3 位服务人员。它用于验证“内容不足时不出现空壳和假故事”。

## 设计原则

1. 不把丰富内容态当生产默认页。
2. 没有照片、视频和节点时，不显示对应卡片骨架。
3. 不伪造未来 7 天、材料护照、验收证据、整改记录和装修故事。
4. 只在有真实数据的地方展开；没有的地方用一条克制的说明说清“何时会出现”。
5. 零待办不是空白，而是明确的“今天不需要您操作”。
6. 装修历程无素材时只展示第一章，不展示 18 天、42 张照片、纪念册等富内容。

## 分级渲染

| 内容等级 | 条件 | 页面表现 |
| --- | --- | --- |
| L0 事实型 | 只有合同、报价、付款、团队 | 文字 Hero、付款卡、团队卡、诚实空态 |
| L1 进度型 | 有阶段与进度 | 阶段卡、计划或当前阶段 |
| L2 证据型 | 有照片、视频、责任人说明 | 现场视频、照片墙、每日全景、整改 |
| L3 故事型 | 有多个节点、素材、人物表达 | 数字统计、完整时间线、纪念册、家庭分享 |

真实数据详情页不允许：

- 用丰富内容态的报价行、材料照片或变更金额填充空态。
- 把“合同已生效”扩写成已返回合同正文或签署材料。
- 把“报价已转项目”扩写成当前接口已经返回线下登记人。
- 把增减项展示成业主在线确认，或为 0 条变更制造假时间线。

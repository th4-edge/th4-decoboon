# 新手企业操作引导手册

- 状态：`frozen_for_implementation / pending_independent_acceptance`
- 唯一状态契约与验收矩阵：`07-系统内引导与验收清单.md`
- 适用对象：新注册企业的 Boss；其他角色按岗位首页和对象主线上手。

## 1. 首次上手目标

企业注册完成后，Boss 不需要理解全部菜单，只需完成报价基础数据和第一个客户/房屋，即可开始第一份客户报价。

首页显示：

```text
开始使用装得清  0/3
下一步：维护报价项目库
完成后可维护标准成本价，再建立第一个客户和房屋。
[立即维护]
```

首次入驻完成条件固定为 3 个必做步骤：

1. 至少一个有效报价项目。
2. 至少一个报价项目维护正数标准成本价。
3. 至少一个客户并关联至少一套房屋。

邀请成员和供应商品牌关系为可选步骤，不改变 `3` 的必做分母。

## 2. 首次上手步骤

### 第1步：维护报价项目库（必做）

- 维护类型、分类、名称、品牌、规格、单位、计价方式、销售价和成本价。
- 至少一个有效可报价项目后完成本步骤。
- 完成标准：当前企业存在真实报价项目，而非页面打开或保存成功提示。

### 第2步：维护标准成本价（必做）

- 成本价直接维护在报价项目，不要求先建供应商。
- 成本维护角色：Boss、店长、材料/履约、财务。
- 至少一个有效报价项目满足 `costPrice > 0` 后完成本步骤。
- 成本价可暂时为空，系统标记“成本未维护”，但首次入驻成本步骤保持未完成。

### 第3步：创建第一个客户及房屋（必做）

- 客户：姓名、手机号、来源、负责人。
- 房屋：客户、地址、小区、楼栋、房号、面积和户型。
- 至少一个客户并关联至少一套房屋后完成本步骤。
- 仅有客户、没有房屋时不得显示完成。

### 第4步：维护供应商品牌关系（可选）

- 供应商不是维护报价成本的前置条件。
- 需要材料下单和采购时再维护材料供应商，并在供应商下关联品牌；厂家/班组按对应采购类型另行使用。
- 完成谓词：至少一个 `status=active` 且 `type=supplier` 的供应商，并至少关联一个非空品牌。
- 只新增供应商名称、未关联品牌时，不算完成。
- 可选步骤完成后不改变首次入驻的必做分母和下一步。

### 第5步：邀请关键成员（可选）

- 可按实际需要邀请店长、业务员、设计师、项目经理、材料/履约、财务。
- 单人多角色企业可以暂不邀请，不阻塞首次入驻完成。
- 完成谓词：当前企业存在至少一个非 Boss 的有效成员。

## 3. 后续业务里程碑

第一份报价、客户接受、合同签约和项目立项是对象主线上的后续业务里程碑，不计入首次入驻完成分母。

完成首次入驻只表示企业基础数据已具备开始第一份报价的条件，不表示已经完成首单、签约或项目交付。

## 4. 成本调整与签约

```text
报价阶段：销售价格快照 + 当前成本参考
签约时：数量 × 当前 CatalogItem.costPrice，冻结合同行成本
签约后：修改报价项成本不改历史签约快照
实际采购：到货后另行形成实际成本和应付
```

成本不完整时利润和毛利率为空，页面显示“成本未完整”。

“成本缺失是否允许签约”仍按业务正式规则执行；本手册不把成本完整性当作未经确认的强制阻断条件。

## 5. 角色首次登录提示

| 角色 | 首次提示 |
| --- | --- |
| Boss | 维护报价项、标准成本价、客户/房屋；供应商和成员按需补充 |
| 店长 | 维护本店报价和成本，查看本店经营 |
| 团队负责人 | 配置团队和成员范围 |
| 业务员 | 登记客户、跟进、建立房屋、约量房 |
| 设计师 | 选项目库、工程量、报价和客户决策 |
| 项目经理 | 项目开工后处理计划、现场和验收 |
| 材料/履约 | 维护报价项目成本、供应商品牌关系和采购 |
| 财务 | 检查成本完整性、应收应付和结算 |

## 6. 状态刷新要求

- 用户从报价项目库、客户建档、供应商品牌页返回首页时，首页必须重新读取真实状态。
- 下拉刷新和非首次 `onShow` 都必须重新收敛状态。
- 删除、停用或回退业务对象后，已完成状态必须允许恢复为未完成。
- 接口异常必须显示可确认的异常/未知状态，不能用空数组伪装“已完成”或“确定未完成”。

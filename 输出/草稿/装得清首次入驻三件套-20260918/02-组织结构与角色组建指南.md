# 组织结构与角色组建指南

## 1. 组织结构

```text
Company 企业
  -> Store 门店
  -> Team 团队
  -> Employee 员工
  -> ProjectParticipation 项目参与关系
```

- 企业：数据隔离的第一边界。
- 门店：店长的默认范围。
- 团队：团队负责人的默认范围。
- 员工：普通岗位默认只处理本人或参与对象。
- 项目参与关系：设计师、项目经理、履约/材料在项目上的显式协作关系，不替代经营负责人。

## 2. 默认数据范围

| 角色 | 默认数据范围 | 说明 |
| --- | --- | --- |
| Boss | Company | 全公司经营、组织和关键审批 |
| StoreManager | Store | 本门店客户、报价、项目和团队 |
| TeamLeader | Team | 本团队客户、报价、项目和成员 |
| Marketer | Self/参与客户 | 本人负责客户和跟进 |
| Designer | Self/参与客户与项目 | 本人负责或被指派的设计、报价和项目 |
| Pm | Self/参与项目 | 本人负责或参与项目 |
| ProjectSupport | Self/参与项目 | 项目采购、到货和履约范围 |
| Finance | 财务职责范围 | 应收、应付、往来、结算和成本权限 |

## 3. 角色职能

### Boss 企业负责人

- 目标：看清经营、控风险、定组织、处理高影响决策。
- 日常：经营看板、关键报价/合同、资金、异常和权限。
- 首次配置：企业资料、组织、报价项目库、供应商成本和核心成员。
- 不应承担：逐条录入客户、重复对账、替代每个岗位操作。

### StoreManager 门店店长

- 目标：本店客户转化、设计调度、项目履约和回款。
- 日常：分配客户、指定设计师、盯报价/合同/项目/应收异常。
- 权限：本店数据；不能看其他门店越权数据。
- 交接：客户分给业务员/设计师；项目交给项目经理；财务事项交财务。

### TeamLeader 团队负责人

- 目标：团队漏斗、成员产能和交付风险。
- 日常：团队客户分配、跟进催办、设计与项目协同、业绩查看。
- 权限：本团队客户、项目、成员和业绩。
- 不应承担：企业级权限和跨团队数据。

### Marketer 业务员/家装顾问

- 目标：把线索转为有效客户并推进到量房、设计和报价。
- 日常：登记客户、记录电话/微信/到店/拜访、建立房屋、预约量房。
- 必须完成：首次有效跟进后才能进入量房。
- 不应看到：标准采购成本和项目毛利。

### Designer 设计师

- 目标：完成量房、设计诉求、方案、分项和报价，推动客户决策。
- 日常：录量房、选项目库分项、填工程量、解释销售价、提交报价。
- 成本权限：只看到销售价；成本字段按管理策略控制。
- 交接：客户接受后交 Boss/有签约能力的角色；项目生效后交项目经理。

### Pm 项目经理

- 目标：项目按期、按质、安全、成本可控交付。
- 日常：阶段、任务、现场动态、材料需求、问题整改、验收申请。
- 权限：本人参与项目；不改报价和经营负责人。
- 交接：采购执行交履约/材料；收付款交财务。

### ProjectSupport 履约/材料

- 目标：保障材料计划、询价、采购、到货和履约协同。
- 日常：材料计划、供应商选择、采购、到货确认、异常登记。
- 成本权限：可看本次采购执行价；不默认看供应商历史和项目综合毛利。
- 交接：到货后形成实际成本和应付，交财务处理付款。

### Finance 财务

- 目标：应收应付准确、资金可追踪、项目成本完整、结算可靠。
- 日常：收款、付款、核销、台账、供应商往来、结算和成本检查。
- 权限：根据正式财务范围读取；成本不完整时利润为空。
- 不应做：为了平账直接修改原始业务事实。

## 4. 推荐邀请顺序

### 单人/3–8 人小团队

1. Boss 兼主要经营。
2. 设计师。
3. 项目经理或履约角色。
4. 业务员。
5. 财务可稍后或由 Boss 兼任。

### 10–30 人单店

1. 店长。
2. 团队负责人。
3. 业务员和设计师。
4. 项目经理和履约/材料。
5. 财务。

### 2–3 店

1. Boss。
2. 店长。
3. 团队负责人。
4. 各店业务员、设计师、项目经理。
5. 财务和履约共享或分店配置。

## 5. 邀请流程

```text
Boss/店长/团队负责人
-> 选择角色
-> 选择门店/团队
-> 输入手机号和姓名
-> 系统校验席位与邀请限制
-> 员工微信接受邀请
-> 复制企业/门店/团队/角色
-> 生成角色首次登录任务
```

注意：

- 邀请门店目前固定复制邀请人门店，多店场景的目标门店选择仍需业务裁决。
- 团队负责人邀请不能越级邀请店长或其他团队负责人。
- 邀请接受后，员工首次登录应看到自己的岗位任务，而不是全公司菜单。

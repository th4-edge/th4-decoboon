# 业务前置数据准备指南

## 1. 最低可用数据

要开始第一份报价，只需要：

1. 企业、默认总店和 Boss。
2. 至少一条报价项目，含销售价、单位、计价方式和可选成本价。

要开始采购下单，再增加：

3. 至少一个供应商/合作方。
4. 供应商关联品牌。

## 2. 报价项目库与成本

必须维护：

- 项目类型、分类、名称、品牌、规格、单位。
- 计价公式。
- 销售价。
- 成本价。
- 是否有效。

成本规则：

- `CatalogItem.costPrice` 是标准成本来源。
- 不要求供应商和采购价记录。
- 供应商价格变化时直接修改报价项成本价。
- 签约时才冻结成本快照。

## 3. 供应商和品牌关系

需要采购时维护：

- 供应商类型、名称、联系人、电话、账期、结算方式。
- 供应商关联品牌，如“马可波罗”“东鹏”“圣象”。

采购匹配：

```text
材料品牌 -> 有效供应商品牌关系 -> 可用供应商列表
```

供应商品牌关系是采购关系，不是报价成本的逐项计算公式。

## 4. 员工邀请

准备：

- 姓名、手机号、角色。
- 门店、团队。
- 数据范围和岗位说明。

推荐顺序：

1. Boss。
2. 店长/团队负责人。
3. 业务员、设计师。
4. 项目经理、材料/履约。
5. 财务。

## 5. 客户与房屋

- 客户和房屋必须是两个对象。
- 客户地址不能代替房屋档案。
- 量房、设计、报价、合同、项目都绑定具体房屋。

## 6. 历史数据准备

- 报价项目库：名称、分类、品牌、规格、单位、销售价、成本价。
- 供应商：名称、类型、联系方式、品牌。
- 员工：手机号、角色、门店、团队。
- 历史报价：原报价编号、客户、房屋、分项、数量、销售价、成本参考和状态。

旧成本只作参考，不自动成为标准成本；由企业确认后回填。

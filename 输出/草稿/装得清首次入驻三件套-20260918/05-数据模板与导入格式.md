# 数据模板与导入格式

## 1. 通用规则

- UTF-8 CSV。
- 日期 `YYYY-MM-DD`。
- 金额为数字，不带货币符号。
- 品牌名称与报价项目保持一致。
- 成本价可由 Boss、店长、材料、财务维护。
- 供应商和品牌关系在采购前补充，不作为报价项前置。

## 2. 模板

| 文件 | 用途 |
| --- | --- |
| `templates/01-报价项目库导入模板.csv` | 项目、销售价、成本价 |
| `templates/02-供应商合作方导入模板.csv` | 供应商主数据 |
| `templates/03-供应商品牌关系导入模板.csv` | 品牌与供应商匹配 |
| `templates/04-员工邀请清单模板.csv` | 组织邀请 |
| `templates/05-历史报价兼容模板.csv` | 旧报价迁移 |

## 3. 成本导入顺序

```text
报价项目
-> 销售价和成本价
-> 供应商
-> 供应商品牌关系
-> 材料采购时按品牌选供应商
```

不再要求导入逐项供应商采购价作为标准成本。

## 4. 校验

- 报价项目编码唯一。
- 成本价不得为负数。
- 品牌关系中的品牌必须能匹配报价项品牌，否则进入待确认。
- 同一供应商同一品牌重复关系需要合并或确认。
- 历史成本导入必须标记为“历史参考”或“确认标准成本”。

## 5. 幂等

- 重复导入按企业、编码和品牌关系幂等。
- 失败按整批回滚。
- 不产生半成品供应商品牌关系。

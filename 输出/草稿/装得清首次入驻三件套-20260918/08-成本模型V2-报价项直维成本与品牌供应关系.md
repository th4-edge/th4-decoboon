# 成本模型 V2：报价项直维成本与品牌供应关系

- 决策来源：用户 2026-09-18 最新产品决策。
- 状态：`user_confirmed / pending_business_record`
- 影响：`BR-003`、`CatalogItem`、`PartnerPrice`、`Partner`、合同签约、项目成本和采购。
- 重要：本模型与原 `BR-003` 存在冲突，开发前必须形成正式业务裁决记录，不能静默覆盖。

## 1. 新模型

```text
报价项目库 CatalogItem
-> 直接维护标准成本 costPrice
-> 报价时只形成销售价格快照
-> 合同签约时读取当前报价项目成本并计算/冻结签约成本
-> 项目使用签约成本作为预计成本基线
-> 实际采购到货后另行形成实际成本
```

供应商不再是维护报价成本的必经前置。

## 2. 成本维护

- 报价项目一条记录同时维护销售价和标准成本价。
- 标准成本价直接保存在 `CatalogItem.costPrice`。
- 维护角色：Boss、店长、材料员/ProjectSupport、财务。
- 设计师、业务员默认不看到标准成本。
- 供应商不存在也允许先保存报价项目。
- 供应商价格调整时，直接修改对应报价项目成本价。
- 批量调整可按品牌、分类或项目筛选后批量修改。

## 3. 签约成本时机

- 报价阶段：成本仅为当前参考，不要求完整，不锁定为最终成本。
- 合同签约时：系统按报价分项数量 × 当前 `CatalogItem.costPrice` 计算成本。
- 签约完成后：形成合同成本和合同行成本快照，后续修改报价项目成本不得改变已签约快照。
- 合同生效和项目立项：项目沿用合同签约成本快照作为预计成本基线。
- 实际采购到货：形成实际成本和应付，实际成本与签约成本差异单独保留。

## 4. 未完整成本处理

待业务智能体确认：

- 关键成本缺失时是否允许签约。
- 允许签约时，是否显示“成本未完整”并禁止利润展示。
- 是否要求指定审批人确认后才能签约。

本方案默认建议：

```text
成本缺失 -> 显示清单 -> 可允许签约但利润为空
只有正式业务确认后才可改为强制阻断
```

## 5. 供应商与品牌关系

供应商主数据后置维护：

```text
先创建报价项目
-> 报价值中包含品牌，如“马可波罗”
-> 后续维护供应商
-> 在供应商下关联品牌
-> 材料采购时按品牌筛选可用供应商
```

示例：

```text
马可波罗瓷砖报价项 20 条
供应商 A 关联品牌：马可波罗
供应商 B 关联品牌：马可波罗
采购“马可波罗 800×800 地砖”时，系统列出 A、B 供选择
```

不需要为每个报价项目分别创建供应商采购价。

## 6. 品牌关系对象

建议新增 `PartnerBrand`：

| 字段 | 说明 |
| --- | --- |
| company | 企业 |
| partner | 供应商/厂家/班组 |
| brand | 品牌名称，如马可波罗 |
| status | 有效/停用 |
| priority | 可选，展示顺序 |
| createdBy | 维护人 |

供应商下单匹配流程：

```text
材料计划或采购项
-> 读取 CatalogItem.brand
-> 查询有效 PartnerBrand
-> 返回可用供应商
-> 用户选择本次供应商
-> 采购单保存供应商和本次执行价
```

若没有匹配品牌：

- 允许手工选择供应商；
- 提示“为该供应商补充品牌关系”；
- 不阻断紧急采购，但留下待补数据。

## 7. 与原供应商采购价模型兼容

- `PartnerPrice` 不再作为标准成本的必需来源。
- 已存在 `PartnerPrice` 的企业可选择：
  1. 以某个供应商价格回填 `CatalogItem.costPrice`；
  2. 保留为历史价格，不参与标准成本；
  3. 后续只用于比价和采购参考。
- 回填必须人工确认供应商、有效期和成本口径，不能自动选择最低价或最新价。
- 原采购执行价继续保存在采购单，不改其业务含义。

## 8. 报价与合同快照

```text
报价：
销售价格快照 + 当前成本参考

签约：
合同行成本快照 = 数量 × 当前 CatalogItem.costPrice
合同成本快照 = Σ 合同行成本
costSnapshotAt = 签约时间

项目：
预计成本 = 合同成本快照
实际成本 = 实际采购/到货等事实
成本差异 = 实际成本 - 预计成本
```

## 9. 菜单与引导变化

- 报价项目库直接出现“成本价”字段。
- 不再要求先进入供应商采购价才能维护成本。
- 供应商协作只在采购、材料下单和品牌关系需要时使用。
- 首页上手路径改为：
  1. 报价项目库和成本价；
  2. 可选：供应商和品牌关系；
  3. 第一条客户。
- 视频 V03 必须展示直接维护成本价。
- 视频 V04 改名为“供应商与品牌关系”，不再讲逐项采购价绑定。

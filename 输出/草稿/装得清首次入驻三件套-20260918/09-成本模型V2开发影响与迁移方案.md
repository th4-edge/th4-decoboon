# 成本模型 V2 开发影响与迁移方案

## 1. 后端对象变化

### CatalogItem

- `costPrice` 成为企业标准成本的直接来源。
- `catalog/item/save`、`catalog/item/update` 接受并保存成本价。
- `CatalogCostContext.COST_VISIBLE` 增加材料员/ProjectSupport。
- 销售价与成本价仍分离，设计师、业务员、项目经理默认不返回成本价。

### Partner

- 供应商主数据保留，但不再作为维护报价成本的前置条件。
- 供应商可在采购前补充。

### PartnerBrand

建议新增：

```text
PartnerBrand
- partnerBrandId
- company
- partner
- brandName
- status
- priority
- createdBy
```

索引：

```text
(com_id, partner_brand_id)
(com_id, partner_id, partner_brand_id)
(com_id, brand_name, partner_brand_id)
```

约束：同一企业、同一供应商、同一品牌避免重复关系。

### PartnerPrice

- 不再作为标准成本的必需来源。
- 保留表和数据以兼容历史，但不再要求报价项逐项维护。
- 后续只用于历史价格、比价或采购参考。

### ProjectContract / ContractLine

建议增加：

```text
ProjectContract.signedCostAmount
ProjectContract.costComplete
ProjectContract.costSnapshotAt
```

合同签约时：

```text
合同行成本 = 报价行数量 × 当时 CatalogItem.costPrice
合同成本 = Σ 合同行成本
```

如果现有 `ContractLine.cost` 可以承担行成本，就不新增行字段，只补合同级汇总和快照时间。

### ProjectCostContext

新的成本优先级：

```text
已签约合同成本快照
-> 已签约合同行成本快照
-> 当前 CatalogItem.costPrice
-> 成本未完整
```

实际成本：

```text
采购到货/入库实际成本
-> 未发生时使用签约预计成本作为参考
```

签约成本与后续实际成本必须分开展示，不得覆盖。

## 2. 签约流程

```text
合同草稿
-> 不锁定成本
-> 正式签约
-> 重算成本完整性
-> 形成合同成本快照
-> 合同生效
-> 项目预计成本使用签约快照
```

关键：

- 合同草稿创建时不冻结最终成本。
- 只有签约动作发生时，使用当时报价项目成本。
- 重复签约幂等，不生成第二套成本快照。
- 签约后报价项成本变化不更新签约快照。

## 3. 报价与成本展示

报价阶段：

```text
销售金额：已形成快照
当前参考成本：按当前 CatalogItem.costPrice 计算
签约成本：待签约时确定
```

有成本权限的角色可看成本和缺失项；无权限角色不返回成本字段。

## 4. 供应商品牌采购流程

```text
材料计划
-> 读取品牌
-> 查询有效 PartnerBrand
-> 返回供应商列表
-> 选择本次供应商
-> 填写/确认采购执行价
-> 下单
-> 到货形成实际成本和应付
```

没有品牌关系时允许人工选择供应商，并提示补充关系。

## 5. 数据迁移

1. 报价项目成本：
   - 优先使用客户确认的 Excel 成本价回填 `CatalogItem.costPrice`。
   - 旧 `PartnerPrice` 可作为候选来源，但不能自动选取。
2. 供应商品牌：
   - 从报价项目品牌和供应商历史采购记录整理。
   - 不能确认的关系标记待确认。
3. 已签约项目：
   - 保留原成本和实际成本事实。
   - 若需要形成新口径，单独迁移或重算快照，禁止直接覆盖。
4. 未签约报价：
   - 不迁移最终成本，签约时按新模型重算。

## 6. 前端变化

- 报价项目库编辑器增加可编辑“标准成本价”。
- 成本价对 Boss、店长、材料、财务可见可编辑。
- 设计师和业务员不展示成本字段。
- 供应商协作增加“品牌关系”Tab。
- 采购选择供应商时按品牌过滤。
- 合同签约页增加成本预览、缺失项和快照说明。

## 7. 验收

- 无供应商可以保存报价项和成本价。
- 签约前修改成本价，签约使用最新值。
- 签约后修改成本价，不影响已签约快照。
- 供应商按品牌匹配，不要求逐项采购价。
- 实际采购价变化不会无痕修改签约预计成本。
- 成本缺失时利润为空。
- 材料角色能看到和维护成本，但其他敏感权限按新 T05 执行。

# 装得清首次入驻三件套

- 版本：`v0.2`
- 状态：`draft_for_business_review`
- 关键更新：报价项目直接维护成本价；供应商后置维护；供应商按品牌关联；签约时计算并冻结成本。
- 事实依据：`BR-001`、`BR-002`、`BR-003`、`SOL-001`、`SOL-002`、`DEC-001`。
- 冲突提示：成本模型 V2 与 `BR-003` 的供应商采购价来源、材料角色成本权限存在冲突，正式开发前需业务智能体更新正式规则。

## 三部分内容

1. 新手企业操作引导：从注册到第一条报价和签约。
2. 组织结构与角色组建：邀请哪些角色，各自负责什么。
3. 业务前置数据准备：报价项目、成本价、供应商品牌关系、员工和客户房屋。

# 菜单命名与信息架构

## 1. 当前问题

- App 供应商协作首页标题正确，但页面导航标题仍出现“供应链”。
- 报价项目库成本区只显示“维护供应商采购价”，当供应商数量为 0 时，没有下一步。

## 2. 统一术语

| 当前混用 | 建议统一 |
| --- | --- |
| 供应链 / 供应商协作 | 面向操作人员统一为“供应商协作” |
| 合作方 / 供应商 | 标题“供应商/合作方”，业务简称“供应商” |
| 成本价 / 采购价 | 报价项目库显示“标准成本（自动汇总）”；采购价页面维护“采购价”“人工/班组价” |
| 未维护成本 / 成本 0 | “成本未维护”，不得显示 0 为已维护成本 |

“供应链”可以保留在套餐权益、行业介绍和后台管理中，不作为日常操作主菜单名称。

## 4. App 信息架构调整

- 底部或业务入口：`供应商协作`。
- 顶部 Tab：`项目采购 / 材料到货 / 供应商 / 采购价 / 库存`。
- 从报价项目库点“维护采购价”时，进入采购价编辑页并保留 `itemId`。
- 无供应商时展示空状态：

```text
还没有供应商/合作方
标准成本需要先绑定供应商采购价。
[新增供应商]
```

- 新增供应商成功后，自动返回采购价页，项目仍预选，不要求重新从报价库进入。

## 5. 功能菜单可见性

- Boss：供应商协作、报价项目库、供应商采购价均可见。
- 店长/财务：可见成本维护，但只在自身权限范围。
- 设计师/业务员：报价项目库只显示销售价；成本显示“成本未维护/无权限查看”的语义，不显示金额。
- 项目经理/材料员：从项目采购进入，不直接暴露供应商历史报价与项目毛利。

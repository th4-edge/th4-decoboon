# 交互与开发候选包

## 1. 首页开始使用卡

新增一个由真实数据推导的首次使用卡，不新增持久化 onboarding 表。

状态来源：

- 企业/门店：登录会话中的 Company/Store。
- 团队成员：`company/member/page` 数量。
- 报价项目：`catalog/item/page` 数量。
- 供应商：`partner/page` 数量。
- 采购价：`partner-price/page` 数量。
- 客户/房屋：`customer/customer/page`、`property/property/page` 数量。

卡片的每个步骤显示：

```text
状态 | 名称 | 为什么 | 操作 | 负责角色
```

## 2. 报价项目库成本区

当前：

```text
标准采购成本：待维护
[维护供应商采购价]
```

改为按状态显示：

```text
无供应商：
标准成本：未维护
先建立供应商/合作方，才能形成采购成本。
[新增供应商]

有供应商、无采购价：
标准成本：未维护
已找到供应商，下一步绑定该项目的采购价。
[绑定采购价]

有采购价：
标准成本：¥X
来源：供应商 A · 采购价 ¥X + 人工/班组价 ¥Y · 生效至 YYYY-MM-DD
[查看/调整采购价]
```

必须保留 `itemId` 作为上下文。新供应商创建完成后回到当前项目，不丢失编辑上下文。

## 3. 供应商协作页

页面统一标题：

```text
供应商协作
项目采购、材料到货、供应商/合作方和采购价统一维护
```

供应商 Tab 空状态：

```text
还没有供应商/合作方
先添加一个材料供应商、厂家或劳务班组。
[新增供应商]
```

采购价 Tab 空状态：

```text
还没有采购价
选择供应商和报价项目，建立标准成本。
[新增采购价]
```

## 4. 验收标准

- 首次登录 Boss 首页能看到“开始使用装得清”和明确第一步。
- 报价项目可以先保存，成本未维护不阻止销售价维护。
- 无供应商时，成本区按钮指向新增供应商，而不是直接进入空白采购价页。
- 新增供应商后，自动回到采购价编辑并保持报价项目选中。
- 采购价保存后，报价项目库显示“标准成本已同步”和来源摘要。
- App 均使用“供应商协作”，不再在操作路径中显示“供应链”。
- 设计师不看到采购成本，也不看到供应商历史报价。

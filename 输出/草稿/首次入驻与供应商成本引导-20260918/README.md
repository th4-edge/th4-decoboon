# 首次入驻与供应商成本引导方案

- 需求编号：`REQ-PRODUCT-ONBOARD-20260918`
- 当前状态：`draft_for_review`
- 来源：真实“安徽麦鸿装饰设计 / 张伟”首次注册使用记录
- 业务依据：`BR-003 采购执行价与标准成本权限规则`、`SOL-002 项目成本与利润可追溯`
- 设计边界：产品应用引导与信息架构；不改写业务智能体正式规则，不直接修改生产代码。

## 结论

首次注册后，系统必须展示一条面向企业负责人的“开始使用装得清”路径。当前最需要新增的不是更多页面，而是：

1. 首页明确告诉 Boss 先维护什么、为什么维护、完成后能开始什么业务。
2. 报价项目库允许先保存销售项，再单独补供应商和采购价。
3. 从报价项目库点击成本维护时，无供应商要直接引导新增供应商；新增后回到当前项目继续绑定采购价。
4. “供应商协作”成为统一操作名称；供应商、采购价应能从供应商协作进入，不应只在财务经营里出现。
5. App、Breadcrumb、页面标题和按钮统一术语：`报价项目库`、`供应商协作`、`供应商/合作方`、`采购价`、`标准成本`。
